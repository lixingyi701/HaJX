本赛题把"数据质量"和"领域配比"这两个原本无法量化的概念，变成可以进公式的数字，

## 方法总览（一句话原理）

| 环节     | 方法                             | 一句话原理                                                   | 用途                         |
| -------- | -------------------------------- | ------------------------------------------------------------ | ---------------------------- |
| 质量赋权 | **CRITIC**                 | 区分度大、又不与他项重复的指标，权重更高（客观、自动去冗余） | 合成质量分                   |
| 质量合成 | **加权几何平均**           | 乘法形式，一项极差就拉低总分（"短板支配"，保留连续性）       | 合成质量分                   |
| 对照     | **PCA / TOPSIS / K-means** | 降维 / 离理想解距离 / 无监督分档                             | 验证质量结构是内在的         |
| 冲突     | **Kendall's W**            | 衡量多个评委打分有多一致                                     | 定位冲突发生在跨来源之间     |
| 消解     | **Huber 降权**             | 对偏离离谱的信号打折扣而非删除                               | 温和消解冲突、不误伤专业语料 |
| 补分     | **GBDT 梯度提升**          | 很多浅树接力修正前一棵的残差                                 | 给无标签领域补质量分         |
| 配比回归 | **clr 中心对数比**         | 把"占比"换成相对几何均值的对数比，消掉"和为1"的假相关        | 正确刻画配比→损失           |
| 形式选择 | **交叉验证**               | 用没见过的数据当考卷，防止自我打高分                         | 让数据裁决公式形式           |
| 稳健     | **Bootstrap**              | 重采样估计参数的置信区间                                     | 给关键参数误差条             |

详细动机与结论见 `分析说明.md`。

## 核心成果

**问题一**：22 个异质质量信号 → 连续质量分 Q（27.2 万样本）；测得并消解 **21.5%** 的
指标冲突；clr 回归把配比→损失的预测 R² 从 0.654 提到 **0.772**；给出 17×13 迁移矩阵
与最优配比（相对均匀配比预测降损 **11.9%**，95% CI [9.7%, 14.1%]，报告摘要用保守值
9.9%）；发现**内在质量与训练价值几乎正交（秩相关 -0.06）**。

**问题二**：交叉验证从 5 种候选中裁决出**加性惩罚**形式，建立广义标度律

```
L(N,D,Q) = E + Ã(Q)·N^(-α) + B·D^(-β) + (1-Q)·k₀ ,   Ã(Q) = A + k₁(1-Q)
E=1.6901, A=406.4, α=0.340, B=410.6, β=0.280, k₀=0.192, k₁=175.3
```

Q=1 时精确退化为经典 Chinchilla。四条解析命题：质量弹性≈4×规模弹性；质量+0.1 在
100 亿参数处≈扩参 1.64 倍；质量地板 E+(1-Q)k₀ 规模不可救赎；最优配置随质量向"小模型
多数据"移动（∂N*/∂Q<0）。解析解与数值优化互验相对误差 <1e-6。

## 关于附件数据的重要提醒

我们全程遵循**证据分层**：真实观测（A1–A11 等）支撑主结论；半合成/插值数据（B2、
B6–B8）仅用于形式选择并明示假设；外推生成数据（A12–A15、B10）只作旁证。特别地，
**B8 与 B6/B7 不同源且方向相反，不能混入联合拟合**（这是个陷阱）。因此 B 附件推出的
参数（k₀、k₁）**绝对数值不宜直接外推到真实训练体系**，应用时以趋势和结构结论为主。
