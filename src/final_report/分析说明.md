## 零、先用一个比喻理解整道题

训练一个大语言模型，可以想象成培养一个学生：

| 符号 | 含义 | 比喻 |
|---|---|---|
| N | 模型参数量 | 学生的脑容量 |
| D | 训练用的 token 数 | 读了多少书 |
| Q | 数据质量 | 教材好不好 |
| p | 各领域数据配比 | 各科课时怎么分 |
| C | 总算力预算 | 教育经费 |
| L | 验证集损失（越低越好） | 考试扣的分 |

学术界早就知道 N 和 D 怎样影响 L，这就是著名的**标度律**（Scaling Law）：损失随模型和数据变大，按幂函数的规律下降。但"教材好不好""课时怎么分"一直只是定性的说法，写不进公式。整道题要做的事，就是把 Q 和 p 变成数字、塞进公式，再用这个公式去回答"钱该怎么花"和"未来会怎样"。

四个问题是一条链，前一问的产出就是后一问的输入：

```
问题一：把 Q、p 变成数字 → 问题二：把它们写进标度律 → 问题三：在预算约束下求最优 → 问题四：把损失翻译成能力分，做分解和预测
```

整份工作守两条纪律，理解了这两条，就能看懂后面很多"为什么不那样做"。

第一条是**接口化**。每一问的结果都存成固定文件（P1 ~ P4），下游只读取这些文件，不重新拟合。所以全文只估计**一次**标度律，四个问题的口径自然对得上，不会出现"问题二一套参数、问题三又一套参数"的情况。

第二条是**证据分层**。附件数据的可信度差别很大：有的是真实观测，有的是半合成或插值出来的，还有的是纯外推生成的。我们只让真实观测支撑主结论；半合成数据只用来挑选公式形式；外推数据只拿来讨论稳健性。这样即使某张附件表有问题，主结论也站得住。

## 一、数据预处理：先审数据，再动手（论文 §5.1）

**为什么先做这一步。**附件有几十个文件，来源各不相同。如果不先逐表核对就直接建模，很容易把不能放在一起的数据硬拼起来。我们审计时发现了五个会改变建模路线的事实：

- A10、A11 两张表行数不一样（64 行和 63 行），要按编号取交集后才能对齐；
- 17 个配比领域里只有 6 个有官方质量映射，另外 11 个是空白，需要自己补；
- 附件 B1 可以被一个三参数公式几乎完美地拟合（误差只有万分之一点五），说明它是公式生成的，没有噪声，只能当"标准答案"式的锚点用；
- 附件 B8 在相同条件下和 B6/B7 的走势相反（相关系数 −0.03），是一张不能混用的"陷阱表"；
- C1 的日期是上榜日，比模型真实发布日平均晚了约 100 天，所以不能当时间轴用。

**指标的整理。**附件给出的 22 个质量字段格式五花八门：有的是分类器输出的 logits，有的是负对数比，有的是规则统计量（比如平均词长、符号比例）。我们先把它们统一展开成 25 个"越高越好"的指标，再在每个领域内部做稳健归一化，包括缩尾（去掉最极端的 1%）、取对数压重尾、Min–Max 压到 0~1。这里有个细节很关键：归一化的参数在 A1 上算好以后就**冻结**，原样用到 A2、A3 上。否则抽样集和全量集之间的差异，就会跟"处理方式不同"造成的差异混在一起，说不清楚。

## 二、问题一：把"质量"和"配比"变成数字（论文 §5.2）

### 2.1 给每篇文档打一个质量分：CRITIC + 加权几何平均

**要解决什么。**25 个指标要合成一个总分，关键在于每个指标该占多大权重。

**CRITIC 客观赋权。**一句话原理：一个指标如果区分度大（不同文档之间差异明显），又和其他指标不重复，它携带的信息就多，应该给更大的权重。权重完全由数据算出来，不靠人拍脑袋，还会自动压低"重复的信号"。我们没有用常见的熵权法，原因就是熵权法不会惩罚冗余。

**加权几何平均。**合成总分时，我们把各指标"乘起来再开方"，而不是加权相加。乘法有"一票否决"的效果：只要某一项特别差（比如广告概率极高），总分就会被明显拉低。这和业界"发现是垃圾就整篇丢掉"的过滤思路方向一致，但保留了连续的分数，不是非黑即白。

**怎么证明这个分数不是我们"造"出来的。**我们另外用三种假设完全不同的方法给同一批文档打分：

- **等权几何平均**：所有指标一样重；
- **TOPSIS**：看每篇文档离"理想好文档"有多近、离"最差文档"有多远；
- **PCA 主成分分析**：把众多相关指标压缩成少数几个主成分，再按主成分打分。

它们和 CRITIC 的排名相关系数分别是 0.991、0.946、0.871。三种互不相干的思路给出几乎相同的排序，说明"质量高低"是数据里客观存在的结构，不依赖于某种特定的权重。这就是论文里"互相验证"的意思。

**结果。**七个领域的质量排序是：arxiv（0.713）> stackexchange > commoncrawl > github > book > c4 > wikipedia（0.484）。维基百科排在最后，看上去有点反直觉，原因是它各项指标都比较平均，没有突出的强项，而几何平均恰好奖励"没有短板且有长板"的文档。我们还用 KS 检验对比了抽样集和全量集的分数分布（p = 0.60 和 0.12，差异不显著），说明抽样集有代表性。

### 2.2 指标"打架"：冲突的定义与消解

**什么叫冲突。**同一篇文档，有的指标说它好，有的说它差。例如一段 LaTeX 数学推导，"专业性"很高，"表层流畅度"却很低。

**关键选择：阈值不预先设定。**如果事先规定"差异超过某个数才算冲突"，冲突率的高低就由这个数决定了，想让冲突多就把阈值调小，这是循环论证。我们的做法是画出"冲突率随阈值变化"的曲线，取曲线弯得最急的那一点（最大曲率点）作为阈值，结果 τ = 0.75。

**用到的两个工具。**

- **Kendall's W（肯德尔和谐系数）**：衡量"几个评委打分有多一致"，取值 0~1。我们把 25 个指标按来源分成四组，发现组内很一致、组间才打架，所以冲突按"组"来定义。
- **Huber 稳健降权**：一句话原理，对偏离太远的信号不删除，只打折扣，温和地拉回来。

**结果。**实测冲突率是 **21.5%**，扩展集上是 21.1% 和 22.9%，结论可以复现。这直接否定了《数据说明》里"冲突率约 0%"的说法。主要冲突类型是"DSIR 分高、规则型分低"，抽查 30 篇原文后，确认有两类成因：代码和公式专业价值高但表面不流畅；模板化网页统计量好看但没什么教育价值。Huber 降权以后，总体排名几乎不变（相关系数 0.997），冲突样本平均只下调了 0.0033。也就是说，处理方式是"降权而不删除"，既压住了矛盾信号，又不误伤专业语料。

### 2.3 给没有标签的领域补分：桥接

配比实验涉及 17 个领域，其中 11 个没有官方质量分。规则统计量（平均词长、符号比例等）是可以直接用原文重新算出来的，于是我们自己实现了 11 个规则算子，在有官方分的数据上训练一个**梯度提升模型**来学习"规则统计量 → 质量分"的映射，再用它给空白领域打分。

**梯度提升（GBDT）**，一句话原理：用很多棵很浅的小决策树，后一棵专门修正前一棵的错误，逐步逼近目标。它是表格数据上最常用的强预测器之一。

在 6 个有官方分的领域上检验，补出来的分数和官方分的相关系数是 0.70。样本太少的领域（ubuntu_irc 只有 16 篇，philpapers 只有 63 篇）都标注为低置信。

### 2.4 配比与损失的关系：clr 变换 + Huber 回归

**陷阱在哪里。**配比是成分数据，各领域占比加起来必须等于 1，一个涨，别的就必然跌。直接拿占比去做回归，会把这种机械的此消彼长误认为领域之间真的存在替代关系。

**clr（中心对数比）变换。**一句话原理：把每个占比换成"它相对于所有占比几何平均的对数比值"，从而消掉"加起来等于 1"带来的假相关。这是处理成分数据的标准方法，也是我们相对 RegMix（直接用原始配比做回归）的主要改进。

**结果。**检验集上的 R² 从直接回归的 0.654 提升到 **0.772**，这就是处理闭合效应带来的实际收益。梯度提升模型的 R² 更高（0.897），说明领域之间存在交互效应，所以我们做了分工：**解释系数用线性模型，搜索最优配比用非线性模型**。

由线性模型的系数可以得到一张 **17×13 的迁移矩阵**，它告诉我们"多放一点某个领域的数据，各个验证领域的损失会怎样变化"。13 个"自己对自己"的效应全部为负，说明多放某领域的数据，在该领域上的损失总会下降，这符合常识，模型是可信的。

**一个很重要的反直觉结论。**领域的内在质量和它的训练价值几乎不相关（秩相关只有 **−0.06**）。质量分最低的数学领域，训练边际价值反而最高。这说明配比不能照着质量排名来定，必须靠实验回归；同时也说明在问题二里，Q 和 p 必须作为两个独立的变量进入模型。

### 2.5 最优配比与跨尺度验证

在 10 万个随机配比候选中，我们用梯度提升模型找出最优的一批，取前 100 个的平均作为最优配比 p*。它的前五位是：pile_cc 15.6%、stackexchange 10.0%、wikipedia 9.5%、pubmed_central 9.1%、arxiv 8.9%。

降损幅度有两种算法，说明如下：梯度提升模型的点估计是比均匀配比降损 **9.9%**；线性模型用 bootstrap 重抽样得到的 95% 区间是 [9.7%, 14.1%]，中位数 11.9%。论文正文采用更保守的 9.9% 作为主报告值，同时给出区间。

**小模型的结论能不能用到大模型上？**我们用 1M 参数模型的系数，去预测 60M 和 1B 模型的结果，发现配比效应的"排序"基本保持（斜率稳），但损失的"绝对水平"会随规模整体下移（截距漂）。所以往大模型外推时，只需要修正截距。修正后，外推误差（MAE）从 3.5 降到 0.10。

## 三、问题二：把质量写进标度律（论文 §5.3）

### 3.1 背景：经典标度律

```
L(N, D) = E + A·N^(−α) + B·D^(−β)
```

E 是无论怎么堆资源都消不掉的"底损失"；后两项分别是模型不够大、数据不够多造成的损失，会按幂律下降。这就是 Chinchilla 公式，里面没有质量这一项。

### 3.2 先"逆向"附件 B

动手拟合之前，我们先弄清楚附件 B 的各张表是怎么来的（论文图 9）。结论是：B1 由公式生成、没有噪声；B6/B7 可以分解为"基线 + 质量惩罚"，而且惩罚项对 (1−Q) 呈线性；B8 与 B6/B7 走势相反，不能混用。这一步决定了"用哪些表、怎么用"。

### 3.3 质量怎么进公式：让交叉验证来裁决

质量影响损失的方式有很多种。文献里流行"有效数据量"的思路，也就是把低质量数据折算成更少的数据（乘一个小于 1 的系数）。但这只是文献偏好，不一定适合本题的数据。所以我们列出五种候选形式，用**交叉验证**来选择。

**交叉验证**，一句话原理：把数据分成几份，轮流拿其中一份当"考卷"，其余当"复习资料"，看哪种公式在没见过的数据上预测得最准。这样可以避免"自己出题自己考高分"。

结果是**加性惩罚形式胜出**，预测误差 0.051，基本压到了数据噪声的水平；文献偏好的"有效数据量"乘子族全部落败，误差在 0.099~0.105 之间，差了将近一倍。最终的广义标度律是：

```
L(N, D, Q) = E + [A + k₁(1−Q)]·N^(−α) + B·D^(−β) + (1−Q)·k₀
```

参数为 E = 1.690，A = 406.4，α = 0.34，B = 410.6，β = 0.28，k₀ = 0.192，k₁ = 175.3。

用白话说，**质量越差，有两处会变差**：一是底损失被抬高了 (1−Q)·k₀，这部分怎么堆资源都消不掉；二是参数项的系数变大，相当于堆参数的效果被削弱。当 Q = 1 时，这两项都变成 0，公式正好退化回经典的 Chinchilla 形式。配比 p 则通过"配比加权平均质量"和问题一的迁移矩阵接入公式。

### 3.4 从公式推出四条能指导决策的规律

有了公式，就可以用求导等微积分方法推出结论。每一条都另外用数值优化独立算了一遍，两者的相对误差小于十万分之一。

1. **弹性对比。**在典型规模下，损失对质量的弹性大约是对规模的 4 倍。通俗地说，同样按比例改进，提升质量的效果大约是扩大模型的 4 倍。
2. **质量和参数可以互相替代。**质量提高 0.1，在 10 亿参数的规模上相当于把模型放大 1.33 倍，在 100 亿参数的规模上相当于放大 1.64 倍。**模型越大，质量越值钱。**
3. **质量地板。**无论 N、D 堆到多大，损失都降不到 E + (1−Q)·k₀ 以下。低质量数据造成的这部分损失，是规模无法弥补的。这就是问题三里"花钱买质量"在理论上的依据。
4. **最优配置随质量移动。**给定算力，最优模型大小 N* 有闭式解；数据质量越高，最优策略越偏向"小模型、多数据"。这条规律为问题三的"结构性转移"提供了机制上的解释。

问题二还有一个附带结论：从迁移矩阵可以看出领域之间哪些是**互补**关系（例如 stackexchange 和 github 互相帮助，都是问答和代码类数据），哪些是**替代**关系（例如增配 enron 邮件会让数学领域的损失上升）。

## 四、问题三：在预算约束下怎么花钱（论文 §5.4）

### 4.1 问题是什么

总成本由三部分组成：训练成本 6ND、提升质量的成本 D·[g(Q) − g(Q₀)]，以及长上下文带来的注意力成本 η·N·D·L_ctx。总成本不能超过预算 C，目标是让损失 L 最小。题目给了三种提质成本函数 g（指数型、幂函数型、对数型），需要比较它们。

### 4.2 关键技巧：把约束"解掉"

三项成本都和 D 成正比，而损失随 D 增大严格下降，所以最优解一定会把预算花光（约束取等号）。于是 D 可以用 N 和 Q 直接表示出来：

```
D = C / [κN + Δg(Q)]，  其中 κ = 6 + η·L_ctx
```

原来"三个变量加一个约束"的问题，就变成了"两个变量、没有约束"的问题。这样做的好处是，不需要《数据说明》里建议的"罚函数"。罚系数取多少本身就是一个任意的选择，还会让结果偏离真正的最优解。

**求解器的设计。**固定 Q 以后，损失对 log N 是单峰的（先降后升），所以内层用**黄金分割法**（每次把搜索区间按 0.618 的比例缩小，是找单峰函数最小值的经典方法）；外层对 Q 做三级网格加密，最终精度小于十万分之一。这样一共求解了 3 种 g × 7 档预算 × 5 档上下文长度 × 2 种起点质量，共 **210 组**最优解。

**怎么知道求解器算得对。**我们做了两项检验：在不提质的情形下，问题二给出了 N* 的闭式解，数值解与它的相对误差不超过 1.83×10⁻⁷；和"粗网格暴力穷举"相比，损失差不超过 1.6×10⁻⁵，而且判断出的"区制"完全一致。

### 4.3 核心概念：结构性转移

题目要求给"结构性转移"一个数学定义。我们的定义是：**最优解所处的"边界状态"发生了改变**。Q 只有三种可能的状态：贴在下界 Q₀（完全不提质）、在中间（部分提质）、贴在上界 1（提满）。数学上这叫 KKT 条件中的"活跃约束集"。预算跨过某个临界值 C_crit 以后，状态从一种变成另一种，就称为发生了结构性转移。

**为什么要这样定义。**如果只是"看图，觉得曲线在这里拐弯了"，那是主观判断；按活跃约束集来定义，就可以计算、可以检验。我们进一步推出了一个判别量 Φ(C)，它等于"提质带来的边际收益"除以"提质挤占数据造成的边际损失"。Φ < 1 时不值得提质，Φ = 1 的那个预算就是 C_crit，可以用二分法直接解出来。

### 4.4 结果怎么读

**第一，转移几乎是"跳变"。**小预算时完全不提质，一旦过了临界点，就直接把质量提满，中间几乎没有"部分提质"的过渡。原因是：损失对 Q 是线性的，而提质成本对 Q 是凸的（越往上越贵），这种组合下最优解倾向于落在两端的角点上。在全部 210 组中，34 组是"不提质"的 Q₀ 角点，3 组是内点，全部出现在 C = 10¹⁹ 和 10²⁰ 这两档的指数型和幂函数型中；其余都是提满。

**第二，成本函数的形式决定临界点。**主口径下，指数型的 C_crit 约为 10^20.61，幂函数型约为 10^20.48，而对数型早了大约两个数量级（10^18.52）。原因是对数型函数在 Q 接近 1 时的边际成本最低。所以"要不要提质"没有统一的答案，要看提质成本是什么形式的。

**第三，结论稳健。**我们用了三种不同的口径识别临界点（Φ = 1 的解析解、提质成本占比的峰值、D/N 曲线的拐点），主口径下它们相差不超过 0.05 个数量级。把问题二的参数重抽样 500 次（bootstrap），C_crit 的波动在 ±0.03 个数量级以内。

**上下文长度的影响。**注意力成本与训练成本之比是 ηL_ctx/6，两者相等时 L_ctx = 6/η = **30000**，这是题目要求的解析临界值。上下文越长，相当于给每个参数"加价"，所以最优策略是缩小模型：上下文从 2k 增到 131k 时，最优模型缩小到原来的 0.48 倍，注意力成本占到总成本的 81%。数值解和解析公式的最大偏差只有 0.002。

**把配比也一起优化会怎样？**配比和规模、质量联合优化，能在 p* 的基础上再降约 13.7%，但这部分收益几乎全部来自配比本身，规模和提质通道的贡献不到 0.1%。而且在不同的预算和成本函数下，最优配比的排序几乎一样（秩相关 ≥ 0.976）。所以"先定配比、再定规模和质量"的分步做法是成立的。

### 4.5 顺带纠正《数据说明》的三条错误建议

- 说明文档给的"C = 10²² 时的最优配置"只花掉了 0.06% 的预算，按我们的标度律，它的损失是 5.36，而真实最优只有 2.14；
- "各档预算都应该 Q* = 1、不用比较成本函数"的说法，和上面 34 组不提质的结果矛盾；
- "穷举网格 + 罚函数"不仅没有必要，而且没法连续地识别出临界点。

## 五、问题四：规模和技术，各贡献了多少（论文 §5.5）

### 5.1 先把四项口径说清楚

题目点名要求说明四件事，因为口径选得不一样，结论可能完全不同：

| 口径 | 我们的选择 | 为什么 |
|---|---|---|
| 能力怎么衡量 | 主口径用 C1 排行榜的 Average；副口径用 C8 逐任务重算的"去饱和分" | Average 是公认指标，但里面混有已经"考满分"的任务 |
| 什么算开源 | 权重可以下载就算 | 按许可证细分以后，宽松和社区许可两档的前沿几乎一样 |
| 模型类型 | base（预训练）和 chat（对话微调）分开分析 | 两类模型的能力来源不同；合并模型数量太多，也不是独立的技术样本，所以剔除 |
| 时间轴 | 用 C2 的真实发布日 | C1 的上榜日平均晚约 100 天，而且只覆盖 9 个月 |

### 5.2 任务饱和：为什么要"去饱和"

我们把 C8 的 1958 个评测文件逐个任务拆开，发现 39 个任务中有 10 个已经饱和（大家都接近满分，比如时间顺序推理任务已经到了 1.00）。饱和任务就像一门人人都考 100 分的科目，放在总分里只会把进步"稀释"掉。去掉这些任务以后，前沿在 9 个月里的相对涨幅从 29.5% 变成 **48.2%**，也就是说，Average 把真实进步速度低估了约 1.6 倍。

### 5.3 桥接：把"损失"翻译成"能力分"

问题二、三讲的都是损失 L，问题四要的是能力分 S，中间需要一座桥。我们用 **S 形函数（sigmoid）**来连接：损失很高时，得分停在随机猜测的水平；损失降到某个区间时，得分快速上升；再往后逐渐饱和。这和"能力涌现"的经验现象一致。

选择 S 形而不是直线，同样是由交叉验证决定的：S 形的留一误差是 8.08，直线是 8.28，常数是 9.51。数据按可比性分层加权：同一模型、同一验证集的高可比数据权重为 1，近似可比的数据权重为 0.5。

这里还发现了一个事实：损失和得分是**负相关**（r = −0.51，损失越低、得分越高），而《数据说明》写的是 +0.68 正相关，方向完全反了。

### 5.4 贡献分解：结构模型 + Shapley

**思路。**对每个模型，用问题二的标度律算出它的"规模状态" L̂(N, D)，这一项代表规模的贡献；再加一个随时间线性增长的"技术项"，代表同样规模下，因为方法进步而多拿的分数。模型写成：

```
得分 = S 形桥接(规模状态 L̂) + τ × (年份 − 2023)
```

拟合的 R² 为 0.87。τ = 2.45，意思是"规模不变的情况下，每年因技术进步多拿约 2.5 分"。

**Shapley 分解。**一句话原理：它来自合作博弈论，把"两个因素一起变化带来的总增长"公平地分给两个因素。做法是：先变规模再变技术算一遍，先变技术再变规模再算一遍，取两次的平均。这样就不会因为计算的先后顺序而偏向某一方。

**结果与如何读。**2023 年中到 2025 年初，base 模型前沿从 12.5 分升到 37.3 分。

- 用结构模型（主口径）算，技术进步贡献 **13%~23%**，规模扩张贡献 77%~87%；
- 用业界常见的线性"效率前沿"方法算，技术占比是 **38%~46%**。

两类方法相差约 33 个百分点。我们没有硬凑出一个数字，而是如实并列两者，并解释差异的来源：线性方法假设得分随算力直线上升，没法表达"损失刚进入陡峭区时，得分会突然加速"这种 S 形红利，于是把这部分规模红利错记到了技术头上。结构模型能吸收这部分，拟合优度也明显更高（0.87 对 0.66），所以主结论采用结构口径，线性口径作为上界参考。无论用哪种方法，"**规模扩张占主导**"这个定性结论都成立。

chat 模型额外有一项"后训练增益"：同一家公司的 chat 版比 base 版平均高 4.3 分，而且这个差距每年还在扩大约 3.3 分，说明后训练本身也是一种持续进步的非规模技术。

### 5.5 预测：算力增长放缓时会怎样

**预测链条。**这一步不引入新的自由参数，完全沿用前面的结果：

```
算力增速情景 → 问题三的最优配置给出损失下降多少 → 桥接成得分增量 → 加上技术项 → 前沿预测
```

算力增速的三个情景来自 C4 数据中开源模型历年最大训练算力的趋势：基线每年 0.60 个数量级，减半 0.30，降到四分之一 0.15。不确定性用蒙特卡洛模拟 4000 次得到，同时包含标度律参数、分解参数、后训练增益和前沿残差四种来源。

**结果（base 开源前沿，24 个月后的中位数）：**基线情景 46.2，减半 45.2，四分之一 44.1。

**怎么理解。**算力增速从 0.60 降到 0.15，24 个月后的前沿只少了约 2 分。原因是规模增量本来就处在 S 形曲线的饱和段，被压缩了；而技术项基本不受影响。所以**算力越紧张，技术进步在增量中的占比越高**，从 55% 升到 77%。对 chat 模型来说，"后训练增益能不能继续增长"的影响（约 7 分）比算力情景的影响（约 2 分）大得多。

**回测。**只用 2024 年中以前的数据重新拟合，去"预测"2025 年初的前沿：我们的模型误差是 −0.78 分，朴素的直线外推误差是 +2.65 分。直接对月度排行榜做时间序列外推，3 个月后误差达到 +7.9 分，因为前沿已经进入平台期。这也是我们不直接用 ARIMA 外推的实证理由。

## 六、检验与稳健性：怎么知道结论可信（论文 §6）

论文用一张总表（表 13）列出了全部检验，这里说明怎么读它。我们把"对照"分成三类，不能混在一起：

- **互相验证**：同一个问题，用假设完全不同的方法去算，看结论是否一致。例如 CRITIC 与 PCA、解析解与数值解、三种识别临界点的口径。
- **改进证据**：新方法在同一判据上优于旧方法。例如 clr 回归的 R² 0.772 高于直接回归的 0.654；加性形式的 0.051 优于乘子族的 0.099。
- **概念区分**：两者本来就应该不同，"不一致"本身就是结论。例如质量和训练价值的相关只有 −0.06，这不是检验失败，而是"内在质量不等于训练价值"的证据。

上下游工序之间（比如冲突分析和配比回归）只是流水线上的前后关系，不构成互相验证，论文里没有做这类声称。

灵敏度分析对每一问的关键假设都做了扰动：冲突阈值、质量口径的换算基准、提质成本系数 η 的 ±50%、桥接数据的分层权重、分解的时间窗口等。结论的**定性部分**（排序、区制、"规模为主"）在所有扰动下都不变，变化的只是数值大小。

## 七、局限：哪些地方要谨慎（论文 §7.2）

我们也如实说明了模型的局限：

- 11 个补分领域的质量分依赖桥接模型（R² 只有 0.31），只能看趋势；
- 附件 B 的质量实验表有半合成成分，k₀、k₁ 的绝对数值不宜直接套用到真实训练中；
- 问题三的"跳变"和"对数型早两个数量级"这两个结论，对提质成本函数的具体形式敏感；
- 问题四的桥接数据中，高可比层只有 7 个点，而且都在底部区域，S 形上升段主要依靠近似可比的数据；
- 所有预测都是**情景条件下的预测**，不包括新架构这类突破性事件。

## 八、一句话总结

问题一把"数据质量"和"配比"从形容词变成了可计算的数字，并纠正了三处想当然（冲突率不是 0、成分数据不能直接回归、质量不等于训练价值）；问题二用交叉验证选出加性惩罚形式，把质量写进标度律，推出"质量弹性是规模的 4 倍""低质量有规模补不回来的地板"等规律；问题三证明了提质决策会在临界预算处发生"不提质 → 提满"的跳变，临界点由成本函数的形式决定；问题四表明过去两年开源模型的进步主要来自规模扩张，但算力增长放缓以后，技术进步将成为增量的主体。

贯穿全文的判断是：**数据质量和配比是与算力并列的一等资源**。预算小的时候，钱应该先花在规模上；跨过临界预算以后，应该把数据质量提满；算力增长放缓时，能力的增长会越来越依赖非规模的技术进步。
