# 问题一求解结果汇总

> 运行日期 2026-09-23。代码在 `code_q1/`（q1_01 → q1_07 依序执行，q1_00_common 为公共库；纯 numpy/pandas 自实现，无 scipy/sklearn/LightGBM 依赖）。所有产出在 `outputs_q1/`：`tables/` 论文表格、`figures/` 中文图、`interface/` 五份下游接口。

## 核心数值结论

### 子任务 (a) 质量评分（SQ1）

- 22 字段展开为 **25 指标**（modernbert×4 取 softmax 期望分、qurater 拆 4 维、ad/fluency 取 P(label=1)、fineweb_edu 直取）；域内估计变换参数（A1 冻结）→ 方向统一 → 1%/99% 缩尾 → Min-Max。
- **主线 CRITIC + 加权几何平均**；对照方法一致性：vs 等权 Spearman **0.991**、vs TOPSIS **0.946**、vs PCA **0.871**（PCA 取 10 主成分累积方差 80.6%）。K-means 三档占比 优23%/普43%/劣34%（仅作相对档位对照，不替代连续 Q——页眉陷阱）。
- 七域质量中位数排序：**arxiv 0.713 > stackexchange 0.590 > commoncrawl 0.557 > github 0.533 > book 0.511 > c4 0.499 > wikipedia 0.484**。
- **抽样代表性（A1 vs A2/A3 全量，同一冻结管线）**：arxiv KS D=0.021 (p=0.60)、github KS D=0.012 (p=0.12)，Cohen's d≈0.005 → 抽样集代表性良好，域级结论可放心由抽样集外推。

### 子任务 (b) 冲突消解（SQ2）

- 25 指标按来源分 4 组，组内 Kendall W：DSIR 0.998（几乎同构）、轻量分类器 0.627、模型评分器 0.447、**规则型 0.128**（规则指标彼此测的是不同侧面）。
- 冲突 = 4 组域内分位排名极差 > τ；**τ=0.75 由冲突率-τ 曲线最大曲率自适应确定**（拒绝预设阈值）。**A1 冲突率 21.5%——直接反驳《数据说明》页眉"冲突率≈0%"的循环论证**。
- 冲突×域 卡方=142.4 (df=6, p≈1.5e-23)：冲突与域强相关；各域冲突率 wikipedia 25.0% > book 24.6% > github 22.9% > arxiv 21.1%。
- 主冲突类型跨三集复现：**"DSIR 高 × 规则型低"**（A1 19.6% / A2 15.1% / A3 18.1%）。扩展集冲突率 A2 21.1%、A3 22.9%，与抽样集 21.5% 一致。
- 消解：**Huber 连续降权**（保序性 Spearman(Q,Q̃)=0.997，冲突样本平均 -0.0033，非冲突基本不动——"降权不误伤"）；对照调和平均短板惩罚（冲突样本 -0.149，供"严格口径"敏感性）。人工抽查样本 30 条已导出 `T3_manual_check_samples.csv`（带 content 前 500 字符）。

### 桥接（A16 缺口的解决，本方案独创点）

- 11 个 inferred 域无官方质量信号 → **自实现 11 个 rps 规则统计量算子 Φ**，在 A1 上（同源复算，n=21,590）以消解后 Q̃ 为标签训练校准函数 ĝ（GBDT，域分层 5 折 **CV R²=0.31**；Ridge 0.25）→ 应用到 A18 的 31,340 篇 17 域原文。
- 6 个映射域互验：校准分 vs 官方分 Pearson 0.70、MAE 0.055（Spearman 0.26，n=6 太小仅供参考）。
- 17 域最终 Q̂_d（映射域用官方分、inferred 用校准分，均带 bootstrap CI 与证据等级标注）：最高 arxiv 0.716，最低 dm_mathematics 0.355；ubuntu_irc(16篇)/philpapers(63篇) 标低置信。

### 子任务 (c) 配比建模（SQ3）

- **N1 改进证据（clr vs 裸 OLS）**：1M 检验集 R² 0.772 vs 0.654、RMSE 0.320 vs 0.432 —— clr 变换处理闭合效应后线性模型显著更优。GBDT 非线性对照 R²=0.897（存在域间交互，故 p* 搜索用 GBDT，系数解释用 clr 线性）。
- **迁移矩阵 T (17×13)**：自域效应全为负（dm_mathematics -2.47 最强，github -0.77，arxiv -0.79……），跨域外溢可见 stackexchange↔github 互补；供 Q2 替代/互补分析。
- **λ 质量交互项（N3）**：λ·Σpᵢ(1-Q̂_d) 在 **10/13 验证域显著**（bootstrap 95% CI 不含 0），加项后检验集 RMSE 全部不升（dRMSE≤0）。**注意符号结构**：多数域 λ<0（中位 -0.249）、arxiv 域 λ=+0.79——质量惩罚项的作用方向随验证域而异，说明"质量对配比-损失关系有独立解释力，但不是同号乘子"，这一发现要如实写入论文并在 Q2 作为"质量进入标度律应做域条件化"的证据。
- **质量-价值解耦（N-bridge 检验）**：域级质量分 Q̂_d 与训练边际价值 ν_d 的 Spearman = **-0.06 ≈ 0** —— 定量证实"内在质量 ≠ 训练价值"（RegMix pile_cc 现象的一般化），为 Q2 把 Q 与 p 作为两个独立变量、Q3 独立决策提供依据。

### 跨尺度验证与外推（SQ4）

- 1M 系数直接预测：目标损失排名 Spearman = 1M留出 0.52 / 60M 0.47 / 1B 0.68（**排序中等保持，绝对值完全漂移**：60M/1B 的 R² 为大负数——损失水平整体下移，截距漂移主导）。
- 系数漂移拟合 b_v(N)：截距 ρ 均为负（github -0.22 最陡）、**斜率 β 几乎不漂**（max|ρ_β|≈0.007）——"配比效应稳定、基线水平随规模下降"，这直接决定 Q2 中 p 进入标度律的方式（配比项与规模项可分离）。
- est 表（**幂律外推生成、非观测**，仅作稳健性讨论）：直接套 1M 系数 MAE≈3.5（完全不可用）；尺度漂移修正后 MAE 收窄到 **0.10（35 倍改善）**。逐域稳健性排序：arxiv/pubmed_central/ubuntu_irc 最稳（ρ>0.84），pubmed_abstracts/pile_cc 最不稳（ρ<0.40）。

### 最优配比 p*

- Dirichlet（以训练配比均值为中心多浓度）采样 10 万 + GBDT 预测 + top-100 平均；GBDT 与线性模型采样点秩相关 0.77（交叉校验）。
- **等权口径 p***：pile_cc 15.6% > stackexchange 10.0% > wikipedia 9.5% > pubmed_central 9.1% > arxiv 8.9%…enron_emails≈0。预测收益 vs 均匀配比 **9.9%**（GBDT 点估计）/ 线性 bootstrap 95% CI **[9.7%, 14.1%]**。
- **pile_cc 口径 p***（RegMix 原文目标）：pile_cc 33.2% 一家独大——复现 RegMix"网页数据对下游最有利"的反直觉发现。
- Q̄(p*_eq)=0.554（供 Q3 的 Q₀ 参考）。

## 论文写作要点（如实报告，不粉饰）

1. 1M→60M/1B 的 R² 大负值不是模型失败，是**截距漂移**——绝对预测跨尺度不可用、排序部分可用，正好支撑"外推必须做尺度修正"的论证（并给出修正后 35 倍改善的证据）。
2. λ 的符号在域间不一致，**不要写成"质量惩罚一致为正"**；写"质量对配比-损失关系有显著独立解释力，方向依验证域而异"。
3. 6 域互验的 Spearman 仅 0.26（n=6），主证据用 Pearson 0.70 + MAE 0.055，并说明小样本限制。
4. ubuntu_irc/philpapers/europarl/gutenberg 样本极少，其 Q̂_d 的 CI 已在表中，引用时带区间。
5. est 表全部结论标注"幂律外推生成、非观测"。
