# 问题一、二 通俗分析说明

> 这份文档是配套《问题一二报告.pdf》的"白话导读"。报告本身是竞赛正文，追求严谨、
> 密集；这份文档反过来，讲清楚三件事：**我们为什么要这样一步步分析、每一步用的模型
> 到底是个什么东西（一句话原理）、每一步最后得到了什么结论**。看完这份再回头读报告，
> 就不会被公式挡住。
>

## 一、这道题到底在问什么（用一句话说清）

训练一个大语言模型，能力好不好，主要由四样东西决定：

- **N**：模型有多大（参数量）
- **D**：喂了多少数据（token 数）
- **Q**：数据质量好不好
- **p**：数据配比，即各个领域（网页、代码、论文、书……）各占多少

前两样 N、D 学术界已经研究得很透（著名的"标度律"）。但**Q 和 p 一直缺一个能塞进
公式里的数值刻画**——大家都知道"数据质量重要""配比重要"，可"质量"是个形容词，没法
直接算。这道题的核心任务，就是**把"质量"和"配比"从形容词变成数字**，再研究它们和
N、D 一起怎样共同决定模型能力。

- **问题一**：把质量变成一个 0~1 的连续分数 Q，把配比和模型损失的关系量化出来。
- **问题二**：把 Q、p 塞进经典标度律，得到一个统一的"广义损失公式"，并推导出一些
  有用的规律（比如"质量提高一点，等于模型放大多少倍"）。

---

## 二、总体分析思路：为什么是这个顺序

我们把四个问题看成一条递进的链：

```
问题一：把数据侧压成两个数字  →  问题二：把它们塞进公式  →  问题三：在预算下做优化  →  问题四：翻译成能力分
         (质量 Q、配比关系 f(p))        (广义标度律 L)           (最优配置)            (能力预测)
```

所以问题一每算出一个东西，都要**存成一个明确的文件（"接口"）**，好让问题二、三、四
直接拿来用，而不是各做各的、对不上口径。这是整份工作最重要的纪律。

还有一条贯穿始终的原则叫 **"证据分层"**：附件里的数据来源不一样——有的是真实观测
（可信），有的是半合成、插值的（只能参考），有的是纯外推生成的（只能做旁证）。我们
**只让最可信的数据支撑主结论**，把弱证据明确标注、降级使用。这样即使某些附件数据不
靠谱，主结论也站得住。

## 三、问题一：把"质量"变成数字（逐步拆解）

### 步骤 0｜先审数据，再动手

**为什么**：附件有 20 多个文件，来源杂。我们先逐个核对，发现了几个"坑"，直接影响后面
怎么建模，例如：某两张表行数对不齐（要按编号取交集）、17 个配比领域里只有 6 个有官方
质量标签（其余 11 个得自己补）、附件 B 里有一张表其实是公式生成的（没有噪声，只能当
"标准答案"锚点）、还有一张表（B8）和其他表方向相反（是陷阱，不能混用）。

**结论**：先把数据的可信度分好级，避免"把不同源的数据硬拼在一起"这种致命错误。

### 步骤 1｜给每篇文档打一个质量分（核心模型：CRITIC + 几何平均）

**为什么**：附件给了每篇文档 22 个"质量信号"（流畅度、广告概率、教育价值、专业性……），
方向、量纲都不一样，还互相打架。要合成一个总分，得先解决"每个信号该占多大权重"。

**用到的模型，一句话原理**：

- **CRITIC 客观赋权**：一种自动定权重的方法。它认为——一个信号如果**区分度大**（不同
  文档之间差异明显）、而且**跟别的信号不重复**，就更有信息量，给更大权重。好处是权重
  由数据本身决定，不靠人拍脑袋，还能自动惩罚"重复的信号"。
- **加权几何平均**（把各信号乘起来再开方，而不是加起来）：为什么用乘法？因为乘法有
  "一票否决"的味道——只要某一项特别差（比如广告概率极高），总分就被显著拉低。这跟
  业界"发现是垃圾就整篇丢掉"的过滤思路方向一致，但我们保留了连续性（不是非黑即白）。

**为了不"自说自话"，我们又用了三种完全不同的方法做对照**：

- **PCA（主成分分析）**：一句话——把很多互相相关的指标压缩成几个"主成分"，用最少的
  维度保留最多的信息。这里用它做降维验证。
- **TOPSIS（优劣解距离法）**：一句话——给每篇文档算"离理想好文档有多近、离最差文档有
  多远"，据此排名。
- **K-means 聚类**：一句话——不看标签，自动把文档分成几堆（这里分"优/普通/劣"三档），
  看分堆结果和连续分数对不对得上。

**结论**：四种方法（CRITIC、等权、TOPSIS、PCA）给出的文档排名高度一致（相关系数
0.87~0.99）。**这说明"质量高低"是数据里客观存在的结构，不是我们用某种权重"造"出来的**
——这就是不同方法"互相验证"的意义。领域质量排名：arxiv 论文最高，维基百科反而偏低
（因为它的指标很平均，没有突出优势）。

### 步骤 2｜指标打架怎么办（冲突的定义与消解：Kendall W + Huber 降权）

**为什么**：同一篇文档，有的指标说它好、有的说它差。比如一段 LaTeX 数学公式，"专业性"
很高但"表层流畅度"很低。这种"打架"（冲突）有多普遍？怎么处理？

**关键的方法选择——不预设阈值**：如果我们事先规定"差异超过某个小值才算冲突"，那结论
就被定义决定了（想让冲突多就把阈值调小）。这是循环论证。我们改成**让数据自己说话**：
画出"冲突率随阈值变化的曲线"，取曲线拐弯最急的那个点做阈值。

**用到的模型，一句话原理**：

- **Kendall's W（肯德尔和谐系数）**：衡量"多个评委打分有多一致"的指标（0~1，越大越
  一致）。我们用它发现：**同一来源的信号内部很一致，冲突主要发生在不同来源之间**。
- **Huber 稳健降权**：一种"对付异常值"的经典思想——对偏离得太离谱的信号，不是删掉，
  而是**打个折扣**（降低它的权重），温和地拉回来。

**结论**：真实冲突率是 **21.5%**（不是《数据说明》里写的"约 0%"——那是用预设小阈值
把结论藏进定义了）。主要冲突类型是"专业价值高但表层流畅度低"的文档（代码、公式、
论文）。我们用 Huber 降权来消解：**降权而不是删除**，既压住了矛盾信号，又不误伤专业
语料。处理前后排名几乎不变（相关 0.997），证明这是"微调"而非"推倒重来"。

### 步骤 3｜给没有标签的领域补质量分（桥接：自实现规则算子 + 梯度提升校准）

**为什么**：配比实验涉及 17 个领域，但只有 6 个有官方质量分，另外 11 个是空白。不能瞎
猜，也不能不管。

**怎么做**：有一类质量信号（规则统计量，比如平均词长、符号比例）是**可以用文本精确重算
的**。于是我们：自己写代码把这 11 个规则算子复现出来 → 在"既有官方分又能算规则量"的
领域上，训练一个**梯度提升模型（GBDT）**学习"规则量 → 质量分"的映射 → 再用它给空白
领域打分。

- **梯度提升（GBDT）**，一句话原理：用很多棵很浅的小决策树，一棵接一棵地专门去修正
  前一棵的错误，逐步逼近目标。是表格数据上最常用的强预测器之一。

**结论**：在有官方分的 6 个领域上验证，补出来的分和官方分相关 0.70。最终每个领域的
质量分都带上"置信标注"（官方 / 推断），样本太少的领域（如只有 16 篇的 ubuntu_irc）明确
标为低置信。

### 步骤 4｜配比和模型损失的关系（核心改进：clr 变换 + Huber 回归）

**为什么**：我们想知道"多放一点某领域的数据，会让模型在各领域上的损失怎么变"。直接
拿配比去回归会有个陷阱：配比是**成分数据**——各领域占比加起来必须等于 100%，所以一个
涨、别的必然跌。直接回归会把这种"机械的此消彼长"误当成"领域之间的真实替代关系"。

**用到的模型，一句话原理**：

- **clr（中心对数比）变换**：处理成分数据的标准工具。简单说，就是把"占比"换算成"相对
  于所有领域几何平均的对数比值"，消掉"加起来必须等于 1"带来的假相关。这是我们相对
  已有文献（RegMix 直接用原始配比回归）的**主要量化改进点**。
- **Huber 回归**：就是上面那个稳健思想用在回归上，抗少数异常实验点。

**结论**：用 clr + Huber，预测准确度（检验集 R²）从直接回归的 **0.654 提升到 0.772**
——这个提升就是"处理成分数据闭合效应"带来的实打实收益。由此得到一张 **17×13 的
"迁移矩阵"**：告诉你增配某个领域会怎样影响每个验证领域的损失。还发现一个反直觉但很
重要的结论：**领域的"内在质量"和它的"训练价值"几乎不相关（秩相关只有 -0.06）**——
质量最低的数学领域，训练边际价值反而最高。这直接说明：**配比不能照着质量排名来定，
必须靠实验回归**，也说明问题二里 Q 和 p 得当成两个独立变量。

### 步骤 5｜最优配比 & 小模型能不能代表大模型（Dirichlet 采样 + 跨尺度验证）

**为什么**：既然有了配比→损失的关系，就能反过来找"最好的配比"。但我们是在小模型
（1M~1B）上做的，能不能推广到大模型（10B/70B）？必须验证。

**结论**：搜出来的最优配比让预测损失比"均匀配比"降低约 **11.9%（95% 区间 9.7%~14.1%）**
（报告摘要用了更保守的 9.9% 说法，区间一致）。头号领域是网页语料 pile_cc，复现了
RegMix"网页数据对下游最有利"的反直觉结论。跨尺度验证发现：**配比效应的"排序"在不同
规模间基本保持（斜率稳），但"绝对水平"会随规模整体下移（截距漂）**——所以往大模型
外推时，只需要做一个"截距修正"，修正后预测误差缩小了 35 倍。

## 四、问题二：把质量塞进"标度律"（逐步拆解）

### 背景：什么是标度律

**标度律**（Scaling Law）是深度学习里一个著名的经验规律：模型损失 L 会随参数量 N 和
数据量 D 按**幂律**下降，写成 `L = E + A·N^(-α) + B·D^(-β)`。其中 E 是无论怎么堆资源
都消不掉的"底损失"。这就是经典的 Chinchilla 公式。**它没有质量这一项**——我们要做的
就是把 Q 补进去。

### 步骤 1｜质量该怎么进公式（不靠猜，靠交叉验证选形式）

**为什么**：质量能以很多种方式影响损失。文献里流行的一种叫"有效数据量"思路——把低
质量数据折算成"少了一些的数据"（相当于乘一个 <1 的系数）。但这只是文献偏好，不一定
适合本题数据。**我们不预设，而是列出 5 种候选形式，用交叉验证让数据来裁决。**

- **交叉验证**，一句话原理：把数据分成几折，轮流拿一部分当"考卷"、其余当"复习资料"，
  看哪种公式形式在没见过的数据上预测得最准。防止"自己出题自己打高分"。

**结论**：**线性乘性耦合加地板胜出**（五折误差 0.0497，压到数据噪声的下限）。只折扣数据项的文献口径误差 0.0979，是单参数模型里最差的。**模型形式由数据裁决，而不是从文献照搬。** 最终的广义标度律是：

```
L = {E + A·N^(-α)·[1+κ_N(1-Q)] + B·D^(-β)·[1+κ_D(1-Q)] + k₀(1-Q)}
    · exp(s(N)·[f̄(p)-f̄(p*)])
κ_N=0.431, κ_D=0.140, k₀=0.141
```

翻译成白话：**质量越低，参数项和数据项都变贵，另外还有一块堆规模也消不掉的地板。** Q=1 且配比取推荐配比时，公式退回经典 Chinchilla。主口径 Q₀ = 0.6609，不再把 Pile 除以 0.5608 当成满分。

### 步骤 2｜从公式里推出有用的规律（四条解析命题）

有了公式，就能用微积分推出一些"能指导决策"的结论。每一条我们都用数值优化独立验证过
（解析解和数值解相对误差小于百万分之一）：

1. **弹性对比**：在 (10^10 参数、10^12 token、Q=0.9) 处，**质量弹性大约是参数弹性的 3.7 倍**。质量的好处不随模型变大而消失——**模型越大，质量越值钱**。

2. **质量↔参数的等效替代**：在算力最优点上，质量从 0.5 提到 0.6，相当于参数扩大 **1.29 / 1.42 / 1.77 倍**（预算 10^20、10^22、10^24）。超过大约 10^13 参数后，这次提升不能再用扩参补回来。

3. **质量地板**：无论 N、D 堆到多大，损失都下不去 `E + (1-Q)·k₀` 这条线。低质量数据
   造成的这部分损失是**规模无法救赎的**。这就是问题三"花钱买质量"在理论上为什么必要。

4. **算力最优配置随质量移动**：给定算力预算，最优的模型大小 N* 有闭式解，而且
   **数据质量越高，最优策略越偏向"小模型、多喂数据"**。Q=0.3 时的最优参数量是 Q=1 时的 1.32 倍；C=10^22 时 token/参数比从 36 升到 63。

## 五、"互相验证"和"互相补充"到底怎么区分

这是之前特意讨论过的一个点，也是报告里《检验清单》那张表的框架。三类关系不要混：

- **互相验证**：同一个问题、用假设完全不同的方法，看结论一致不一致。例：CRITIC 和 PCA
  是两套完全不同的赋权哲学，排名却高度一致 → 互相验证成功，说明结论稳。解析解 vs
  数值优化也属于这类。
- **改进证据**：新方法比旧方法在同一判据上更好。例：clr 回归 R²=0.772 打败裸回归
  0.654 → 证明我们的改进有效。
- **概念区分**：两个东西本来就应该不一样，"不一致"本身就是结论。例：质量分 vs 训练
  价值相关只有 -0.06 → 这不是"验证失败"，而是"内在质量 ≠ 训练价值"这个重要发现的
  证据。

**上下游分工的方法之间不存在"验证"关系**（比如冲突分析和配比回归是流水线的两道工序，
不能说它俩互相验证）——报告里刻意没有做这种错误声称。

## 六、一句话总结

问题一把"数据质量"和"配比"这两个原本是形容词的东西，变成了可以进公式的数字，还
顺手纠正了三处"想当然"（冲突率不是 0 而是 21.5%、成分数据不能直接回归、质量≠训练
价值）。问题二把它们塞进标度律，用数据（而非文献）裁决出线性乘性耦合，
再推出四条能直接指导资源配置的规律。核心判断只有一句：**数据质量是和算力并列的一等
资源**——这为问题三的优化提供了目标函数、初值和机制。
