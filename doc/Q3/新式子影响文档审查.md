## 3. 正确的降维与边际判据

固定配比，令 $K=6+\eta L_{ctx}$、$\Delta g=g(Q)-g(Q_0)$。对 $Q\ge Q_0$ 和题中递增成本函数，$\Delta g\ge0$。由

$$L_D=-\frac{m\beta T_D}{D}<0$$

可知预算取等，故

$$D=\frac{C}{KN+\Delta g},\qquad
\frac{\partial D}{\partial Q}=-\frac{Dg'(Q)}{KN+\Delta g}.$$

在固定 $N,D,\mathbf p$ 时，正确的质量偏导是

$$L_Q=-k_0-\frac{m}{Q}(\kappa_NT_N+\kappa_DT_D).$$

图片给出的偏导适用于无地板版本；对当前主式遗漏了 $-k_0$。此外，“负偏导随 $Q$ 增大而减小”符号不准确：固定 $N,D$ 时，负偏导随 $Q$ 增大而上升，递减的是收益幅度 $-L_Q$。

预算消元后的目标 $F(N,Q)$ 满足

$$F_Q=-k_0-\frac{m}{Q}(\kappa_NT_N+\kappa_DT_D)
+\frac{m\beta T_Dg'(Q)}{KN+\Delta g}.$$

因而，应采用

$$\boxed{\displaystyle
\Phi(C;Q)=
\frac{\left[k_0+\frac{m}{Q}(\kappa_NT_N+\kappa_DT_D)\right](KN+\Delta g)}
{m\beta T_Dg'(Q)}}.$$

这里的 $N,D$ 应取**固定该质量 $Q$ 时**的最优规模，而不能混用全局最优质量点。令 $V_C(Q)=\min_N F(N,Q)$，在内层最优解光滑且不碰搜索边界时，由包络定理 $V_C'(Q)=F_Q$。

- 下界的局部一阶必要条件：$\Phi(C;Q_0)\le1$。
- 内点的一阶必要条件：$\Phi(C;Q)=1$，还要检查是否为极小值及是否全局最优。
- 上界的局部一阶必要条件：$\Phi(C;1)\ge1$。

**局部条件不能自动识别全局切换。** 若两个局部极小分支竞争，全局最优会在两分支损失相等时切换；下界此时仍可能满足局部 KKT 条件。题中的对数成本是凹函数，不能借“成本均凸”消除这一风险。应同时追踪 $V_C(Q)$ 的端点、内点及各分支损失，分别报告全局状态切换点与局部 $\Phi=1$ 根。二分只能用于已括根且满足相应单调性/单次切换条件的区间。

旧式即使 $L_Q$ 在固定 $N,D$ 时为常数，消元后仍含 $L_DD_Q$；故不必然只有角点。更早的一侧质量模型也不能代替当前 Q3 v2 中的双侧线性质量模型作为“旧式”。截图所引 34 个下界、3 个内点与当前论文草稿中的 8、18 也不是同一轮统计；二者均不能用作新式验收结果。

内层黄金分割的框架可保留。固定 $Q$ 后，除去常数和正乘子，目标为

$$a_QN^{-\alpha}+b_QC^{-\beta}(KN+\Delta g)^\beta.$$

其驻点方程等价于 $N^{\alpha+1}(KN+\Delta g)^{\beta-1}$ 等于正常数；该函数对数导数的分子为 $(\alpha+\beta)KN+(\alpha+1)\Delta g>0$，因此内层具有唯一驻点。外层 $Q$ 不能沿用这一单峰证明，网格加密仍需独立粗网格及多分支核对。

## 4. 为什么配比仍然耦合

沿用当前基线质量定义时，联合问题的可行集为

$$Q\ge Q_0(\mathbf p)=\sum_i p_iQ_i,\qquad
D[KN+g(Q)-g(Q_0(\mathbf p))]\le C.$$

即使 $m(\mathbf p)$ 不显含 $N,D,Q$，可行集仍随配比变化。固定 $N,Q$ 且处于共同可行区域时，提高起始质量会减少提质开销，从而增加可用 $D$；在光滑部分，

$$\frac{\partial D}{\partial Q_0}=
\frac{Dg'(Q_0)}{KN+g(Q)-g(Q_0)}>0.$$

于是配比同时影响预测损失乘子与预算利用率，单独最小化 $m$ 不能保证联合最优。若仍把最终质量直接定义成 $Q=\sum_i p_iQ_i$，目标本身还会继续耦合。

只有另外假设 $Q_0$ 外生固定、可行集是配比域与规模质量域的笛卡尔积、$s$ 为常数，且其他成本与项均不依赖配比，才有

$$\mathbf p^*\in\arg\min_{\mathbf p}m(\mathbf p).$$

若 $s>0$，这等价于最小化 $\tilde\varphi$；若 $s=0$ 则配比无差异，若 $s<0$ 则方向相反。在这些额外条件下，地板位于乘子外并不破坏先求配比的性质，但仍不能宣称候选数值搜索给出了精确全局解。

更合适的主方案是直接读取 P1 冻结的 $\mathbf p^*$，明确它是赛题允许、证据等级支持的建模取舍；联立优化保留为探索性敏感性。若继续联立，应保留 $Q_0(\mathbf p)$ 和信赖域，在外层搜索配比、内层求规模质量，不能仅因乘法形式而删除联合检验。

还有一个固定配比下也要明确的口径：按 P2 的 $p_{ref}$ 归一化，$m(\mathbf p^*)\approx0.8989423$，不等于 1。当前 Q3 v2 写“不再乘配比项”，与完整 P2 公式须先统一。含地板时，这个常数不能无声删掉，因为 $\Phi$ 含 $k_0/m$；若采用以 $p^*$ 为基准的三变量简化，应明确其参数和归一化定义。不得既声称完整继承 P2，又沿用未重标定的 $A,B$ 并忽略乘子。

## 5. 配置比的方向需要纠正

固定配比和质量、无提质开销 $\Delta g=0$ 时，质量地板与 $N$ 无关，公共乘子在规模一阶条件中抵消。因此

$$N^*=\left(\frac{\alpha A}{\beta B}\right)^{1/(\alpha+\beta)}
Q^{(\kappa_D-\kappa_N)/(\alpha+\beta)}
\left(\frac C K\right)^{\beta/(\alpha+\beta)},$$

$$\boxed{\displaystyle
\frac{D^*}{N^*}=\left(\frac{\beta B}{\alpha A}\right)^{2/(\alpha+\beta)}
\left(\frac C K\right)^{(\alpha-\beta)/(\alpha+\beta)}
Q^{2(\kappa_N-\kappa_D)/(\alpha+\beta)}}.$$

若在这一无提质成本对照族中质量随预算变化，则

$$\frac{d\ln(D^*/N^*)}{d\ln C}=
\frac{\alpha-\beta}{\alpha+\beta}
+\frac{2(\kappa_N-\kappa_D)}{\alpha+\beta}
\frac{d\ln Q^*}{d\ln C}.$$

因此，在 $Q^*$ 随预算增加的条件下，$\kappa_D>\kappa_N$ 的质量项贡献为负，与截图的方向相反。当前估计恰为 $\kappa_N>\kappa_D$，两个指数分别为 0.0967742 和 0.4206452。真实主问题含有 $\Delta g$，不能将上述对照式冒充其完整闭式解，更不能仅凭指数大小预测实际临界点后的全部趋势。达到 $Q=1$ 后质量不再变化，不能把提质过程中的附加效应一直外推。

3. 不能把九个符号理解成在 Q3 同时自由拟合九个参数。$E,A,\alpha,B,\beta$ 来自 B1，质量参数来自 B6，$s_{red}$ 由训练校准量确定；Q3 应读取冻结接口。
4. 当前 P2 bootstrap 的 `samples` 形状是 `(300,6)`，列为 `E,A,B,kappa_N,kappa_D,k0`；$\alpha,\beta$ 固定，配比和映射误差未全量传播。应据实际有效样本数和状态统计条件区间，不能将其写成 500 次全参数不确定性。

## 10. 对问题二和问题三的实际价值

**对问题二，价值主要是机制表达和可检验性，而非已经证明预测更准。** 幂次形式可写成 $N_{eff}=NQ^{\kappa_N/\alpha}$、$D_{eff}=DQ^{\kappa_D/\beta}$；$\kappa_N,\kappa_D$ 分别是两项可约损失对质量的负对数弹性，并非总 Loss 的常弹性。这使“质量补偿多少参数或数据”有清楚的代数表达，也能通过嵌套模型检验质量主要作用在哪一侧。线性旧模型已有双侧质量项，不能把“增加数据侧影响”本身称为相对当前旧式的新贡献。现有数据对 $\kappa_D$ 的支持较弱，幂次拟合也不优于线性对照。

**对问题三，价值是把结构假设转成可比较的资源决策。** 固定配比后，可比较幂次与线性、有地板与无地板、完整双侧与数据侧指数为零时的最优 $N,D,Q$、预算份额及状态切换。若结论稳定，可支持策略稳健性；若不稳定，可明确结论依赖何种尚未充分识别的假设。当前所有新临界点、内点比例和配置比变化都应视为待计算结果。

因此，这份图片文档适合作为需要修正的“模型变更影响清单”，不适合直接作为新理论贡献。更有价值的论文论证是：质量地板及两侧质量弹性的不同假设是否改变资源配置，以及这种改变是否超出参数与模型不确定性；不是未经证明地宣称新式更优或配比精确可分离。
