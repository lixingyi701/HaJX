## 2. 目标函数、成本与求解

主目标固定推荐配比 \(\mathbf p^*\)，使用

\[
L=E+k_0(1-Q)+\left[A N^{-\alpha}Q^{-\kappa_N}+B D^{-\beta}Q^{-\kappa_D}\right]\exp\{s_{\rm red}\tilde\varphi(\mathbf p^*)\}.
\]

地板 \(k_0(1-Q)\) 在括号外，不乘配比因子。\(\exp\{s_{\rm red}\tilde\varphi(\mathbf p^*)\}\) 记为 \(m_*\)，由 P2 的 `s_red_main` 与 `phi_tilde_pstar` 计算，当前为 \(0.8989423152\)。下面导数里的 \(m_*\) 用这个值。系数 \(E,A,\alpha,B,\beta,\kappa_N,\kappa_D,k_0\) 全部读取 P2，不在 Q3 再拟合。`m=1` 只作对照。\(Q=1\) 时地板为零，括号内两项仍乘 \(m_*\)。当前 \(\tilde\varphi(\mathbf p^*)\neq 0\)，固定推荐配比下 \(Q=1\) 不退化为经典基线 \(E+AN^{-\alpha}+BD^{-\beta}\)；该退化只在 \(\tilde\varphi=0\)（参照配比）时成立。

算力约束为

$$6ND+D[g(Q)-g(Q_0)]_++\eta NDL_{ctx}\le C,\quad Q_0\le Q\le1,\quad\eta=2\times10^{-4}.$$

必须比较题目附录 B 三类成本：指数 $g=10^7e^{6Q}$（凸）、幂函数 $g=5\times10^9Q^4$（凸）、对数渐进 $g=2\times10^9\ln(1+10Q)$（凹）。成本水平与边际曲率均不同，比较其最优解时不能把差异全归因于“凸/凹”；单个成本项凸也不保证联合优化凸。题目**建议** $C=10^{19},10^{22},10^{24}$ FLOPs，并允许自选其他档位，但硬要求是至少三个不同量级；本项目自主采用 $10^{19}$ 至 $10^{25}$ 七档并单列上述三点。$L_{ctx}^{crit}=6/\eta=30000$ token，注意力/训练成本比恒为 $\eta L_{ctx}/6$，在固定 $L_{ctx}$ 下与 $C,N,D$ 无关。C7 五档中 8192 在临界值以下，32768 在其以上；30000 不是 C7 实测档位。成本交叉并不自动构成预算驱动的最优策略转移。

对固定 $N,Q,\mathbf p^*$，$\partial L/\partial D=-m_*\beta T_D/D<0$，故在无额外 $D$ 上限的本模型内预算用尽。令 $K=6+\eta L_{ctx}$、$\Delta g=g(Q)-g(Q_0)\ge0$，由

$$D=\frac{C}{KN+\Delta g}$$

降至 $(\log_{10}N,Q)$ 的**二维有界**优化，仍须满足 $Q_0\le Q\le1$。固定 $Q$ 且令 $\Delta g=0$ 的解析对照为

$$N^*=\left[\frac{\alpha A Q^{-\kappa_N}}{\beta B Q^{-\kappa_D}}\right]^{1/(\alpha+\beta)}\left(\frac C K\right)^{\beta/(\alpha+\beta)},\qquad D^*=\frac{C}{KN^*}.$$

式中 $m_*$ 与地板因对固定 $Q$ 的规模求导而抵消；其值仍影响不同 $Q$ 之间的最优选择。由上式得 $D^*/N^*\propto(C/K)^{(\alpha-\beta)/(\alpha+\beta)}Q^{2(\kappa_N-\kappa_D)/(\alpha+\beta)}$；这是**无提质开销对照**，真实 $\Delta g>0$ 情景的比值及预算斜率须由数值最优解计算。当前参数下的两个指数约为 $0.09677$ 和 $0.42065$，不能据此直接预测提质区间的斜率。

固定 $Q$ 的内层规模解可继续用 $\log N$ 黄金分割，但须验证搜索边界未限制最优点。外层须比较 $Q_0$、$1$ 与可能的多个内点局部极小值；保留独立粗网格核对，不能仅以一次局部细化宣称全局最优。搜索所设的 $N$ 界仅为数值界，不能被误称为题目给出的模型规模限制。$Q_0\ge1-10^{-10}$ 时只有唯一质量状态，不可进入临界预算搜索。线性质量形状仅为对照：没有经 Q2 冻结的高精度参数接口时，不得拼接旧 Q3 常数充作同口径对照；P2 的 `nofloor_sensitivity` 必须使用其**单独重估**的 $\kappa_N,\kappa_D,k_0$ 与共享的 B1 基线参数，不得只把主式 $k_0$ 置零。

## 3. 结构性转移与敏感性

本项目把结构性转移操作化为**全局最优解**的质量约束活跃状态变化：`LOWER`（$Q^*=Q_0$）、`INTERIOR`、`UPPER`（$Q^*=1$）。这是为落实题干“最优策略发生质的变化”所作的数学定义，不是题目给定的唯一判据。离开下界与到达上界是两个不同的临界事件；如两个内点局部最小分支交换全局最优地位，即使仍同属 `INTERIOR`，也单列为“全局分支切换”。须注明扫描的预算区间、离散化精度和边界分类容差；若全局解并列，不得强行给单一状态。对于固定 $Q$ 的规模最优解，令 $S=KN+\Delta g$，剖面目标的质量导数及边际比为

$$F_Q=-k_0-\frac{m_*}{Q}(\kappa_NT_N+\kappa_DT_D)+\frac{m_*\beta T_Dg'(Q)}{S},$$

$$\Phi(C;Q)=\frac{\left[k_0+\frac{m_*}{Q}(\kappa_NT_N+\kappa_DT_D)\right]S}{m_*\beta T_Dg'(Q)}.$$

这里 $N,D$ 均在该**固定 $Q$** 下优化，不能代入其他质量点的全局规模解。内层解光滑且未触及搜索边界时，$\Phi(C;Q_0)\le1$、内点 $\Phi(C;Q)=1$、$\Phi(C;1)\ge1$ 分别是相应状态的**局部一阶必要条件**。$\Phi=1$ 根不是全局状态切换的充分条件：若局部最小分支竞争，全局切换发生在分支目标值相等处。求解时须核对剖面曲线及端点，局部根与全局临界点分别输出；二分只用于已括根且已检查单次切换的区间。

提质份额 $s_Q$ 的局部峰值和 $d\ln(D^*/N^*)/d\ln C$ 相对无提质成本基线的偏离是辅助口径，不得与两个全局临界点混称同一事件。旧“差小于 0.5 dex”仅可作为预设描述容差，不是不同事件必须一致的验收阈值。$Q_0=1$ 的配置仅有 $Q=1$，质量状态记 `NO_QUALITY_RANGE`，临界预算使用 JSON `null`；搜索区间未括根返回 `NOT_BRACKETED` 和 `null`，不得返回上界 26。发现多次切换或多根时分别记录，不能强行给出单一 $C_{crit}$。

敏感性至少包括三类 $g$、C7 五档、$\eta=10^{-4},2\times10^{-4},3\times10^{-4}$、P2 参数重抽样、P2 主/锚点两种质量映射、P1 域质量与配比的不确定性，以及固定配比乘子 `m=1`、Q2 的 `H_tot` 和 P2 无地板参数对照。其中题设固定 $\eta=2\times10^{-4}$，另两值只是**本项目扰动情景**，不能写成赛题给定系数。`H_tot` 在固定 $\mathbf p^*$ 时对完整基线 Loss 乘一个与 $N,D,Q$ 无关的正常数，因此其最优 $N,D,Q$ 与 `m=1` 对照相同，最优 Loss 的数值按该常数缩放；联立 $\mathbf p$ 时才需要重新优化，且仍属探索性。Q2 将 `H_red/H_tot` 称为配比效应假设的下/上界，不能把二者的数值结果说成独立真实验证。当前 P2 bootstrap 为 300 组、六列 `E,A,B,kappa_N,kappa_D,k0`，$\alpha,\beta$ 和 $m_*$ 固定；其区间仅是条件参数区间。P1 的固定 $\mathbf p^*$ 重抽与重选 $\mathbf p^*$ 是不同不确定性来源，应分开报告。若未传播 P1 和映射误差，不得称全链条不确定性；若某项接口不可用，要明确标记为未完成，不用旧结果填补。
