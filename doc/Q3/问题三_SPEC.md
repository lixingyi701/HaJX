## 1. 目标与冻结输入

给定总预算 $C$（FLOPs）和外生上下文长度 $L_{ctx}$（token），在 $N$（参数绝对个数）、$D$（训练 token 绝对个数）、$Q\in(0,1]$（B 侧无量纲质量）之间最小化验证 Loss。$C$ 输入和计算均用绝对 FLOPs，不能把附件的 $C_{\rm FLOPs\_1e21}$ 数值直接代入；Q2 已把 `N_params_B`、`D_tokens_B` 的十亿单位转换为绝对量。主方案固定 P1 在 A4 训练信赖域内选出的 17 域推荐配比 $\mathbf p^*$，这是赛题允许的建模选择；**不是**配比与规模精确可分离的定理。联立配比仅作探索性敏感性，不得称已验证的四变量主律。联立时的配比硬约束只有单纯形 $p_i\ge 0,\sum_i p_i=1$。若再把搜索限制在 P1 训练信赖域内，则与固定 $\mathbf p^*$ 一样，属于防止配比通道外推的建模选择，不是赛题硬约束。

本问按**单次训练的静态预算情景**建模；题干未给训练起止日期、逐期预算、地域或特定行业范围，也没有规定 GPU 数、工期、显存、碳排放、部署推理、硬件采购、通信拓扑或电费等额外目标/约束，不能把它们写作赛题硬要求。最小化验证 Loss 是结合全文标度律与问题二输出确定的目标口径；不把尚未建立 Loss–Benchmark 桥接的得分当作同一目标。$L_{ctx}$ 是情景输入，不作为可由优化器自由选择的变量。连续 $N,D$ 和 $Q\ge Q_0$ 是本方案为解析求解与“质量提升”设定的**建模假设**；若需要可落地的离散架构、数据量或供应上限，题干未给，需要补数据后重算，不能以搜索边界冒充物理约束。

## 2. 目标函数、成本与求解

主目标固定 $\mathbf p^*$ 后**完整读取 P2 的幂次 M4+质量地板式**。令 $T_N=AN^{-\alpha}Q^{-\kappa_N}$、$T_D=BD^{-\beta}Q^{-\kappa_D}$，并按 P2 `p_channel` 计算

$$m_*=\exp\{s_{\rm red}\tilde\varphi(\mathbf p^*)\}>0,\qquad
L=E+k_0(1-Q)+m_*(T_N+T_D).$$

当前接口的 `s_red_main=1.4996207320`、`phi_tilde_pstar=-0.0710422374` 给出 $m_*\approx0.8989423$。乘子只作用于两项随规模变化的损失，不作用于 $E$ 或地板；参考点是 P2 的 $\mathbf p_{ref}=\mathbf p_{train\_mean}$，**不是** $\mathbf p^*$。为保持与完整 P2 公式一致，主情景保留 $m_*$；若做“忽略配比效应”对照，须单独标记 `m=1`，不得混进主情景。P2 把跨规模配比通道标为 `exploratory`，故含 $m_*$ 的 Q3 结论须报告这一条件性来源，并比较 `m=1`；不能称配比效应已获得独立真实验证。系数 $E,A,\alpha,B,\beta,\kappa_N,\kappa_D,k_0$ 全部读取 P2，不在 Q3 再拟合。

算力约束为

$$6ND+D[g(Q)-g(Q_0)]_++\eta NDL_{ctx}\le C,\quad Q_0\le Q\le1,\quad\eta=2\times10^{-4}.$$

必须比较题目附录 B 三类成本：指数 $g=10^7e^{6Q}$（凸）、幂函数 $g=5\times10^9Q^4$（凸）、对数渐进 $g=2\times10^9\ln(1+10Q)$（凹）。成本水平与边际曲率均不同，比较其最优解时不能把差异全归因于“凸/凹”；单个成本项凸也不保证联合优化凸。题目**建议** $C=10^{19},10^{22},10^{24}$ FLOPs，并允许自选其他档位，但硬要求是至少三个不同量级；本项目自主采用 $10^{19}$ 至 $10^{25}$ 七档并单列上述三点。$L_{ctx}^{crit}=6/\eta=30000$ token，注意力/训练成本比恒为 $\eta L_{ctx}/6$，在固定 $L_{ctx}$ 下与 $C,N,D$ 无关。C7 五档中 8192 在临界值以下，32768 在其以上；30000 不是 C7 实测档位。成本交叉并不自动构成预算驱动的最优策略转移。

对固定 $N,Q,\mathbf p^*$，$\partial L/\partial D=-m_*\beta T_D/D<0$，故在无额外 $D$ 上限的本模型内预算用尽。在 $Q\ge Q_0$ 时，把正部写成 $\Delta g=g(Q)-g(Q_0)$ 还要求所用 $g$ 在 $[Q_0,1]$ 上不减。附录 B 的指数、四次幂和对数在 $(0,1]$ 上的导数分别为 $6\times 10^7 e^{6Q}$、$2\times 10^{10}Q^3$ 和 $2\times 10^{10}/(1+10Q)$，三者均严格为正，因此在 $[Q_0,1]$ 上严格递增，正部可以去掉。这是这三类给定函数的性质；更换 $g$ 后若单调性不再成立，必须保留正部，不得沿用下面的降维。令 $K=6+\eta L_{ctx}$、$\Delta g=g(Q)-g(Q_0)$，由

$$D=\frac{C}{KN+\Delta g}$$

降至 $(\log_{10}N,Q)$ 的**二维有界**优化，仍须满足 $Q_0\le Q\le1$。固定 $Q$ 且令 $\Delta g=0$ 的解析对照为

$$N^*=\left[\frac{\alpha A Q^{-\kappa_N}}{\beta B Q^{-\kappa_D}}\right]^{1/(\alpha+\beta)}\left(\frac C K\right)^{\beta/(\alpha+\beta)},\qquad D^*=\frac{C}{KN^*}.$$

式中 $m_*$ 与地板因对固定 $Q$ 的规模求导而抵消；其值仍影响不同 $Q$ 之间的最优选择。由上式得 $D^*/N^*\propto(C/K)^{(\alpha-\beta)/(\alpha+\beta)}Q^{2(\kappa_N-\kappa_D)/(\alpha+\beta)}$；这是**无提质开销对照**，真实 $\Delta g>0$ 情景的比值及预算斜率须由数值最优解计算。当前参数下的两个指数约为 $0.09677$ 和 $0.42065$，不能据此直接预测提质区间的斜率。

固定 $Q$ 的内层规模解可继续用 $\log N$ 黄金分割，但须验证搜索边界未限制最优点。外层须比较 $Q_0$、$1$ 与可能的多个内点局部极小值；保留独立粗网格核对，不能仅以一次局部细化宣称全局最优。剖面黄金分割是主求解器。§4 点名的关键 18 组还须用另一类有约束求解器核对；该核对用于验收，不替换主求解器。搜索所设的 $N$ 界仅为数值界，不能被误称为题目给出的模型规模限制。$Q_0\ge1-10^{-10}$ 时只有唯一质量状态，不可进入临界预算搜索。线性质量形状仅为对照：没有经 Q2 冻结的高精度参数接口时，不得拼接旧 Q3 常数充作同口径对照；P2 的 `nofloor_sensitivity` 必须使用其**单独重估**的 $\kappa_N,\kappa_D,k_0$ 与共享的 B1 基线参数，不得只把主式 $k_0$ 置零。

## 3. 结构性转移与敏感性

本项目把结构性转移操作化为**全局最优解**的质量约束活跃状态变化：`LOWER`（$Q^*=Q_0$）、`INTERIOR`、`UPPER`（$Q^*=1$）。这是为落实题干“最优策略发生质的变化”所作的数学定义，不是题目给定的唯一判据。离开下界与到达上界是两个不同的临界事件。$Q^*(C)$ 连续离开 $Q_0$，或连续到达 $1$，各计一次转移；判定依据是状态标签改变，包含平滑通过边界的情形。是否离开边界以分类容差为准：$Q^*$ 相对 $Q_0$ 或 $1$ 的偏离不超过容差时，仍记为相应边界状态，不计转移。如两个内点局部最小分支交换全局最优地位，即使仍同属 `INTERIOR`，也单列为“全局分支切换”。须注明扫描的预算区间、离散化精度和边界分类容差。扫描区间内全局状态没有变化时，记 `NOT_IDENTIFIED`，临界预算为 JSON `null`，并写明“在所分析预算区间内未识别到”。`NOT_BRACKETED` 只用于端点已经显示状态变化、但根未被括住的情形，此时同样不得编造临界点。全局解并列时，不得给出单一状态，并须把并列集合写入 `P3_structural_transition.json`：每个成员至少包含 $N,D,Q,L$、状态标签，以及与当前最优 Loss 的差。容差内目标值相同而状态不同的解，按并列处理。

对于固定 $Q$ 的规模最优解，令 $S=KN+\Delta g$，剖面目标的质量导数及边际比为

$$F_Q=-k_0-\frac{m_*}{Q}(\kappa_NT_N+\kappa_DT_D)+\frac{m_*\beta T_Dg'(Q)}{S},$$

$$\Phi(C;Q)=\frac{\left[k_0+\frac{m_*}{Q}(\kappa_NT_N+\kappa_DT_D)\right]S}{m_*\beta T_Dg'(Q)}.$$

这里 $N,D$ 均在该**固定 $Q$** 下优化，不能代入其他质量点的全局规模解。内层解光滑且未触及搜索边界时，$\Phi(C;Q_0)\le1$、内点 $\Phi(C;Q)=1$、$\Phi(C;1)\ge1$ 分别是相应状态的**局部一阶必要条件**。$\Phi=1$ 根不是全局状态切换的充分条件：若局部最小分支竞争，全局切换发生在分支目标值相等处。求解时须核对剖面曲线及端点，局部根与全局临界点分别输出；二分只用于已括根且已检查单次切换的区间。

提质份额 $s_Q$ 的局部峰值和 $d\ln(D^*/N^*)/d\ln C$ 相对无提质成本基线的偏离是辅助口径，不得与两个全局临界点混称同一事件。旧“差小于 0.5 dex”仅可作为预设描述容差，不是不同事件必须一致的验收阈值。$Q_0=1$ 的配置仅有 $Q=1$，质量状态记 `NO_QUALITY_RANGE`，临界预算使用 JSON `null`。扫描区间内没有状态变化时返回 `NOT_IDENTIFIED` 和 `null`；端点已显示变化但未括根时返回 `NOT_BRACKETED` 和 `null`。两种情形都不得返回上界 26，也不得编造临界点。发现多次切换或多根时分别记录，不能强行给出单一 $C_{crit}$。

敏感性至少包括三类 $g$、C7 五档、$\eta=10^{-4},2\times10^{-4},3\times10^{-4}$、P2 参数重抽样、P2 主/锚点两种质量映射、P1 域质量与配比的不确定性，以及固定配比乘子 `m=1`、Q2 的 `H_tot` 和 P2 无地板参数对照。其中题设固定 $\eta=2\times10^{-4}$，另两值只是**本项目扰动情景**，不能写成赛题给定系数。`H_tot` 在固定 $\mathbf p^*$ 时对完整基线 Loss 乘一个与 $N,D,Q$ 无关的正常数，因此其最优 $N,D,Q$ 与 `m=1` 对照相同，最优 Loss 的数值按该常数缩放；联立 $\mathbf p$ 时才需要重新优化，且仍属探索性。Q2 将 `H_red/H_tot` 称为配比效应假设的下/上界，不能把二者的数值结果说成独立真实验证。当前 P2 bootstrap 为 300 组、六列 `E,A,B,kappa_N,kappa_D,k0`，$\alpha,\beta$ 和 $m_*$ 固定；其区间仅是条件参数区间。P1 的固定 $\mathbf p^*$ 重抽与重选 $\mathbf p^*$ 是不同不确定性来源，应分开报告。若未传播 P1 和映射误差，不得称全链条不确定性；若某项接口不可用，要明确标记为未完成，不用旧结果填补。

验收阈值：预算超限相对误差不大于 $10^{-9}$、三项份额和误差小于 $10^{-9}$；$N,D>0$，$Q\in[Q_0,1]$；在已证明预算饱和的主模型下，预算使用率与 1 之差小于 $10^{-9}$；无提质开销时闭式 $N^*$ 相对误差小于 $10^{-5}$。**关键 18 组**专指主口径 $Q_0(\mathbf p^*)$、三种 $g$、题面建议预算 $10^{19},10^{22},10^{24}$，以及临界上下文两侧的 C7 档 $8192$ 与 $32768$。它是求解器互验子集。主网格仍须对每种 $g$、七档预算和 C7 五档给出最优配置；210 组不因这 18 组而缩减。互验至少包括剖面黄金分割、独立粗网格，以及另一类有约束光滑求解器（SLSQP 或多起点信赖域）。后一类作用在 $(\log N,Q)$ 上，或直接处理含预算不等式的 $(N,D,Q)$；它必须换算法，不能用同一黄金分割的更密网格代替。18 组上，剖面解的 Loss 不劣于另外两类，差不超过 $2\times10^{-5}$。状态不一致时写入 `tied_set`，不保留单一标签。在 $L_{ctx}=2048$ 上对两个 $Q_0$ 做的粗网格对照可以保留为诊断，但不能充当这 18 组。对下界、内点、上界代表场景，以有限差分核对**含 $m_*$ 与地板**的剖面导数/$\Phi$，同时检查内层搜索边界、外层多个候选极小值及全局状态判定。$Q_0=1$、`NOT_IDENTIFIED` 与 `NOT_BRACKETED` 须专门验收，不得用旧临界预算替代；临界点若在扫描区间外，只能报告相应状态和区间。`H_tot` 固定配比解须与 `m=1` 配置一致，Loss 按常数缩放。主/敏感性结果必须晚于所用输入，manifest 哈希匹配。留出误差只继承 Q2 的半合成插值检验；蒙特卡洛重复优化只验证模型内稳定性，不能表述为真实训练验证。输出字段、单位、来源、证据等级和下游 Q4 的读取说明须写入 `doc/Q3/问题三结果说明.md`；该文件在按本版重跑并核验接口后建立，未建立前不得用旧 P3 数字填写。报告数字只可由当前接口复核。

联立配比的探索性对照如需保留，硬约束只有单纯形 $p_i\ge 0,\sum_i p_i=1$，并按 $Q_0(\mathbf p)=\sum_i p_iQ_i$ 同时更新质量下界和 $g(Q_0)$。本方案仍把搜索限制在 P1 训练信赖域内；这一限制与固定 $\mathbf p^*$ 一样，是防止配比通道外推的建模选择，须在对照说明中标明，不能写成赛题硬约束。须从稳定的 P1/P2 接口重建**同一**配比乘子，不能只优化乘子，也不能把配比通道用到信赖域之外。联立结果写入单独表格，每行记录完整 $\mathbf p$ 或可复核的配比标识，以及已启用信赖域。未记录 $\mathbf p$ 的联立行不得并入 `P3_optimal_config.csv`。现有 `q3_03_mixture_joint.py` 依赖 P1 内部 GBDT pickle、把乘子作用于整个 Loss，且比较 2 个基线与 4000 个 Dirichlet 样本共 4002 个候选，只能视为旧探索结果，不能称本版四变量主优化或严格可分离性证明。
