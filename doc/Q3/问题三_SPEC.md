## 1. 目标与冻结输入

给定总 FLOPs 预算 $C$ 和外生上下文长度 $L_{ctx}$，在 $N$（参数绝对个数）、$D$（token 绝对个数）、$Q\in(0,1]$ 之间求最小验证 Loss。主方案固定 P1 推荐配比 $\mathbf p^*$；联立配比只有在 Q2 发布经合规训练与留出检验的四变量接口后，才可升为主方案。

| 输入 | 标准路径 | 要求 |
| --- | --- | --- |
| P1 质量与配比 | `src/outputs_q1/interface/P1_Q_domain.csv`、`P1_p_star.csv`、`P1_summary.json` | 17 域按名称连接，份额和为 1；不得按行序连接。 |
| P2 标度律 | `src/outputs_q2/interface/P2_scaling_law.json`、`P2_bootstrap.npz` | 校验公式版本、`q_mapping`、参数列和证据状态；不在 Q3 重新拟合。 |
| C7 上下文 | `附件/C_efficiency_evolution/model_architecture_metadata.csv` | 从 `max_position_embeddings` 读取并核对五档 $2048,4096,8192,32768,131072$。 |

主映射 $Q_B=Q_A$，$Q_0=\sum_i p_i^*Q_i=0.6608889991$，须与 P1/P2 两个接口互验。`pile_cc` 的 $Q_{final}=0.6761349048$ 仅是**同一映射下的单域对照**，不是第二种质量映射。P2 的推荐配比锚点敏感性映射给出 $Q_0=1$，属于“无可用提质区间”；部分单域会越过 B 侧支持域，须报越界，不得静默截断。所有上游半合成与外推标记原样继承。

## 2. 目标函数、成本与求解

主目标采用 P2 当前线性质量耦合形式：

$$L=E+AN^{-\alpha}[1+\kappa_N(1-Q)]+BD^{-\beta}[1+\kappa_D(1-Q)]+k_0(1-Q).$$

系数全部从 P2 接口读取，配比固定时不再乘配比项。算力约束为

$$6ND+D[g(Q)-g(Q_0)]_++\eta NDL_{ctx}\le C,\quad Q_0\le Q\le1,\quad\eta=2\times10^{-4}.$$

必须比较题目附录 B 三类成本：指数 $g=10^7e^{6Q}$（凸）、幂函数 $g=5\times10^9Q^4$（凸）、对数渐进 $g=2\times10^9\ln(1+10Q)$（凹）。不可统称三者均凸。$C$ 至少覆盖 $10^{19},10^{22},10^{24}$，本项目主网格为 $10^{19}$ 至 $10^{25}$ 七档。$L_{ctx}^{crit}=6/\eta=30000$，注意力/训练成本比为 $\eta L_{ctx}/6$。

对固定 $N,Q$，Loss 随 $D$ 递减，故预算用尽。令 $\kappa=6+\eta L_{ctx}$、$\Delta g=g(Q)-g(Q_0)$，由

$$D=\frac{C}{\kappa N+\Delta g}$$

降至 $(\log_{10}N,Q)$ 优化。$\Delta g=0$ 时的闭式对照为

$$N^*=\left[\frac{\alpha A h_N(Q)}{\beta B h_D(Q)}\right]^{1/(\alpha+\beta)}\left(\frac C\kappa\right)^{\beta/(\alpha+\beta)},\quad h_X=1+\kappa_X(1-Q).$$

求解器须显式比较 $Q_0$、$1$ 两端，核查 $N$ 搜索边界、预算残差、三项份额之和，并以闭式解及独立粗网格互验。$Q_0\ge1-10^{-10}$ 时只有唯一质量状态，不可进入临界预算搜索。

## 3. 结构性转移与敏感性

主定义按质量约束活跃状态：`LOWER`（$Q^*=Q_0$）、`INTERIOR`、`UPPER`（$Q^*=1$）。离开下界与到达上界是两个临界点。解析边际比

$$\Phi(C;Q)=\frac{(\kappa_NAN^{-\alpha}+\kappa_DBD^{-\beta}+k_0)(\kappa N+\Delta g)}{\beta BD^{-\beta}g'(Q)}$$

应与数值状态切换核对。提质份额 $s_Q$ 局部峰值和 $d\ln(D^*/N^*)/d\ln C$ 相对基线的偏离是辅助口径；“差小于 0.5 dex”为预设分析容差。若 $Q_0=1$ 返回 `NO_QUALITY_RANGE` 和 `null`；搜索区间未括根返回 `NOT_BRACKETED` 和 `null`，不得返回上界 26。本文代码已加入此边界处理，产物仍需重生并验收。

敏感性至少包括三类 $g$、C7 五档、$\eta=10^{-4},2\times10^{-4},3\times10^{-4}$、P2 参数重抽样、P2 两种质量映射，以及 P1 域质量/配比的不确定性。当前 P2 bootstrap 固定 $\alpha,\beta$，所得区间是条件参数区间。若未传播 P1 和映射误差，不得称全链条不确定性。

## 4. 输出与验收

输出位于 `src/outputs_q3/`：

| 文件 | 最低字段或用途 |
| --- | --- |
| `interface/P3_optimal_config.csv` | 每组 $C,g,L_{ctx},Q_0$ 的 $N,D,Q,L$、三项成本份额、状态和预算残差。 |
| `interface/P3_sensitivity_Lctx.csv` | 相对 2048 档的数值/解析比例、$\kappa$、注意力/训练比和临界状态。 |
| `interface/P3_structural_transition.json` | 两个临界点、`status`、分析区间、条件区间；缺失值使用 JSON `null`。 |
| `interface/P3_run_manifest.json` | 运行时间、Git 提交、P1/P2/C7 输入 SHA-256、映射版本、求解边界、随机种子。 |
| `tables/T1`–`T3`、`figures/F1`–`F8` | 与接口同轮生成，图表标题自带结论。 |

验收阈值：预算相对残差及份额和误差均小于 $10^{-9}$；$N,D>0$，$Q\in[Q_0,1]$；无提质开销时闭式 $N^*$ 相对误差小于 $10^{-5}$；关键 18 组求解 Loss 不劣于独立粗网格，差不超过 $2\times10^{-5}$。重跑结果必须晚于输入，manifest 哈希匹配。输出字段、单位、来源与下游读取说明须写入 `doc/Q3/问题三结果说明.md`。报告数值只可由当前接口复核。

`q3_03_mixture_joint.py` 当前依赖 P1 内部 GBDT pickle，乘子 $m(\mathbf p)$ 也不是 Q2 已标定的 $s(N)$ 通道；只能作为探索性附录，不能称四变量联合律或正式主优化。脚本实际比较 2 个基线与 4000 个 Dirichlet 样本，共 4002 个候选。
