## 2. 主接口

`P3_optimal_config.csv` 共 210 行：3 种 \(g\) × 预算 \(10^{19}\) 至 \(10^{25}\) × C7 五档 × 主口径与 `pile_cc` 单域对照。`pile_cc` 只替换 \(Q_0\)，不是第二种质量映射。主方案各行共用 manifest 中的 `p_star_eqweight`，本表不重复 17 维配比。

| 字段 | 单位与含义 |
| --- | --- |
| `C` | 预算，绝对 FLOPs |
| `N_opt`,`D_opt` | 参数个数、训练 token 数，均为绝对量 |
| `Q_opt` | 无量纲质量，范围 \([Q_0,1]\) |
| `L_opt` | 预测验证 Loss |
| `D_over_N` | \(D^*/N^*\)，无量纲 |
| `C_train`,`C_attn`,`C_quality` | 三项成本，绝对 FLOPs |
| `total_cost`,`residual` | 实际总消耗与剩余预算，绝对 FLOPs |
| `share_*` | 三项成本除以 `total_cost` |
| `budget_use` | `total_cost/C` |
| `state` | `LOWER` / `INTERIOR` / `UPPER`；并列时为 `TIED` |
| `m_star` | 主情景配比乘子 |

本轮 210 行的预算相对残差最大约 \(4\times10^{-16}\)，三项份额和的误差最大约 \(3\times10^{-16}\)。份额分母是实际总消耗。

`P3_sensitivity_Lctx.csv` 给出相对 2048 档的数值规模比、无提质解析比、\(K=6+\eta L_{ctx}\)、注意力/训练比，以及离开 \(Q_0\) 和到达 \(1\) 的临界预算。解析比只在无提质开销时与数值解对照；本轮该相对差最大约 \(4.8\times10^{-8}\)。

`P3_structural_transition.json` 的分析区间是 \(\log_{10}C\in[17,26]\)。`phi_local_root` 是 \(\Phi=1\) 的局部根。`scan_events` 记录全局状态变化；`smooth=true` 表示该步 \(Q^*\) 连续通过边界。`tied_set` 本轮为空。无数值的临界预算在表内为缺失，不写成 26。

`P3_run_manifest.json` 固定 `P1_p_star.csv` 的路径、列名、17 域顺序和 SHA-256，并记录 P1/P2 输入哈希与 F1–F3 的哈希。

## 3. 下游 Q4 怎么读

当前 Q4 独立流程不读取本接口，数值资源链仍是 `DEFERRED_Q3`。若以后读取：

- 只用 `Q0口径=主口径p*加权` 的行作为主配置；`pile_cc` 行不能当作另一种映射。
- \(N,D,C\) 用绝对量，不要把 `log10C` 代回成本式。
- 损失已含 \(m_*\) 和地板。不要再用 \(m=1\) 或把 \(k_0\) 置零后的旧式 Loss 与这里的 `L_opt` 直接相减。
- `state` 与 `scan_events` 是预算转移；`L_ctx_crit=30000` 是注意力与训练成本的交点，二者不是同一事件。

## 4. 本轮已核对的数量级

主口径、\(L_{ctx}=2048\)：指数型在 \(\log_{10}C\approx19.059\) 平滑离开 \(Q_0\)，约 \(20.355\) 平滑到达 \(1\)；幂函数型约为 \(19.529\) 与 \(20.106\)。对数型的离开与到达同为 \(\log_{10}C\approx18.579\)，扫描上一个步长内 \(Q^*\) 从 \(Q_0\) 变为 \(1\)，JSON 记 `coarse_step=true`。该情形的 \(\Phi\) 局部根约 \(18.904\)，与全局离开点相差约 \(0.32\) dex，不能当成同一个临界预算。

关键 18 组（三种 \(g\)，预算 \(10^{19},10^{22},10^{24}\)，上下文 \(8192,32768\)）上，剖面解的 Loss 不高于粗网格，也不高于多起点 SLSQP，状态一致。无提质闭式 \(N^*\) 的最大相对误差约 \(2.1\times10^{-7}\)。固定配比下，`H_tot` 与 `m=1` 的配置相对差约 \(1.5\times10^{-7}\)，Loss 按 \(\exp(s_{\rm train}\tilde\varphi(\mathbf p^*))\) 缩放。

这些是模型内的优化与数值核对。留出误差只继承 Q2 的半合成插值检验，不能写成真实训练验证。
