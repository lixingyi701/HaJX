\subsection{灵敏度与稳健性分析}

\textbf{问题一。}冲突阈值 $\tau$ 在 $[0.6,0.85]$ 内变化时，冲突率在 $12\%$–$35\%$ 之间连续变化，域排序与主冲突类型不变。Huber 降权与调和平均两种消解规则下，域级质量排序的 Spearman 相关 $>0.95$。评价权重取等权与 pile\_cc 单域两个口径时，$\bp^*$ 的头部域一致，只是集中度不同。

\textbf{问题二。}去掉地板后，质量 $+0.1$ 在 $N=10^{11}$、$D=3\times10^{11}$ 处的等效参数倍数由约 $3.0$ 降到约 $1.5$，方向仍是模型越大、同样的提质越难用参数补回。$\kappa_N,k_0$ 的 95\% 区间为 $[0.126,0.157]$、$[0.201,0.255]$，且 $P(\kappa_N>\kappa_D)=P(k_0>0)=1$；$\kappa_D$ 的区间 $[0.000,0.041]$ 含 $0$。$C=10^{19}$ 时提质是否划算取决于成本函数，$C\ge10^{20}$ 后三种 $g(Q)$ 都是提质更划算。高预算端的倍数依赖半合成地板的外推。

\textbf{问题三。}主口径 $Q_0=0.6609$ 下，指数型 $C_{\mathrm{crit}}$ 的 bootstrap 90\% 区间为 $[18.85,18.90]$。$Q_0$ 相图（图~\ref{fig:q3phase}）表明：$Q_0$ 越低，$C_{\mathrm{crit}}$ 越小。指数型存在约 $1.29\dex$ 的部分提质区间，对数型仍是跳变。

\textbf{问题四。}C6 中 Medium 层的权重取 $0.25$–$1.0$ 时，$S(1.85)$ 的变化不到 $0.4$ 分。C3 历史点的权重取 $0.2$ 与 $1.0$ 时，技术进步率分别为 $0.50$ 与 $0.21\dex/\mathrm{yr}$，因此只作敏感性分析。分解换用 2024$\to$2025 与 2024.5$\to$2025.25 两个窗口，M1b 的技术占比为 $7.1\%$ 与 $8.2\%$，M2 为 $30.6\%$ 与 $24.3\%$，“规模为主”的定性结论不变。

\section{模型的评价与推广}

\subsection{模型的优点}

(1) \textbf{证据分层，接口贯通。}半合成与外推数据只用于形式选择和稳健性讨论，没有混入主结论。四问之间通过接口文件衔接，广义标度律全文只估计一次，下游各问直接消费，口径前后一致。

(2) \textbf{形式有可检验的对照。}冲突阈值取最大曲率点，质量项在 26 个候选中比较并报告留出误差，桥接形式由留一交叉验证决定，结构性转移由 KKT 活跃集定义。问题二的幂次主式是为有效规模解释而指定的，交叉验证更优的线性对照在正文中保留。

(3) \textbf{解析与数值互验。}四条命题、$L_{\mathrm{ctx}}^{\mathrm{crit}}$ 与 $\Phi(C)=1$ 判据都有闭式表达，并与数值解逐项对照，结论可解释。

(4) \textbf{直面误导信息。}冲突率、Loss–Benchmark 相关的符号、最优配置、是否提质等问题上，本文都用量化证据修正了《数据说明》中的误导性说法。

\subsection{模型的局限与改进方向}

(1) 11 个 inferred 域的质量分依赖校准函数（$R^2_{\mathrm{cv}}=0.31$），信息量有限；若能增补这些域的模型评分器信号，可显著收紧区间。

(2) 附件 B 的 B6–B8 为半合成数据，$\kappa_N,\kappa_D,k_0$ 的绝对数值不宜直接外推到真实训练体系，应用时以趋势与结构结论为主。

(3) 问题三中 $g(Q)$ 的形式与参数取自赛题附录 B，“角点解”与“对数型早两个数量级提质”对成本函数的形式敏感，本文已把三种形式并列给出。

(4) C6 的 High 层只有 7 点且全部位于底噪区，桥接的上升段依赖 Medium 层；问题四的结构口径与线性口径相差 32.8pp，是全文最大的不确定性来源。若能获得更多同验证集的 Loss–Benchmark 对，可以缩小这一分歧。

(5) 预测为情景条件预测，不包含新架构等离散突破。

\subsection{模型的推广}

“基线 + 质量修正”的标度律结构，以及“约束取等后解析消元”的降维方法，可推广到含多种数据处理成本（去重、合成数据、多模态对齐）的资源配置问题。“S 形桥接 + 连续时间项 + Shapley 分解”的框架也适用于其他存在能力饱和的技术演进分析。

\section{结论}

本文围绕“算力约束下如何配置资源以提升大模型能力”，建立了四个递进衔接的模型。

\textbf{问题一}建立了从 22 个异质信号到连续质量分的可复现管线，测得并消解了 $21.5\%$ 的指标冲突，用 clr 回归给出 17 域配比的迁移矩阵与最优配比（预测降损 $9.9\%$），并发现域级质量与训练边际价值近乎无关（$\rho=-0.06$）。

\textbf{问题二}建立了幂次广义标度律 $L=E+k_0(1-Q)+[AN^{-\alpha}Q^{-\kappa_N}+BD^{-\beta}Q^{-\kappa_D}]\exp(s_{\mathrm{red}}\tilde\varphi(\bp))$（$\kappa_N=0.142$，$\kappa_D=0.011$，$k_0=0.228$，$Q_0=0.6624$）。在参照点上质量弹性约为参数弹性的 $1.62$ 倍；质量提高 $0.1$ 在 $N=10^9$ 处须把参数扩大为原来的 $1.30$ 倍，在 $N=10^{11}$ 处约扩大为原来的 $3$ 倍。沿算力前沿，同样的提质所等价的算力倍数随预算上升。$C\ge10^{20}$ 后，三种提质成本下都是提质比扩参数更划算。地板来自半合成 B6，外推到高预算时按假设使用。

\textbf{问题三}把约束优化解析降维为二维无约束问题，以 KKT 活跃集的改变定义结构性转移，并用 $\Phi(C)=1$ 识别临界预算。主口径下，指数型、幂函数型、对数型离开 $Q_0$ 的 $\log_{10}C_{\mathrm{crit}}$ 为 $18.87/19.40/18.17$。指数型有约 $1.29\dex$ 的部分提质区间，对数型为跳变。上下文长度越过 $6/\eta=30000$ 后，注意力成本占主导，最优模型随之缩小。配比与规模决策近似可分离。

\textbf{问题四}用“标度律 + S 形桥接 + 时间技术项”的结构模型分解前沿增长：规模扩张是主导，非规模技术进步占 $13\%$–$23\%$（结构口径；线性口径的 $30\%$–$46\%$ 为上界参考）。在算力增速放缓至 $0.15\dex/\mathrm{yr}$ 的情景下，24 个月的 base 开源前沿中位数为 $44.1$，技术进步在增量中的占比升至 $77\%$。

四问共同说明，\textbf{数据质量与配比是与算力并列的一等资源}：小预算时应把算力用在规模上，跨过临界预算后应把质量提满；算力增长放缓时，能力增长将越来越依赖非规模技术进步。
