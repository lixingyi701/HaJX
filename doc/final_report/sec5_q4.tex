\subsection{问题四的模型建立与求解}
\label{sec:5.5}

问题四需要把 Benchmark 表现、训练规模和时间变化放到同一口径下，分析规模扩张与非规模因素的模型内贡献，并在算力增速放缓情景下讨论开放权重模型的能力变化。现有材料包含两条实现流程；预测已按 $T_0=2026.75$（现在）重新锚定并重跑，分解结果尚未按当前规范全部重跑。本节说明其可支持的范围与尚未通过的检验。

\subsubsection{模型建立}
\label{sec:5.5.1}

\paragraph{数据口径与样本边界}

主能力指标为 C1/C2 的 \texttt{Average}，由六项 Benchmark 维度等权汇总，量纲为 0--100 分。C2 在 C1 榜单上增加 Epoch 匹配信息，二者属于同一批榜单记录，不能互相作为独立验证。模型类型按榜单标签区分：\texttt{base} 包括 pretrained 与 continuously pretrained，\texttt{chat} 包括 chat 与 fine-tuned；merges、multimodal 与 other 不纳入这两类主回归。C2 的发布日用于模型时间轴；C1 的提交日用于 C8 月度汇总。两类日期回答不同问题，不能互换。

本问关注开放权重模型，但“权重可获得”与许可证允许的用途是两个字段。许可证未知或缺失时保留未知状态，不能仅凭模型出现在 Hub 推断其权重可下载或许可范围。现有 C2$\times$C4 面板尚未执行 Spec 要求的严格开放权重筛选和未知项审计，因此下文涉及该面板的结果应理解为\textbf{候选样本分析}，不能称为已验证的开放权重总体前沿。C2 与 C4 先按发布日期和组织匹配，再要求参数量差异小于 50\%；未匹配记录及缺失原因应在重跑时单列，现有 P4 产物没有提供完整的匹配质量审计。若训练 token 缺失，则由 $D=C/(6N)$ 反解的值是估算量而非观测量。代入 $C=6ND$ 时，$N$ 与 $D$ 使用绝对参数数和 token 数，$C$ 为 FLOPs。

C3 混合了不同评测口径，只作为标记清楚的时间趋势敏感性材料，不并入主面板，也不用于证明主模型的外部有效性。C5/C6 的 Loss 来源与验证集可比性分层使用；高可比样本不能单独支撑映射曲线的高分段。

\paragraph{C8 逐任务饱和度与去饱和分}

为减少已接近任务上限的维度对汇总分变化的压缩，先按叶子任务随机基线 $c_j$ 归一化得分
\[
\hat{s}_{j}=\max\left\{0,\frac{s_j-c_j}{1-c_j}\right\},
\]
再按 C1 提交日构造任务级累计 Top-5 前沿 $F_{t,j}$。去饱和分剔除判为饱和的任务，以起点剩余空间作为家族内权重，并令六个任务家族等权：
\[
S_{\mathrm{desat},t}=100\sum_j w_j\hat{s}_{j,t},\qquad
w_j\propto 1-F_{\mathrm{start},j}.
\]
该分数依赖任务集合、随机基线和起点选择，因而是对 \texttt{Average} 的敏感性口径，不是同尺度的独立真值。

\paragraph{Loss--Benchmark 桥接}

C6 的 Loss 与 Benchmark 得分按可比性分层后，用有界 S 形函数描述二者关系：
\[
S(L)=lo+\frac{hi-lo}{1+\exp\!\left[k(L-L_0)\right]},
\qquad 0\leq lo\leq hi\leq100,\quad k>0.
\]
High 层为同模型、同验证集记录，权重为 1；Medium 层的验证集不同但近似可比，权重为 0.5。主结果使用 C6，对 base/chat 和各评分维度分别拟合；C5 未并入该主拟合。既有 \texttt{P4\_bridge\_params.json} 中 \texttt{base|Average} 的参数为 $(lo,hi,k,L_0)=(8.626,21.572,46.119,2.070)$。该组对应 44 行；C6 整体分层为 High 7 行和 Medium 68 行。对同一批 C6 样本作留一检查时，S 形、线性与常数模型的 RMSE 分别为 8.079、8.283 和 9.514 分（\texttt{P4\_bridge\_params.json}）。误差差距有限，且留一检验没有跨来源独立样本，不能据此宣称 S 形映射已外部验证。High 层仅覆盖低分底噪区，主要约束下界；曲线上升段主要由 Medium 层决定。

\paragraph{规模与非规模因素的模型内分解}

每个面板观测把 C2 能力分与 C4 匹配配置连接，再使用问题二的标度律计算规模状态 $\hat L_i$。既有主模型 M1b 将损失的非线性映射与时间项相加：
\[
S_i=lo+\frac{amp}{1+\exp\!\left[k(\hat L_i-L_0)\right]}
+\tau(t_i-2023)+\varepsilon_i.
\]
其中 $amp$ 为映射振幅，$\tau$ 表示控制已计算规模状态后的年度时间关联。对照 M1c 把时间项写入等效年降损 $\delta$：
\[
S_i=lo+\frac{amp}{1+\exp\!\left[k(\hat L_i-\delta(t_i-2023)-L_0)\right]}+\varepsilon_i.
\]
其他比较包括效率前沿线性模型 M2、分位数回归 M3 和以 $\log_{10}C$ 为解释变量的 OLS。对两个端点状态 $(\hat L_0,t_0)$ 与 $(\hat L_1,t_1)$，采用两因素 Shapley 分配，按两种变化顺序的平均分配模型预测变化\cite{shapley}：
\[
\begin{aligned}
\Delta S_{\mathrm{scale}}={}&\tfrac12\{[f(\hat L_1,t_0)-f(\hat L_0,t_0)]
+[f(\hat L_1,t_1)-f(\hat L_0,t_1)]\},\\
\Delta S_{\mathrm{time}}={}&\tfrac12\{[f(\hat L_0,t_1)-f(\hat L_0,t_0)]
+[f(\hat L_1,t_1)-f(\hat L_1,t_0)]\},\\
\Delta S_{\mathrm{model}}={}&\Delta S_{\mathrm{scale}}+\Delta S_{\mathrm{time}}.
\end{aligned}
\]
技术份额定义为 $\Delta S_{\mathrm{time}}/\Delta S_{\mathrm{model}}$，不是对观测增量的占比。模型的时间项可能吸收数据质量、后训练、架构和样本构成变化；它是条件关联，不是已识别的技术因果效应。chat 的后训练增益另按同组织 base/chat 配对估计，也只作描述性关联。

\subsubsection{求解方法}
\label{sec:5.5.2}

既有主链按 \texttt{q4\_01\_c8\_parse.py}、\texttt{q4\_02\_saturation.py}、\texttt{q4\_03\_bridge.py}、\texttt{q4\_04\_decomp.py}、\texttt{q4\_05\_forecast.py} 的顺序运行，末尾由 \texttt{q4\_99\_check\_report.py} 检查接口和报告字段。C8 先按叶子任务解析，再与榜单模型匹配；C6 桥接以分层加权最小二乘估计，并用留一法比较函数形式。C2 与 C4 依发布日期、组织和参数量差异匹配；对未提供训练 token 的配置，按 $D=C/(6N)$ 反解时同时保留“估算”来源标记。

预测脚本以算力增长情景更新 $C$，在 $Q=1$、上下文长度 $L_{\rm ctx}=4096$ 的 P2 损失切片上计算规模损失变化，再锚定到既有前沿损失并经 M1b/M1c 映射为分数。该计算没有读取 P3 的最优配置接口，没有乘固定推荐配比的 $m(\bp^*)$，也没有检验四变量联合资源关系；因此它只是 Q2 标度律在 $Q=1$ 切片上的情景计算，不是当前 Q3 完整资源优化链的下游验证。项目核查还记录了 P2 的训练/留出边界尚未通过现行 Spec 验收，相关 P4 数值继承了这一上游限制。

需区分下列来源状态：第一，\texttt{src/outputs\_q4/} 中的预测接口（\texttt{P4\_frontier\_forecast.csv}、\texttt{T8\_*}、图 \texttt{F14}）已按 $T_0=2026.75$ 重跑，但分解表图（\texttt{P4\_decomposition.csv}、图 \texttt{F12/F13}）仍是代码及公共输入修订前生成的旧轮次结果；第二，\texttt{independent/} 中的脚本和来源项目报告尚未在本仓库运行。预测数字表示既定参数、样本和映射条件下的模型输出，不表示已复现全链或通过验收。

\paragraph{尚未关闭的验收项}

截至 2026-09-26，问题四的预测已按 $T_0=2026.75$（现在）重新锚定并重跑，但仍未通过全部验收。要形成现行 Spec 下可用的正文结果，至少需要：按可获得性与许可证分别执行并记录开放权重纳入规则；为每次分析保存一致的数据截止日、$T_0$、输入哈希和仅使用起点前信息的样本清单（前视冻结）；在修复后从原始附件重跑既有主链；独立运行补充链并将其视为代码实现对照而非独立数据验证；对 C6 到榜单映射的迁移误差单独校准和传播；按现行 P2/P3 接口重算，明确 $Q=1$ 与固定 $p^*$、$m(\bp^*)$ 的差别及 \texttt{DEFERRED\_Q3} 状态；最后验证预测对象究竟是当期新模型水平还是累计最高前沿，并据此检查区间单调性。此外，数据截止 2025-03 与预测起点 2026-09 之间存在约 1.5 年的数据缺口，该缺口的"现在"前沿状态只能靠模型外推。在这些检查完成前，本节中的预测仍属条件情景，不得表述为已验收的全链条前沿预测。
