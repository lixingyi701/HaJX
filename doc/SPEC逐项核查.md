## 问题一

已对齐题目的部分：

- A1/A2/A3 全量 51,230 / 17,523 / 203,752。
- 流式读取。
- 预处理参数只在 A1 上估计，并冻结到 A2/A3。
- 22 个字段展开为 25 列后再合成。
- 主分是 CRITIC 加权 Huber 中心，\(Q\in[0,1]\)。
- 域级用中位数，并给 bootstrap 区间。
- A4–A15 按 `index` 成对使用，1B 为 64 行。
- 单纯形用 \(10^{-4}\) 替换非正份额后再做 clr。
- 13 个验证域的 clr+Huber 是主模型，A6–A11 上同时报告绝对误差和 Spearman。
- A12/A14 标成训练集子集，A13/A15 标成幂律外推，并明确估算表上的排序反转没有观测支持。
- 7 个质量域到 17 个配方域用了 A16 的 direct / near_direct / inferred；c4 只在质量侧，inferred 域靠 A18 桥接。

这些都有理由，也有“不能当成准确率”的限制。

下面几项题目点了名，SPEC 里还没有闭合。

### 用原文检验评分是否可靠

题目要求用原始教材内容检验评分。现行做法是用 A1/A18 的规则特征去预测已经算好的 \(Q\)（五折 \(R^2=0.41\)），以及把抽样行号写入 `T3_manual_check_samples.csv`。SPEC 写明含原文的文件只在本地缓存、不作为已完成标注。这里没有高分/低分文本对照，也没有“高分文本在外部统计量上确实更好”的结论。桥接拟合的是 \(Q\) 自己，不能代替这项检验。

### 冲突消解后的综合评价模型

题目要求定义冲突、分析成因，并建立相应的综合评价模型。SPEC 把冲突放在主分之后：六来源分歧只作诊断，不回写 \(Q\)，还删除了 `T3_resolution_effect.csv`。成因分析是充实的（RPS 内部 Kendall \(W=0.140\)，A2/A3 上高分歧候选约 4.7%–5.0%，与 A1 同量级）。缺的是“考虑冲突”和“不考虑冲突”两套 \(Q\) 的排序对照作为主结果。实验性的 \(Q_{v2}\) 最接近这一要求，但 SPEC 声明它不进入 P1 接口。

### A2、A3 与抽样集的域级对照

现在只有 KS 检验 \(p=0.313/0.220\)，结论是未检出分布差异。SPEC 没有并列给出 arxiv、github 在 A1 与 A2/A3 上的均值、分位数和区间。第 3 节的域级表只含 A1。

### 四个没有 Loss 的训练域

`nih_exporter`、`enron_emails`、`europarl`、`philpapers` 没有验证 Loss。它们被留在 17 维 clr 里，但问题一 SPEC 没有写出“保留、合并还是只解释间接影响”，也没有合并敏感性。这一点只出现在数据字典的旧方案里，不能算现行 SPEC 已经说明。

### 方向表

适宜型点了词数、句数、平均词长和词熵，其余只写“正向保留、负向取负”。没有 22 个指标的方向与理由对照表。列表字段的压缩规则写在展开步骤里（ModernBERT 取期望分、`ad_en` 取无广告概率等），但没有单独标出哪 8 个是列表型。

### 尺度修正的证据等级

尺度修正把 A8/A9（60M）用作标定，只用 A10/A11 做独立检验。冻结模型在三个检验尺度上都评估过，这一点符合“先检验再修正”的写法。论文里不能把 60M 上修正后的误差说成样本外结果。SPEC 自己已经这么区分了。

### 文档内部不一致

- 文首写实现标准是 `final/code_q1/`，本仓库代码和产物在 `src/code_q1/`、`src/outputs_q1/`。
- §4.1 仍写配比边际为 dm_mathematics \(-0.156\)、enron_emails \(+0.146\)，问题二 v7.1 已改为 \(-0.147\)、\(+0.138\)。

## 问题二

这一问和附录 A 的对应关系是齐的。

- 只读 P1 接口，不读附件 A 原始文件。
- B1 的 1,176 行给出 \(E=1.6901\)，\(A=406.39\)，\(\alpha=0.34\)，\(B=410.59\)，\(\beta=0.28\)，RMSE \(1.51\times 10^{-4}\)，\(C/(6ND)\) 中位比为 1。文中注明近乎公式生成。
- 主式同时含 \(N,D,Q,\mathbf p\)，且 \(Q_B=1\)、\(\mathbf p=\mathbf p_{\mathrm{ref}}\) 时退回经典形式。依据写了。
- B6 的 360 点训练，B7 新增 90 点留出。B8 因 Loss 随 \(Q\) 上升且 64% 的点低于 \(E\) 而排除，并说明仍满足“使用 B6 或 B7、B8”。
- B2、B3、B4、B5、B9、B10 都用了。B4 的 57 点里 13 点与 B1 近邻，剔除后 Spearman 仍为 0.98。B3 相关为 1 是因为它由 B1 派生。B10 标为估算。B11/B12 做了来源审计。
- 弹性、领域替代/互补、质量 \(+0.1\) 的参数倍数，以及三类 \(g(Q)\) 下 \(\mathrm{MU}_Q/\mathrm{MU}_N\)，都有定义和数字。\(C=10^{19}\) 时指数型、幂函数型改为扩参数更划算，不再是三类都提质。这个结论和数据说明里“任何预算都应把质量拉满”相反，而且写清了条件。

两处要收紧。

经典参数只有点估计和 RMSE。bootstrap 固定了 \(\alpha,\beta\)，正文区间给的是 \(\kappa_N,\kappa_D,k_0\)，没有 \(E,A,\alpha,B,\beta\) 的置信区间。

主式被指定为幂次 M4+地板，不是交叉验证选出来的。同一数据上线性 M4+地板的留出 RMSE 是 0.042，幂次是 0.053，高于噪声代理 0.046。\(\kappa_D\) 的区间 \([0,0.041]\) 含 0，收缩检验 \(p=0.43\)。SPEC 把这些都写了，这是优点；但“为什么仍用拟合更差的幂次”主要是形式指定，论证短于证据。文首还写明《证明过程_修订版》仍是线性主式。下游差异 Q2-4 未关：Q3、Q4 若直接套用 \(\kappa_N,\kappa_D\)，形状会算错。

\(Q_B=\sum_i p_i Q_i\)、\(\mathbf p_{\mathrm{ref}}\) 等于 A4 训练配比均值、用 B1 的 \(E\) 和 B6 的 \(k_0\) 算 RegMix 可约份额，都标成假设。半合成与外推的可信度边界是够的。输出路径同样写成了 `final/outputs_q2/`，与仓库的 `src/outputs_q2/` 不一致。

## 问题三

SPEC v5 把题目要求写全了，而且和 Q1 v7、Q2 v7.1 对齐：

- \(N,D,Q\) 为决策变量，\(\mathbf p^*\) 固定并说明理由。
- \(L_{ctx}\) 外生，取值来自 C7 的五档 2048、4096、8192、32768、131072。
- 约束、三类 \(g(Q)\)、\(Q_0=0.66241\)、\(L_{ctx}^{\mathrm{crit}}=6/\eta=30000\)、同一 \(D\)，都在。
- 结构性转移定义为全局最优的质量状态在下界、内点、上界之间切换，并区分局部 \(\Phi=1\) 根和全局切换。
- 七档预算是本队设计，建议的三档被单列，没有把建议值写成唯一合法档位。

这些都还停留在规范里。§5 的 Q3-1 到 Q3-9 全部未关。当前代码仍是线性乘子：

```python
def hN(Q, p=PAR):
    return 1.0 + p["kappa_N"] * (1.0 - Q)

def hD(Q, p=PAR):
    return 1.0 + p["kappa_D"] * (1.0 - Q)
```

固定配比时也没有乘 P2 的 \(m_*\approx 0.899\)。已有 P3 表仍是旧 \(Q_0\)，没有 manifest。所以问题三的预算优化、三类成本比较、结构性转移和上下文敏感性，都不能用现有数字回答。

SPEC 自身的数学是通的：预算用尽、降到 \((\log N, Q)\)、无提质开销时的闭式，以及“\(H_{tot}\) 在固定配比下与 \(m=1\) 同配置、只缩放 Loss”，都写清了适用条件。\(Q\ge Q_0\) 被标成建模假设，而不是题目给定的物理约束。未重跑之前，不应把这份 SPEC 里的公式说成已算出的最优配置。

## 问题四

尚未满足题目的部分，SPEC §6 已经列出，和题目核对后仍然成立：

- 主分解没有严格执行开放权重筛选（58 个 base 行里 2 行 Unreleased、1 行缺失）。
- C6 桥接上界约 21.6，盖不住分解面板上约 37 分的前沿；桥接误差没有进入最终预测区间。
- 预测锚点是 2025.25，12 个月目标 2026.25 相对今天已经是过去；面板里还有晚于锚点的模型，回测不是严格的事前冻结。
- C8 报的是 1,958 个 JSON、约 1,861 个模型，与检查点里“1,860 个目录可解析、1,854 个模型六维完整”不一致，SPEC 没有解释 4 个截断 JSON。MATH 的 MAE 3.50 仍待解释。
- 数据说明把 C7 同时绑到问题三和问题四。主链 SPEC 没有写 C7 与 C1 `Model` 的匹配规则。独立流程里有上下文长度连接，但该流程未在本仓库运行，不能算主结果。
- 前三问的最优 Loss 没有译成 Benchmark。预测用的是 \(Q=1\) 的 \(L^*(C)\)，不是 Q3 各档最优配置。
