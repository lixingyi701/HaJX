# Q4 独立实现运行说明

## 合并位置与关系

独立实现位于 `src/code_q4/independent/`，入口为 `run_q4_independent.py`，算法模块在 `q4lib/`。它直接读取 C 组附件，不依赖 Q1–Q3 的 Python 模块；Q3 数值资源优化保持 `DEFERRED_Q3`，只输出符号接口。

它与现有 `src/code_q4/q4_01_c8_parse.py` 至 `q4_05_forecast.py` 是两套独立流程。本次合并保留原流程、`src/outputs_q4/` 既有结果及论文引用，不将来源项目的运行结果登记为本仓库的新结果。独立实现随附的历史运行结论见 [原始运行报告](问题四独立实现原始运行报告.md)。该报告尚未在本仓库重新运行核验。

## 运行

从 F 题仓库根目录运行。依赖按 `requirements.txt` 安装：

```bash
.venv/bin/python -m pip install -r src/code_q4/independent/requirements.txt
.venv/bin/python src/code_q4/independent/run_q4_independent.py \
  --data 附件/C_efficiency_evolution \
  --out src/outputs_q4/independent_run_01
```

`--out` 必须是不存在或为空的目录。每次运行使用新的目录名，例如 `independent_run_02`，避免覆盖旧结果。默认配置来自 `src/code_q4/independent/config_q4.json`，种子为 20260925，bootstrap 次数为 1000。可用 `--origin`、`--cutoff`、`--bootstrap` 覆盖配置；没有足够 C4 季度估计算力增速时，只有显式提供 `--assumed-growth` 才会使用假设增速。

`overrides_template.csv` 用于记录经证实的模型许可、权重、类型和家族修订；`pairs_template.csv` 用于记录经核实的 base/chat 配对。模板未填时程序会保留待核实状态，不会自动认定配对。C9 parquet 字段审计为可选功能，需要额外安装 `pyarrow`。
