## 1. 任务本质

本题是“**用历史 Benchmark 检验已建立的规律，把能力增长拆成规模与非规模两部分，并把损失翻译成得分后预测开源前沿**”。

具体有五项任务：

1. 写明综合能力、开源筛选、模型类型和时间轴。
2. 用动力学模型或因果推断模型，分别给出规模扩张与非规模技术进步的贡献占比。
3. 用历史评测检验前三问传来的规律，并按可比性等级把验证集交叉熵映射到 Benchmark，说明映射误差如何影响占比和预测。
4. 对 C8 做至少一项逐任务聚合，并与汇总表对照。
5. 在算力增长放缓的情景下，预测未来 12 个月或 24 个月的开源能力前沿边界，并给出不确定性。

问题四的核心贡献是**解释已经发生的能力增长来自哪里，并在算力增速下降时指出开源前沿还能到哪里**。前三问提供损失尺度上的规律和配置，本问负责换到得分尺度并引入时间。

## 2. 建模对象与系统边界

- **研究对象：**开放权重或按所声明规则筛选后的大语言模型，其多维 Benchmark 能力随时间形成的前沿，以及前沿变化中可归于规模的部分和可归于非规模技术的部分。
- **能力边界：**主结果是 Benchmark 得分。验证集交叉熵只通过映射进入本问。
- **时间范围：**历史段覆盖所选附件实际包含的日期；预测段为自声明起点起的 12 个月或 24 个月。**【需假设】题干没有给出数据截止日和预测起点，二者必须写明。**
- **模型范围：**pretrained 与 chat/finetuned 分开。未声明纳入的闭源或仅 API 模型不进入“开源前沿”。
- **空间／行业范围：**题干未指定国家、实验室或垂直行业。榜单里的任务维度不是 17 个训练领域，不能把问题一的领域配比直接当成 Benchmark 维度权重。
- **未纳入的内容：**题干没有要求预测闭源前沿、优化推理价格、采购 GPU 或分解电费。这些可以出现在讨论里，但不能写成题目既定的输出。

仓库数据字典中的行数和文件规模是附件现状，不是题干规定的验收常数。解析失败的文件数以实际读取为准，并留下清单。

## 4. 变量、状态与外生情景

| 类型 | 变量 | 解释 |
|---|---|---|
| 观测结果 | 各维得分与综合能力 \(S\) | 本问主响应，来自 C1/C2 或 C8 聚合 |
| 规模状态 | 训练算力、参数量、训练 token 数 | 来自 C4；代表规模扩张。三者如何合成一个规模指标须说明 |
| 时间 | \(t\) | 按所声明的提交日、发布日或版本日 |
| 样本标签 | 是否开放权重、许可证类别、pretrained 或 chat/finetuned | 定义谁能进入前沿 |
| 分解结果 | 规模贡献、非规模贡献、残差 | 在声明的时间窗口上计算 |
| 映射结果 | \(\widehat S(L)\) 及映射误差 | 连接前三问损失与本题得分 |
| 外生情景 | 基准算力增速、放缓算力增速 | 题干只规定要有放缓情景，没有规定数值 |
| 预测结果 | 未来时点的前沿边界及不确定性 | 12 个月或 24 个月 |

问题四不再把 \(N,D,Q,\mathbf p\) 当作待优化的决策变量。它们若出现，是前三问的输入，或是 C4 中已经发生的规模事实。

**【需假设】非规模项是扣除当前规模状态之后、仍与时间或其他技术标记有关的剩余变化。**架构、对齐和数据工程没有在附件里各自单独成列，不能把这三项分别识别成三个互不重叠的百分比，除非另外引入可核验的技术标记并写出假设。

## 5. 模型要回答的量

建议把本问写成两个输出，而不是一个寻优问题：

\[
\boxed{
\text{贡献占比}=
\big(\pi_{\mathrm{scale}},\pi_{\mathrm{tech}}\big),
\qquad
\text{前沿}=
S^{\partial}(T_0+\Delta)
}
\]

其中 \(\Delta=12\) 个月或 \(24\) 个月，\(S^{\partial}\) 是所定义的开源前沿边界，\(T_0\) 是声明的预测起点。

- 题干没有说“最小化某个损失”或“最大化某个得分”。若估计参数时使用最小二乘、加权最小二乘或似然，这是队伍选择的拟合准则，需要说明依据。
- “分别量化各自的贡献占比”要求两个百分比都出现，并写清是占观测涨分的比例，还是占模型所解释涨分的比例。
- 预测的对象是开源模型能力的**前沿边界**。全体模型平均分、中位模型或某一个命名模型的分数，只有在被定义为边界时才能作为主结果。
- 不确定性分析要同时覆盖：规模与映射参数的不确定、放缓情景的不确定，以及映射误差传到占比和前沿之后的范围。只给情景高低两个点、不说明随机误差，或只给拟合标准误、不谈算力放缓，都没有覆盖题干的两处要求。

因此，基础方案是**一个分解模型加一个情景预测**，不是多目标优化。

另外两点应写清：

- **【需假设】同一前沿内部不混用类型。**题干要求区分两类模型。分别报告是直接满足题意的做法；合并后再加类型虚拟变量，只能作为对照，且前沿数字仍应按类型分开。

题干没有要求本问重新施加问题三的预算不等式。算力在这里是已经发生的训练规模，以及未来情景中的增速。

## 7. 候选模型路线

| 路线 | 建模方式 | 适用条件 | 不适用风险 |
|---|---|---|---|
| **动力学：规模状态加随时间变化的剩余项** | 用 C4 的算力、参数或数据表示规模状态，用时间项或技术代理表示非规模变化，在前沿序列上估计两部分的增量 | 附件能提供较密的时间与规模记录，需要可解释的分解 | 时间项会吸收架构、数据、对齐、评测口径和样本构成的全部剩余变化，不能单独证明某一项技术的因果作用 |
| **因果推断：明确干预与对照** | 把某类技术采用或某次规模扩张写成干预，在可比较的模型之间估计贡献 | 存在清晰的干预定义、对照模型和可辩护的识别假设 | 榜单是自行提交的观测样本，缺少随机分配。没有识别假设时，回归系数只是相关 |
| **混合：结构分解加情景外推** | 用动力学或结构方程分解历史，再把问题二、三的损失经映射推到未来得分；放缓情景只改变未来规模路径 | 需要同时回答“历史上各占多少”和“以后前沿到哪” | 两条路线的得分口径、时间起点必须对齐，否则历史占比和未来预测不可比 |

题干允许动力学与因果推断二选一。从附件的形态看，动力学或结构分解更容易在现有字段上做完；若写成因果结论，识别假设和不能识别的部分要同时出现。无论哪一条，都要保留问题二给出的损失规律，避免在问题四另造一套与前三问无关的能力生成机制。

## 8. 识别、聚合、映射与预测

**第一步：固定样本和前沿的操作定义。**

【需假设｜建议写法】在已经声明的开源规则、模型类型和日期轴上，把时点 \(t\) 的前沿定义为截至 \(t\) 的累计最高综合能力，或定义为该时点新模型得分的上分位数。两种定义都要在文中选定一种作为主结果。累计最高水平的预测路径不应低于已经观测到的前沿；若允许下降，应改称为当期新模型的前沿水平。

**第二步：写出分解并定义占比。**

【需假设｜一种可用的动力学形式】设前沿的规模状态由问题二的损失预测或由 \(\log C\) 表示，记为 \(Z_t\)，则

\[
S_t=g(Z_t)+\tau\,t+\varepsilon_t.
\]

从窗口起点 \(0\) 到终点 \(1\)，模型解释的变化为

\[
\Delta S_{\mathrm{model}}
=\big[g(Z_1)-g(Z_0)\big]
+\tau(t_1-t_0).
\]

前一项记为规模贡献，后一项记为非规模贡献。占比至少报告两种分母中的一种，并写明是哪一种：

\[
\pi_{\mathrm{tech}}^{\mathrm{model}}
=\frac{\tau(t_1-t_0)}{\Delta S_{\mathrm{model}}},
\qquad
\pi_{\mathrm{tech}}^{\mathrm{obs}}
=\frac{\tau(t_1-t_0)}{\Delta S_{\mathrm{obs}}}.
\]

若使用第二种，须同时给出 \(\Delta S_{\mathrm{obs}}-\Delta S_{\mathrm{model}}\)。因果路线则把上式换成干预效应的分解，并列出条件独立或平行趋势等假设；不能满足的假设要写成结论边界。

**第三步：完成 C8 的至少一项逐任务聚合。**

【需假设｜聚合公式自定】例如对某一任务族，把逐任务得分先按任务随机基线归一，再在族内平均，得到一条任务级前沿。交付该序列、它与 C1/C2 对应维度的差异，以及这一差异是否改变“规模为主或技术为主”的方向。只做这一项就满足“至少一项”；若多做几项，计算前不要预设推理任务的技术占比一定更高。

**第四步：建立损失到得分的映射并传播误差。**

使用 C6 或 C5 时，按可比性等级分开。【需假设｜函数形式自定】映射应允许损失下降与得分上升的方向检查；若估计出的相关方向相反，先核对损失定义和样本构成，再解释。高可比层与中可比层的角色要写明。文献路线则列出关系式、出处和口径差异。

映射误差对结论的影响，至少做一次可复核的传递：扰动映射参数或残差后，重算技术占比和 12 个月或 24 个月前沿，报告变化幅度。

**第五步：用历史评测检验前三问规律。**

【需假设｜检验对象自定，但至少一条】例如把问题二在历史模型规模上的损失预测映射成分数，与同一批开源模型的实际得分比较；或把问题三不同预算下的最优损失映射成分数，说明它位于已观测前沿的什么位置。检验报告相关方向、误差和样本范围。相关不是因果，一致也不是对未来的准确率。

**第六步：设置放缓情景并预测。**

【需假设｜增速数字自定】用 C4 中通过开源筛选且有算力记录的模型，估计历史算力增速作为基准，再给出至少一个更低增速作为放缓情景。未来规模路径经问题二的损失关系和本问映射变成得分增量，加到声明的前沿锚点上。不确定性用重抽样、参数区间或情景带给出，并写明哪些误差已经进入、哪些没有进入。

预测使用的模型信息和增速估计都截在 \(T_0\) 之前。晚于 \(T_0\) 的发布记录可以用来事后对照，不进入该起点的拟合。

## 10. 验证方式

应分别验证“分解是否算清”“映射是否分层”“预测有没有用到未来信息”。

- **加总闭合。** 规模贡献、非规模贡献和残差与观测变化的关系要能对上。对不上时，先改表格，不改文字去凑百分比。
- **时间外对照。** 【需假设｜建议作为预测的验收】用早于 \(T_0\) 的样本估计，用 \(T_0\) 之后、且未参与估计的模型检查方向和误差。没有这段对照时，预测应写成情景计算，不写成已经检验的预报精度。
- **桥接分层。** 拟合层与对照层分开报误差。对照层不参与估计映射参数。高可比样本若集中在很低或很高的损失段，要写明映射的哪一段其实没有被该层支撑。
- **逐任务对照。** C8 聚合结果与 C1/C2 的对应维度比较。差异大的任务保留在结果里，并说明是否影响饱和判断或前沿涨幅。
- **口径敏感性。** 更换开源规则、模型类型、时间窗口、C3 权重和映射层后，看“规模贡献是否仍占主体”这一方向是否改变。方向改变则并列报告，不选取更好看的一列作为唯一结论。
- **上游数据性质。** 问题二、三中的半合成、估算和外推，映射成分数后仍然保持原性质，不能因为乘了一个 Benchmark 函数就变成独立观测。
- **前视检查。** 列出拟合样本的最晚日期，确认它不晚于该预测的 \(T_0\)。

## 11. 易错点与评委可能追问

| 易错点 | 评委可能追问／写作处理 |
|---|---|
| 只给一个技术占比 | “分子是什么，分母是观测涨分还是模型涨分，窗口是哪两年？”表中同时列出观测变化、模型变化和残差 |
| 把时间系数写成因果技术效应 | “架构、对齐、数据工程各自是多少？评测改版进了哪一项？”时间项写成剩余关联，并列出未能分开的因素 |
| 预训练与对话模型合成一条前沿 | “后训练增益算规模还是算技术？”两类分开报告 |

| 桥接样本不分可比性 | “高可比和中可比的损失来源一样吗？”分层报告；合并只作为敏感性 |
| 映射误差停在拟合残差 | “残差变一点，12.9% 和前沿分数变多少？”把扰动传到占比和预测 |
| 没有基准增速，只有一条“放缓”曲线 | “相对什么放缓？”基准情景与放缓情景并列 |
| 用平均分代替前沿边界 | “前沿边界的定义是哪一个分位数或包络？”在口径节写出操作定义 |

| 累计前沿的下界低于已经达到的分数 | “历史最高分为什么会在预测里下降？”改区间定义，或改称当期前沿 |
| 没有 C8，只用六维平均 | “逐任务记录用在哪一张表？”给出至少一项聚合及与汇总表的差异 |
| C4 只参与匹配模型名 | “算力、数据量、开源权重分别出现在哪个公式或筛选步骤？”三列都要有去向 |
| 单位混用 | “参数以十亿计时，FLOPs 有没有换回绝对量？”C4 算力与 \(6ND\) 使用同一套绝对单位 |
| 半合成损失被说成榜单上的真实能力 | “这条分数来自观测配对，还是来自映射？”保留上游数据性质 |
| 照抄《数据说明》页眉里的相关系数或贡献系数 | “这个符号和分解与损失越低能力越强是否一致？”以附件重算为准，页眉建议只作为待核说法 |
| 文献公式直接套到 0–100 分 | “文献里的得分是同一套六维基准吗？”口径不一致就限制使用范围 |
