# 问题二 Spec：广义标度律与配比通道

> 版本：v3。状态：实施中，尚未通过全部验收。更新日期：2026-09-25（北京时间）。赛题正文决定任务要求；本文件是 Q2 代码的唯一实现标准。推导细节见同目录《证明过程_修订版.md》，现有运行数值见《问题二_模型结果报告.md》。报告和旧代码不能覆盖本 Spec。

## 1. 目标、输入与证据边界

Q2 从 B1 拟合经典标度律，使用 B6 建立质量项，以 B7 新增样本检验，结合 P1 质量与配比接口给出可供 Q3/Q4 读取的冻结模型。B2、B6–B8 为半合成，B3 为插值，B10 为估算；它们不能充当真实训练验证。B4/B5 的评测口径与 B1 不一定一致，主要比较趋势。B8 与 B6/B7 在同点的 Loss 方向冲突，只用于压力检查，不并入质量项拟合。B9/B10 按模型名与 $N,D$ 对齐，不按行号拼接；B11/B12 用于来源和检查点审计。

`N_params_B`、`D_tokens_B` 先乘 $10^9$ 转为绝对个数；`C_FLOPs_1e21` 乘 $10^{21}$。P1 的 17 域质量、配比和 13 验证域系数按域名/列名连接，禁止依赖 CSV 行序。Q2 不重新读取附件 A 原始数据。

## 2. 模型与质量映射

经典基线：

$$L_0(N,D)=E+AN^{-\alpha}+BD^{-\beta}.$$

主候选固定配比 $\mathbf p=\mathbf p^*$ 时为

$$L_{\mathrm{core}}=E+AN^{-\alpha}[1+\kappa_N(1-Q_B)]+BD^{-\beta}[1+\kappa_D(1-Q_B)]+k_0(1-Q_B).$$

$\kappa_N,\kappa_D,k_0\ge0$；$Q_B=1$ 时退化到基线。旧加性模型是 $\kappa_D=0$ 的受限式。必须比较经典、仅参数项、仅数据项、共同乘子、完全耦合与带地板形式，并检查线性、幂形和指数质量响应。形式选择报告训练/验证划分、CV、嵌套比较及半合成性质。

主质量映射是题面语义假设 $Q_B=Q_A=\sum_i p_iQ_i$，故当前 $Q_0(\mathbf p^*)=0.6608889991$。敏感性映射为 $Q_B=Q_A/Q_A(\mathbf p^*)$；该映射会令部分领域超过 B 侧 $Q_B\le1$ 支撑域，不能静默截断或作为已识别的标定。P2 接口必须提供机器可读的 `q_mapping.main/alt`，包括公式、参数、支持域、越界政策、证据等级和来源；Q3/Q4 只能通过该接口消费映射。

配比项可作探索性扩展：

$$L=L_{\mathrm{core}}\exp\{s(N)[\bar f(\mathbf p)-\bar f(\mathbf p^*)]\},\quad
s(N)=\max\{s_0+s_1\log_{10}(N/10^6),0\}.$$

$\bar f$ 取 P1 各验证域预测对数损失等权平均。要将此式作为**已标定的四变量主模型**，$s(N)$ 必须仅从允许的训练数据估计，记录来源、尺度范围及留出检验；A6–A11 只能用于评估。不得读取 P1 的未版本化内部 pickle 或把质量变化与配比变化重复计入。未满足这些条件时，四变量式只能标为探索性结构假设，Q3 主优化固定 $\mathbf p^*$。

## 3. 拟合、检验与输出

1. B1 冻结 $E,A,\alpha,B,\beta$；报告其近乎公式生成的特征，不以极小残差估计真实训练噪声。
2. **只用 B6 的 360 点估计质量参数和选择质量形式**。B7 包含这 360 点；新增的 90 点作为真正的留出集，单独报告 RMSE、偏差及按 $Q,N,D$ 的残差。全 B7 的 450 点结果可列为含训练点的对照，不得称为独立检验。
3. 参数区间须注明抽样单元、固定的指数 $\alpha,\beta$、模型选择不确定性是否包含。B8 另列冲突诊断。B2/B4/B5/B10 的对照不证明质量项泛化。
4. 固定 $\mathbf p^*$ 的解析弹性、质量与扩参等效条件、质量地板、$6ND=C$ 下的 $N^*$ 应与数值解互验。配比乘子生效时，闭式 $N^*$ 一般不再成立。
5. 输出位于 `src/outputs_q2/`：`interface/P2_scaling_law.json`（参数、公式、映射、证据与版本）、`P2_bootstrap.npz`、`P2_theory.json`，以及 T20–T33b 表和 F21–F23 图。下游读取字段变化时同步更新 Q3/Q4 和报告。正式结果说明位于 `doc/Q2/`。
