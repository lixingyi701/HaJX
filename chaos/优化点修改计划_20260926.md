## 1. 背景与目标

## 3. 各优化点详细方案

### 3.1 点 1：Q2 幂次主式的说理缺口（纯文字）

**现状与问题。** 现行 Q2 Spec v7.1 主式为幂次 M4+地板，但明确写着「主式是指定的，不是 CV 选出来的」；CV 规则会选出线性 M4+F（留出 RMSE 0.042），幂次主式留出 RMSE 0.053 且高于噪声代理 0.046。这是 §5 差异表 Q2-6 登记的保留证据边界，论文若只写「指定」就是弱点。

**修改依据。** 《Scaling Laws Revisited: Modeling the Role of Data Quality in Language Model Pretraining》（arXiv:2510.03313）从有效样本量与信息论视角推出 $D_{\text{eff}}=D\cdot Q^\gamma$，即质量以**幂次乘子**进入标度律，$L(N,D,Q)=A/N^\alpha+B/(D^\beta Q^\gamma)+E$，且 $Q=1$ 精确退化为 Chinchilla 形式——与题面「一种自然的设计是：当教材趋于完美时，新公式退化为经典形式」完全对应。SoftQ（arXiv:2606.06888）的 $N$–$D$ 耦合形式可引为后续工作（数据受限 regime 下加性形式错误设定）。

**文件清单。**

| 文件 | 修改内容 |
|------|----------|
| `doc/Q2/问题二_SPEC.md` | §2「主式如何定」：把「指定」改写为「有有效样本量理论推导与独立文献支撑的函数形式选择，CV 规则作为经验对照保留」；§5 差异表 Q2-6 状态同步；追加修订历史 |
| `doc/Q2/证明过程_修订版.md` | 补一段有效样本量推导：$D_{\text{eff}}=D\,g(Q)$，$g(Q)\approx Q^\gamma$（$Q\to1$ 正则变化假设下） |
| `doc/final_report/sec5_q2.tex` | 模型形式选择的说理段落改写（弱点 → 亮点） |
| `doc/final_report/sec6_8.tex` | `thebibliography` 新增两条（见 §6） |

**重跑与验收。** 不动代码、不重跑；改完重新编译 `main.tex`，核对论文中「指定主式」相关表述全部更新。

**下游影响。** 无接口变化；Q3/Q4 已声明待重跑，不受文字修改影响。

### 3.2 点 2：Q1c 尺度修正函数形式升级（改代码 + 重跑）

**现状与问题。** 现行 Q1 Spec v7 §2.6 的尺度修正为两档对数线性形式 $\ln L_v=b_v^{\rm 1M}+\rho_v t+(1+\kappa t)g_v(\mathbf p)$，只用 1M（A4/A5）+ 60M（A8/A9）标定、1B（A10/A11）独立检验。本地已自证其局限：$s(1\text{B})$ 外推 0.854、同集实测 0.612，配比效应衰减比对数线性外推快；1B 平均预测 2.99 仍明显高于观测 2.23，Loss 随规模下降在加速，两档对数线性捕捉不到曲率。

**修改依据。** Data Mixing Laws（Ye et al., ICLR 2024）提出「训练步数 × 模型规模 × 配比」的嵌套解析预测框架，正是为跨尺度预测配比效果设计；其函数形式含饱和/幂律结构，比线性先验更贴合「效应随规模衰减且减速」的观测。

### 3.3 点 3：Q3 结构性转移文献锚点 + regime 诊断（依附 Q3 v5 重跑）

**现状与问题。** 现行 Q3 Spec v5 §3 把结构性转移操作化为全局最优解的质量约束活跃状态变化（LOWER/INTERIOR/UPPER + 全局分支切换），定义本身严谨，但论文缺少该概念的外部文献锚点；$d\ln(D^*/N^*)/d\ln C$ 目前只是辅助口径。

**修改依据。** 《Prescriptive Scaling Laws for Data Constrained Training》（arXiv:2605.01640）发现配置前沿的「turn-back」现象：预算越过临界后最优策略从「加重复次数」质变为「加大模型减轮次」——**预算驱动的最优策略质变**在标度律领域有直接先例；其 prescriptive validation（用律推荐配置再实际训练验证）也是可借鉴的验证思路。

### 3.4 点 4：Q_v2 正名为 D-S 证据折扣（纯文字）

**现状与问题。** 题目要求冲突消解「建立相应的综合评价模型」。现行主链是「评分后只诊断、不改分」+ §2.3-补 的 Q_v2 实验性对照（以来源 Kendall $W$ 作可靠性乘数调整 CRITIC 权重，三集 Spearman 0.92–0.95）。「实验性对照」的定位没有正面回应题目的建模要求。

**修改依据。** Q_v2 的可靠性乘数在数学上就是 **Dempster-Shafer 证据理论的可靠性折扣（discounting）操作**：Kendall $W$ 即折扣系数，$\tilde w_j=w_j\cdot W_{s(j)}$ 即按来源可靠性对证据（指标意见）打折后再合成。给它安上理论名称，「实验性对照」即升级为「有理论框架的消解模型」。

**文件清单。**

| 文件 | 修改内容 |
|------|----------|
| `doc/Q1/问题一_SPEC.md` | §2.3-补 改写：正名为「Dempster-Shafer 可靠性折扣消解模型（对照口径）」，写明 Kendall $W$ 即折扣系数、不替换主质量口径的理由；追加修订历史 |

### 3.5 点 5：Q4 分位数回归前沿交叉验证（新增脚本 + 重跑）

**现状与问题。** 现行 Q4 主链为结构化面板 M1b/M1c + sigmoid 桥接 + 双顺序 Shapley，技术贡献占比 12.9%/23.1%（模型解释增量内），M2/M3 为 45.7%/37.5%，方法间分歧 32.8 个百分点；且 Spec 已登记「不能称最终区间已独立传播 C6 桥接误差」。

**修改依据。** GitHub 公开的同题方案（Akun-python/llm-compute-allocation-modeling，2026-09-25）用 QR90 分位数回归直接拟合前沿 $\ln S=2.481+0.364\ln N+0.089t$，得规模贡献 84%（技术 16%），与本地 M1b/M1c 同量级；其 $N^*\sim C^{0.46}$ 与本地闭式指数 $\beta/(\alpha+\beta)=0.452$ 几乎相同，弹性排序 $\varepsilon_Q>\varepsilon_N>\varepsilon_D$ 双方一致。**两条独立建模路线得出同量级结论，本身就是论文最有说服力的稳健性证据之一**；QR 的经验前沿区间还提供一个独立于桥接 bootstrap 的不确定性通道。

## 7. 风险与开放问题

1. **点 2 可能不改善 1B 外推。** 新函数形式仍只用两档标定，若 1B 误差不降，回退对数线性并在 Spec 修订历史中如实记录尝试与回退依据；不得为让新形式胜出而调检验口径。
2. **点 5 的口径冲突。** QR 直接拟合前沿与 M1b「先拟合个体再取前沿」的口径不同，若两者贡献占比出现量级分歧，按现行 Spec 的既定原则处理：保持方法分歧、不宣称唯一估计，并把分歧本身写进论文。
3. **学术诚信边界。** 同题公开方案（2026-09-25 上线）晚于本项目主要工作；交叉核对只用于验证自有结论的稳健性，论文不得引用其数字作为己方结果，AI 使用披露与参考文献规范按赛题第五节执行。
4. **点 1 的表述分寸。** 文献支撑的是「幂次形式有理论依据」，不能改写为「幂次被证明优于线性」——CV 与留出证据仍显示线性略优，这一代价按 Q2-6 原口径保留在论文中。
5. **点 3 的 regime 诊断可能无信号。** 若 $D^*/N^*$ 斜率在三档预算内无可见 regime 变化，如实报告「未观察到第二类转移」，不夸大。
