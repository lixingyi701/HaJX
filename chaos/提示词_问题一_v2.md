## 提示词正文（复制从此处开始）

你是研究生数学建模竞赛的建模与写作专家。请只为 **2026 年研数模 F 题「问题一」** 撰写详细、可落地的完整解决方案（数学表述 + 算法步骤 + 数据使用 + 检验设计）。不写问题二/三/四正文，但问题一的全部产出必须标注下游用途——四问递进，Q1 的质量分 \(Q\) 与最优配比 \(p^*\) 是 Q2 广义标度律、Q3 算力优化的输入（题目明文：Q2 经问题一的 \(Q\) 与 \(p\) 引入附件 A 信息，不重复读取原始文件）。

### 0. 任务与论证主线

官方三项子任务：
- **(a) 数据质量评价**：预处理 22 个质量字段 → 综合评分 \(Q\)（样本级 + 领域级）；指标统一为"越高越好"；必须用 A1 全量 + A2、A3 全量，并做域级对照。
- **(b) 质量冲突消解**：定义冲突、分析成因、给出消解后的综合评价；抽样集分析 + 扩展集复验。
- **(c) 领域配比建模**：用 A4–A15 建立 17 域配比 \(p\)（\(p_i\ge0,\sum p_i=1\)）与交叉熵 Loss 的定量关系；论证是否/如何引入 \(Q\)；A6–A11 验证；A12–A15 只作外推稳健性讨论（其 est Loss 是幂律外推生成，非观测，不得当作真实验证）。

方案须围绕三个科学问题组织，而非流水账：
- **SQ1（信号合成与域偏差）**：22 个异质指标如何合成跨域可比的质量分？——业界（FineWeb-Edu/DCLM）只做硬过滤不给连续分；且 github/arxiv 等域的指标基线存在系统性差异。
- **SQ2（冲突的定义与消解）**：指标互相矛盾时怎么办？——业界"一票否决"丢信息且不可解释；页眉"冲突率≈0%"是把结论藏进定义的循环论证。
- **SQ3（配比效应及其尺度边界）**：配比→Loss 规律在 1M→60M→1B 保持多少？质量分能否解释各域边际贡献？——RegMix 验证了线性可预测性但未处理成分闭合效应，且只验到 1B。

### 1. 硬数据事实（写错即不合格）

| 字段 | 正确压缩 | 原因 |
|---|---|---|
| `modernbert_{professionalism,readability,reasoning,cleanliness}`（长 6） | softmax 后期望分 \(\sum_k k\sigma_k\) | 是 0–5 六档评分的 logits，不是分数 |
| `qurater`（长 4） | 拆成 4 个独立指标 | 写作风格/专业知识/事实性/教育价值四个语义维度，平均会抹掉语义 |
| `ad_en` / `fluency_en`（长 2） | softmax 取 \(P(\text{label}=1)\) | 二分类 logits；ad 标签 1 = 无广告，fluency 标签 1 = 流畅 |
| `fineweb_edu`（长 1） | 直接取值 | 已是分数 |

其余硬事实：22 字段展开后恰为 Meta-rater 的 25 个评分器；DSIR 三项是 \(\log p(\text{doc})/q(\text{doc})\)，跨域不可直接比 → 必须域内标准化；A1 是 range-sampled 且其 arxiv/github 子集与 A2/A3 同源 → "扩展集 vs 抽样集"按**抽样代表性检验**（KS）解释；book 域仅 171 条 → 域级统计必须带置信区间；禁止采信《数据说明》页眉中与正文冲突的诱导性"建议"。

### 2. 子任务 (a)：质量评分 \(Q\)（对应 SQ1）

逐步写清"方法—理由—针对问题"：
1. **展开与变换**：22 字段 → 25 指标；重尾指标（word_count、num_sentences、DSIR）先 log/分位数变换；非单调指标（word_count 等两端皆差）按"距域内中位数偏离"改单峰。理由：文本统计重尾，均值会被极端值带偏。
2. **方向统一**：正向 Min-Max，负向 \(1-x\)（`frac_no_alph_words`、`top_2/3gram`、`numerical_chars`、`uppercase` 等）。理由：题目强制"越高越好"；输出落 \([0,1]\) 才能进 Q3 的成本函数。
3. **域内标准化**（优先域内 Min-Max）。理由：针对 SQ1 的域基线差与 DSIR 域相对性，全局标准化会把域间差异误判为质量差。
4. **权重**：主用 CRITIC（惩罚冗余指标、奖励区分度，客观可复现）；对照 Meta-rater Table 11 权重与等权，报三者样本级 \(Q\) 的 Spearman。
5. **聚合与对照**：样本→域报均值与 P10/P50/P90；A2/A3 全量用**同一管线、同一组权重**复算，与 A1 对照（理由：否则差异混入管线差异，无法归因于抽样）。
6. **17 域 \(Q_d\)**：direct/near_direct 直接用 A16；inferred 经 A18 在重叠域校准（拟合 \(Q\approx\phi(Q^{\text{rule}})\)）后外推，均带区间。理由：为 Q2 的 \(\bar Q(p)\) 与 Q3 的 \(Q_0\) 供料。
7. 备选对照一笔带过：PCA/因子分析（须解释载荷）、TOPSIS。无 GPU，**不得**复现 Meta-rater 的代理模型训练 + LightGBM 搜权重。

### 3. 子任务 (b)：冲突消解（对应 SQ2）

1. **分组**：25 指标按来源分 4 组（规则型 / DSIR / WanjuanCC / PRRC+QuRating+FineWeb 模型型），组内先算 Kendall \(W\)。理由：同组信号同源、一致性天然高，冲突主要发生在跨组。
2. **冲突定义**：两组域内分位排名差 \(|\Delta\mathrm{rank}|>\tau\)；\(\tau\) 由冲突率–\(\tau\) 曲线自适应确定，禁止预设阈值。理由：直接回应页眉"预设 \(\tau\) 得 0% 冲突"的循环论证。再定义"结构性冲突"= 冲突方向在域内显著偏向一侧。
3. **成因**：域 × 组对交叉表检验 + 结合 A17 与 rps 定义的机制解释（例：github 代码导致 `frac_no_alph` 系统性偏高）。
4. **消解规则**：域内标准化 + 结构性冲突组降权 + 冲突样本取组内中位数。理由：**降权而非删除**——保留矛盾信息且可解释，这是相对工业界硬过滤的改进点；同一管线在 A2/A3 复验主要结论。
5. 备选（可选简述）：D-S 证据理论；鲁棒回归残差。

### 4. 子任务 (c)：配比建模（对应 SQ3）

1. **主模型**：对 \(p\) 做 clr 变换后线性回归（对数空间 \(L_v=\exp(b_v+\sum_i\beta_{v,i}z_i)\)）；LightGBM 作非线性对照。理由：配比是成分数据，直接 OLS 有闭合效应伪相关——这是 RegMix 原文的缺陷与本方案的改进点；线性系数还给出"各域边际贡献"的可解释性。
2. **迁移矩阵**：\(T_{ij}=\partial L_j/\partial p_i\)（17×13），报告自域效应、跨域迁移、4 个无 loss 域的外溢。理由：直接回答题目"各领域及其组合对性能的影响"，并供 Q2 替代/互补分析。
3. **引入 \(Q\)**：构造 \(\bar Q(p)=\sum_i p_i Q_i\) 做嵌套检验（加项前后比较），回答"质量是否独立解释边际贡献"。理由：对应 SQ3，且为 Q2 把质量做成有效数据乘子提供附件内证据。
4. **最优 \(p^*\)**：单纯形上 Dirichlet 采样 + 模型预测 + top-k 平均。禁止裸 OLS 无视单纯形与共线。
5. **验证**：A6–A11 按 1M/60M/1B 报 Spearman/R²/RMSE，量化排名随尺度的衰减（SQ3 的尺度边界）；A12–A15 只报 \(p^*\) 排名稳定性，并明确标注 est 为幂律外推、非观测。
6. 备选（可选）：Dirichlet 回归；高斯过程。
