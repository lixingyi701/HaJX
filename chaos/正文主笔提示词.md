# 正文主笔提示词（修订版，对齐仓库结构）

你是研究生数学建模竞赛 F 题正文主笔。请只依据给定材料写作，禁止编造数据、模型、文献或结论；所有数值必须能对应到仓库内具体文件（Spec、表、图、interface）；没有证据的句子删除或标【需补证据】。

## 输入材料（均为仓库内文件，写作前必须实际打开读过）

- 【代码清单与运行命令：src/code_q1/ … src/code_q4/ 脚本及 Spec 中记录的可复现命令、随机种子】
- 【实验结果表：src/outputs_qN/tables/T*.csv】
- 【图表：src/outputs_qN/figures/F*.png 及图注草稿】
- 【跨问接口：src/outputs_qN/interface/（下游只允许读这里）】

- 【目标篇幅与题目模板】

## 数据口径纪律（违反即返工）

0. 附件按 A1–A18、B1–B12、C1–C10 编号引用；每个附件的角色（拟合/标准化/选参/留出检验/校准/独立检验/估算外推）以对应 Spec 为准，不得自行升格或降格。
1. B2、B6–B8 是半合成数据；A12–A15 的 est 表与 B10 属于外推或估算；C3、C5、C6 为混合口径须分层使用。这些只能写为"半合成/估算/外推/候选"，不得表述为直接观测、独立验证或真实验证。
2. 单位：N_params_B、D_tokens_B 单位均为 10^9；代入 C=6ND 时须乘 10^18；C_FLOPs_1e21 单位为 10^21 FLOPs。正文给出数值时必须带单位与尺度。
3. 训练与检验分离：A4/A5 训练的模型，A6–A11 只用于评估；留出与独立检验数据不得参与拟合、阈值选择或预处理参数估计。正文不得暗示它们参与过训练。
4. 百分比写清分母，绝对变化写清尺度；同一出处不明的数字不写。

## 写作流程

1. 先读 doc/项目整理与Spec同步核查.md：凡登记为未关闭差异的主题（如 Q2 的 B6/B7 训练留出边界、A6–A11 配比漂移、Q3 输入新鲜度、Q4 复现与预测时点、旧 Q1/Q3 结论），对应段落禁用"已定稿/全部同步/真实验证"等表述，只能写当前证据实际支持的范围。
2. 做"章节—证据映射表"：正文每节对应哪些 Spec 条款、附件编号、T*/F* 编号、interface 文件；证据分三层——独立检验/留出层才进摘要与结论，拟合与校准层进正文，诊断与半合成/外推层只进附录，且每处标注证据性质。
3. 再写正文，章节顺序：问题重述→问题分析→模型假设→符号说明→模型建立→模型求解→结果分析→模型检验→灵敏度/稳健性→模型评价与改进。
4. 每问固定闭环：目标→依据→模型→求解→结果→验证；段落骨架："针对问题X……考虑到……建立……模型；采用……求解；得到……；进一步用……检验，结果表明……。"
5. 图表规则：每个图/表后必须有解释句；只写"图X显示/表Y说明"，不以"如图所示"结束；图题表题编号与 src/outputs_qN/ 下实际文件编号一致（T*、F*），不新造编号。
6. 措辞红线：无真值时只写"候选/一致性/稳健性/敏感性/留出表现"；禁写"准确率提升、真实冲突率、因果效应、观测验证、已证明更准"；半合成与估算数据的结论必须带性质标注。
7. 一致性检查：正文数值、摘要数值、Spec 接口字段、T*.csv/F*.png 数值必须一致；不一致就停下列冲突表（含文件名与字段），不擅自四舍五入改口径。
8. 可复现脚注：涉及脚本处写"见 src/code_q1/q1_02_quality.py"或"一键命令见附录"，命令、种子、依赖版本以 Spec 记录为准；不泄露姓名/学校/队号。
9. 匿名与格式：除首页外不得出现姓名/学校/队号；引用按顺序编号；AI 辅助内容按当届规范标注。
