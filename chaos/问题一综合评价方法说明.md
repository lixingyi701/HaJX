# 问题一综合评价方法说明

> 写作备忘。以下按现有代码与结果表说明实际使用的方法；与早期方案文字不一致之处列于文末，写入论文前应核对。

## 一、逻辑主线

综合评价分为四层：将原始质量信号整理为同方向、同尺度的指标；用数据驱动权重合成样本级连续质量分；将样本分聚合为质量域和配比域的质量分；对给定领域配比计算语料质量代理，并用扩展集检验抽样结果的代表性。

\[
22\text{ 个原始字段}
\longrightarrow 25\text{ 个标量指标 }z_{ij}\in[0,1]
\longrightarrow Q_i
\longrightarrow Q_d
\longrightarrow \bar Q(\mathbf p)=\sum_{d=1}^{17}p_dQ_d.
\]

这里的“质量域”是 A1–A3 所用的七域分类；“配比域”是 RegMix 的 17 域分类。两套分类并不相同，不能将七域分数直接当作全部 17 域分数。

## 二、指标预处理与样本级评分

### 1. 将异质字段变成可比较的指标

原始 22 个字段中，`modernbert` 四字段各包含六档 logits，先经 softmax 转为档位概率，再取期望分；`qurater` 的四维分别表示不同语义，拆为四项；`ad_en` 与 `fluency_en` 的二元 logits 取正类概率；`fineweb_edu` 取其唯一分数。展开后共 25 项。这样处理保留了列表字段的原始含义，避免将 logits 或不同语义维度直接求平均。

随后按指标意义统一“越高越好”：负向指标反向，词数、句数、平均词长和一元熵等适宜区间型指标按偏离域内中位数的程度改为单峰指标。每个质量域内对指标做 1%/99% 缩尾和 Min–Max 归一化；变换参数在 A1 上估计后冻结。域内处理旨在减轻量纲、极端值与代码、论文等文本类型固有差异的影响。实现见 [`q1_00_common.py`](../../src/code_q1/q1_00_common.py) 与 [`q1_02_quality.py`](../../src/code_q1/q1_02_quality.py)。

### 2. 用 CRITIC 确定指标权重

在 A1 全部样本的 25 维归一化矩阵上，只估计一套全局权重，各域共用。现有实现使用 Pearson 相关系数：

\[
C_j=\sigma_j\sum_{k=1}^{25}(1-r_{jk}),\qquad
w_j=\frac{C_j}{\sum_{\ell=1}^{25}C_\ell}.
\]

其中 \(\sigma_j\) 表示指标的区分程度，\(r_{jk}\) 表示它与其他指标的相关程度。CRITIC 同时考虑区分力和信息重复，避免对 25 个指标逐一主观赋权。所得权重见 [`T2_critic_weights.csv`](../../src/outputs_q1/tables/T2_critic_weights.csv)。这一方法给“与其他指标不同”的信号较大权重，因此仍须结合后续冲突分析判断差异是否具有合理语义。

样本级分数采用加权几何平均：

\[
Q_i=\exp\!\left[\sum_{j=1}^{25}w_j
\log\bigl(\max(z_{ij},10^{-3})\bigr)\right].
\]

几何平均使明显偏低的指标对总分产生影响，同时保持 \(Q_i\) 为连续量；\(10^{-3}\) 用于避免取零的对数。与等权几何平均、TOPSIS、PCA 分数的样本排序 Spearman 相关依次为 0.991、0.946、0.871。它们说明排序对合成方法具有一定稳健性，但不构成对实际训练价值的直接验证。对照数据见 [`T2_method_agreement.csv`](../../src/outputs_q1/tables/T2_method_agreement.csv)。

## 三、从样本分到域分和语料分

### 1. 七个质量域：以中位数为主口径

对域 \(d\) 内的样本分，现有主口径为

\[
Q_d^{\mathrm{med}}=\operatorname{median}\{Q_i:i\in d\}.
\]

中位数减轻少数极端文档的影响。结果表还报告算术均值、P10/P90，以及对中位数重采样 2000 次得到的 95% 区间。另有按文档 `rps_doc_word_count` 加权的副口径，用于描述较长文档在语料体量中的影响。该实现以**词数代理 token 数**，不应称为精确的 token 加权均值。七域结果见 [`T2_domain_quality.csv`](../../src/outputs_q1/tables/T2_domain_quality.csv)。

### 2. 从七个质量域桥接到 17 个配比域

17 个配比域中，3 个有直接映射，3 个有近似映射，另 11 个没有原有质量信号。对后 11 域，代码在 A1 原文上重算 11 个规则统计特征，以冲突消解后的样本分 \(\widetilde Q_i\) 为标签训练校准模型，再对 A18 文本估分并取域中位数。现有梯度提升模型的五折交叉验证 \(R^2\) 约为 0.31，表明补分仍有较大误差。六个可映射域的最终 `Q_final` 取对应质量域的分数，其余 11 域取校准估分；来源等级与结果写在 [`P1_Q_domain.csv`](../../src/outputs_q1/interface/P1_Q_domain.csv)。实现见 [`q1_04_bridge.py`](../../src/code_q1/q1_04_bridge.py)。

### 3. 给定配比下的语料级质量代理

当 \(p_d\) 表示目标训练语料中域 \(d\) 的份额时，现有接口计算

\[
\bar Q(\mathbf p)=\sum_{d=1}^{17}p_dQ_d,
\qquad p_d\geqslant0,\quad\sum_dp_d=1.
\]

按现有等权评测目标的最优配比，\(\bar Q(\mathbf p^*)\approx0.554\)。这是**域中位数的配比加权代理**，并非对实际训练语料所有 token 的样本分求平均。若未说明配比，就不存在由这些结果唯一确定的“全语料 \(Q\)”；尤其不能直接把 A1、A2、A3 的行拼接后求均值，因为三组的抽样比例不同，且 A1 的相关样本包含在扩展集中。计算见 [`q1_07_optimal.py`](../../src/code_q1/q1_07_optimal.py) 与 [`P1_summary.json`](../../src/outputs_q1/interface/P1_summary.json)。

## 四、抽样集与扩展集的域级对照

A1 拟合的缩尾端点、归一化端点和 CRITIC 权重均被冻结，再原样应用到 arxiv 全量 A2 与 github 全量 A3。这样对照可检验 A1 在这两个域内是否具有代表性，不会将重新拟合引入的差异误当成抽样差异。

| 领域 | A1 抽样域中位数 | 扩展集全量中位数 | KS 距离 | Cohen’s \(d\) |
|---|---:|---:|---:|---:|
| arxiv | 0.7132（1,419 篇） | 0.7113（17,523 篇） | 0.0211 | −0.0041 |
| github | 0.5331（10,000 篇） | 0.5319（203,752 篇） | 0.0122 | 0.0050 |

两域的中位数差均小于 0.002，标准化均值差也很小，支持“**A1 在 arxiv 和 github 两域内可代表所给全量文件的主要质量分布**”这一有限结论。现有 KS 计算给出的 \(p\) 值分别约为 0.60 和 0.12，但 A1 相关样本本身包含在 A2/A3 中，不能将其作为两个独立样本的严格检验结果，也不能以“未检出差异”证明分布完全相同。对照数据见 [`T2_domain_quality.csv`](../../src/outputs_q1/tables/T2_domain_quality.csv) 和 [`T2_sampling_check.csv`](../../src/outputs_q1/tables/T2_sampling_check.csv)。这项对照尚不能证明另外五个质量域或 11 个推断配比域的泛化性。

## 五、写入论文前需要统一的实现口径

1. **预处理描述**：早期执行计划要求 DSIR 按词数归一，并将广告、流畅度 logits 转为 log-odds；当前评分代码实际使用原 DSIR 值与 softmax 正类概率。论文应按最终选定且复核过的实现描述，不能混写。
2. **跨域可比性**：指标按域分别归一化后得到的域中位数，带有“相对各域自身分布”的含义。将不同域的数值直接比较、再用于配比加权，需要明确承认并检验这一跨域尺度假设。
3. **17 域区间**：当前接口中六个映射域的 `Q_final` 取原质量域分数，但 `CI_lo`、`CI_hi` 来自 A18 校准估分；例如 arxiv 的 `Q_final≈0.716` 不在所列区间内。因此这些区间不能作为映射域 `Q_final` 的置信区间。推断域区间主要反映重采样波动，也未充分包含校准模型的迁移误差。
4. **两种样本分口径**：七域结果表使用冲突消解前的 \(Q_i\)，17 域桥接使用消解后的 \(\widetilde Q_i\)。引用两个表时应标明口径，或重新统一计算。
