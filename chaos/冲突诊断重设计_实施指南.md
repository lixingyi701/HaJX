## 一、重设计要点总结

### 1.1 核心改进

原四组方法存在的问题已通过以下改进解决：

| 问题 | 原方法 | 新方法 |
|------|--------|--------|
| RPS组内部异质性高 | 11项规则合并，组中位数掩盖分歧 | 保留11项但单独报告内部离散度 |
| 模型评分器过度聚合 | FineWeb+QuRating+ModernBERT合为一组 | 拆分为S4/S5/S6三个独立来源 |
| 指标数量主导结果 | 四组权重不等（11/3/2/9项） | 六来源等权（各1/6），百分位平均 |
| 组中位数掩盖对立 | 中位数对内部分歧不敏感 | 算术平均保留所有指标投票 |

### 1.2 六来源分组

```
S1_RPS规则      (11项): rps_doc_*  → 文本规则统计
S2_DSIR         ( 3项): dsir_*     → 重要性加权（已残差化）
S3_轻量分类器   ( 2项): fluency_en, ad_en
S4_FineWeb-Edu  ( 1项): fineweb_edu
S5_QuRating     ( 4项): qurater_*
S6_ModernBERT   ( 4项): modernbert_*
```

### 1.3 方法论升级

**单指标层级**：
- 每个指标 $j$ 的标准化分 $z_j(x) \in [0,1]$
- 域内百分位排名 $r_j(x)$
- 与主分 $Q$ 的偏离度 $\delta_j(x) = |r_j(x) - r_Q(x)|$

**来源层级**：
- 来源分数：$\bar r_s(x) = \frac{1}{|I_s|} \sum_{j \in I_s} r_j(x)$（等权平均）
- 来源间极差：$c_{\text{range}}(x) = \max_s \bar r_s(x) - \min_s \bar r_s(x)$
- 来源间标准差：$c_{\text{std}}(x)$（新增，对极值不敏感）
- 方向不一致性：是否存在某来源<0.3且另一来源>0.7

**异常类型区分**：
- 单指标异常：某指标偏离大但同源其他指标正常
- 多来源对立：两个来源之间存在系统性分歧

## 四、结果解读要点

### 4.1 来源内部一致性

**查看**：`T3_source_internal_consistency.csv`

**解读**：
- `kendall_W`：范围0-1，越高表示来源内指标排序越一致
  - 预期：S2(DSIR)、S5(QuRating)、S6(ModernBERT) 较高（0.6-0.8）
  - S1(RPS) 预计较低（0.2-0.4），因其本质异质
- `mean_pairwise_spearman`：来源内指标两两相关的平均值
- `mean_indicator_source_corr`：各指标与来源均值的平均相关

**论文使用**：
- 支持"RPS组内部一致性低"的论断
- 说明拆分模型评分器的合理性（S4/S5/S6各有特点）

### 4.2 冲突率与阈值

**查看**：`T3_conflict_metrics_A1.csv` 和 `T3_extended_recheck_6sources.csv`

**解读**：
- `conflict_rate_range`：基于极差 $c_{\text{range}} > \tau_{\text{range}}$ 的冲突率
  - 预期 A1 约15-25%（与原四组方法的19.08%可比）
- `conflict_rate_std`：基于标准差 $c_{\text{std}} > \tau_{\text{std}}$ 的冲突率（辅助指标）
- `conflict_rate_dir`：存在方向对立（<0.3 vs >0.7）的文档比例

**论文使用**：
- 报告新六来源冲突率，与原四组对比（见 `T3_old_vs_new_conflict.csv`）
- 说明阈值自适应方法（肘部法）及其稳健性（见 `T3_threshold_sensitivity.csv`）

### 4.3 冲突类型分布

**查看**：`T3_conflict_by_domain_source.csv`

**解读**：
- 每行是一个"域×来源配对"的冲突实例
- `source_high` vs `source_low`：最常见的对立来源
  - 预期：DSIR高×RPS低、RPS高×DSIR低（与原方法的"DSIR高×规则型低"对应）
- `count` 和 `share`：该配对在该域冲突文档中的绝对数量和比例

**论文使用**：
- 识别主要冲突模式（如"DSIR认为重要但RPS认为低质"）
- 分析不同领域的冲突特征差异

### 4.4 与原四组方法对比

**查看**：`T3_old_vs_new_conflict.csv`

**解读**：
- `old_conflict_rate` vs `new_conflict_rate`：冲突率差异
- `overlap_jaccard`：两方法识别的冲突文档交集比例（Jaccard系数）
  - 0.5-0.7 表示中等一致性
- `cohens_kappa`：考虑随机一致性的校正一致度
  - >0.6 表示实质一致，0.4-0.6 中等，<0.4 弱一致
- `KS_p_value`：冲突文档 vs 非冲突文档的主分 $Q$ 分布差异（KS检验）
  - p<0.05 表示冲突文档的 $Q$ 分布显著不同

**论文使用**：
- 说明新方法与原方法的一致性和差异
- 如 Kappa 较高，可称"新方法保留了原方法的核心发现"
- 如 Kappa 较低，需说明"新方法揭示了原方法掩盖的细粒度分歧"

### 4.5 单指标异常 vs 多来源对立

**查看**：`T3_single_vs_multi_anomaly.csv`

**解读**：
- `n_single_anomaly`：仅单个指标异常（同源其他指标正常）
- `n_multi_source`：两个或以上来源间存在系统分歧
- `n_both`：既有单指标异常又有多来源对立
- `n_neither`：既不属于单指标异常也不属于多来源对立

**论文使用**：
- 区分"测量误差/特殊文档"（单指标异常）与"评价体系根本分歧"（多来源对立）
- 说明大部分冲突是多来源对立而非个别指标噪声

如运行时缺少 `sklearn`，可手动实现 Cohen's Kappa：
```python
def cohen_kappa(a, b):
    n = len(a)
    po = (a == b).sum() / n
    pe = sum((a == k).sum() * (b == k).sum() for k in np.unique(np.r_[a, b])) / n**2
    return (po - pe) / (1 - pe + 1e-12)
```
