## 1. 凝练科学问题：先前模型遇到了什么核心问题，怎么解决的，效果如何

问题一背后不是一条文献线，而是两条在近三年各自演化、恰好被本题附件同时取样的线。**A1–A3 正是 Meta-rater（SlimPajama-Meta-rater）的质量信号表，A4–A15 正是 RegMix 论文的原始实验数据**。凝练科学问题时应直接引用这两个工作及其上游的 tech report 证据链。

### 1.1 质量侧证据链（对应 A1–A3）

第一阶段是规则启发式过滤。C4 用标点结尾、坏词表、行长等规则；Gopher 提出 doc-level 质量规则（词数区间、符号词比、重复 n-gram 阈值）；SlimPajama 在 RedPajama 1.2T 基础上做低长度过滤和 MinHash-LSH 全局去重得到 627B。**核心问题：规则只能剔除明显垃圾，无法区分"干净但无教育价值"与"高价值"文本**。A1 中的 15 个 `rps_*` 字段就是这一阶段的产物（RedPajama-v2 quality signals 命名规范）。

第二阶段是单一模型打分器。FineWeb-Edu 用 LLM 标注教育价值再蒸馏成小分类器筛数据，同算力下 MMLU 等基准显著提升；QuRating 用成对比较训练打分器（写作质量/专业性/事实性/教育价值四维）；DSIR 用重要性重采样把语料分布拉向目标域（books/wiki/math）；Llama 3 报告 §3.1 明确使用基于 RoBERTa 的多个质量分类器加去重与启发式规则的组合管线。**核心问题随之显现：单一打分器有系统性偏置——教育价值打分器会压低代码和数学文本，流畅度打分器会惩罚 LaTeX 公式和非散文体**。A1 实测样本可直接验证：arxiv 域文档的 `fluency_en` 显著偏低而 `qurater` 教育维、`modernbert_reasoning` 偏高。

第三阶段是多维融合。Meta-rater 提出 PRRC 四维（Professionalism / Readability / Reasoning / Cleanliness，即 A1 里四个 `modernbert_*` 字段的来源），并将 25 个质量信号通过**小代理模型训练实验 + 回归**学习最优加权，而非人为设定；其报告的效果是在 1.3B 规模、同 token 预算下，下游平均分比随机选样提升约 3 个点、比单一 rater 更稳。**方法论上的关键转折：指标权重不再由"文本看起来好不好"决定，而由"加入训练后是否降低目标 Loss"反推**。

### 1.2 配比侧证据链（对应 A4–A15）

Pile 原始配比是人工经验权重。DoReMi 用小代理模型做 Group DRO 自动重加权，8B 下游提升但结果依赖参考模型的选择。RegMix（Liu 等，ICLR 2025；赛题参考文献误写为 Xia/ICML 2024）把配比选择表述为回归问题：训练 512 个 1M 参数小模型（即 A4/A5 的 512 行），每个用 Dirichlet 采样的 17 域配比训练 1B token，拟合"配比 → 各域验证 Loss"的回归模型（线性 + LightGBM），在单纯形上搜索预测最优配比，再迁移到 1B 模型（A10/A11）验证。报告的关键效果：(1) **配比与 Loss 的关系可以被小模型上拟合的回归很好预测**（held-out Spearman 相关极高）；(2) **排序在 1M → 1B 跨约千倍规模上近似不变**，最优配比可迁移；(3) 反直觉发现——对下游任务最有利的单域是 `pile_cc`（普通网页），而非直觉上"高质量"的 wikipedia/书籍，且域间存在非平凡交互。

### 1.3 凝练出的科学问题（论文中的表述建议）

两条线合起来，核心科学问题可以凝练为一句话：**文本的训练价值不能从其内在属性直接读出，只能通过训练实验度量；而真实规模的训练实验不可承受，于是"小代理实验 + 可迁移回归"成为度量数据价值的基本范式——但这引入了两个必须检验的假设：多指标冲突如何消解为一个价值函数，以及小尺度结论能否跨尺度迁移。**

拆成三个子问题写入论文：其一，22 个指标方向、尺度、语义各异且系统性冲突（专业性与流畅度冲突、教育价值与广告并存），如何构造既可解释又不误伤专业语料的综合质量分；其二，质量分（文档/域属性）与训练配比（数据集构成决策）分属两个层面，前者不能直接推出后者，须经配比—Loss 实验回归验证；其三，1M/60M 小模型上得到的配比排序是否在 1B 乃至更大规模上保持（A8–A11 可实证检验，A12–A15 只能作外推一致性讨论）。

**我们可主张的新发现/新工作**（区别于直接复述文献）：(1) 用 A1 实测数据把"指标冲突"从轶事变成可量化结构——给出冲突矩阵、冲突类型分类（专业性型/广告混合型/格式型）与人工抽查证据；(2) 用 A16 映射 + A17 原始文本把质量线与配比线**桥接**起来：对 11 个 inferred 域，利用 `regmix_domain_sample` 的原文自行计算 15 个 `rps_*` 规则指标（这些指标定义公开、可精确复算），从而给全部 17 个配比域构造质量分，检验"域质量分能否解释配比回归中各域的边际效应"——这是两篇原论文都没有做的连接。

## 2. 现有数据集逐项对照：是否同一科学问题、方法能否复用、方案是否全覆盖

结论先行：**是同一科学问题**（A1–A3 是 Meta-rater 信号表、A4–A15 是 RegMix 原数据，我们面对的正是这两个工作处理过的语料），因此其方法可以复用，但每个文件的复用方式与限制不同，逐项列明如下。

### 2.1 A1（51,230 行，含原文）——质量评分与冲突分析的主战场

处理管线（同一规则将应用到 A2/A3）：

1. **指标标量化**：logits 类字段先做 softmax；二元的取正类概率（`ad_en` 取"是广告"概率后**反向**），6 元的取期望分数 E[score]∈[0,5]，`qurater` 4 元按其四维语义分别保留；`dsir_*` 是对数似然比，做域内分位数归一；`rps_*` 中"适宜区间型"指标（词长、词数、数字占比）用与理想区间的偏离度打分，方向型指标（重复 n-gram、无字母词占比）反向归一。不能一律求平均——这是笔记 §2.1 的要求，已被实测字段结构证实（8 个列表字段各有语义）。
2. **分组评分**：按"教育/专业价值（fineweb_edu, qurater 教育维, modernbert_professionalism/reasoning, dsir_*）、清洁度（ad_en 反向, modernbert_cleanliness, rps 重复类）、可读性（fluency_en, modernbert_readability, rps 格式类）、信息密度（unigram_entropy, unique_words）"四组组内加权，再组间加权得 Q_d；等权基线与 PCA 第一主成分作对照。
3. **文档权重口径**：分别报告文档等权与 token 加权（用 `rps_doc_word_count` 近似）两种域级质量分，并说明后续问题二/三采用 token 加权口径（因为标度律的自变量是 token）。
4. **域分布不均的处理**：book 仅 171 行、arxiv 1419 行，域级均值的置信区间必须用 bootstrap 给出；不做跨域直接比较排名时先域内标准化。
5. **冲突分析**：定义文档级冲突度 = 定向归一化后各组分数的分歧度（如组间最大差或方差），在 A1 上取高分位阈值筛出候选冲突文档，**利用 `content` 人工抽查分类**（这是 A1 独有的能力），形成冲突类型表与消解规则（例：`modernbert_professionalism` 高且 `fluency_en` 低且域∈{github, arxiv} → 不惩罚流畅度项）。

### 2.2 A2/A3（arxiv 17,523 / github 203,752 行，无原文）——同管线迁移与一致性检验

指标 schema 与 A1 完全一致（已核验，仅少 `content`/`_source_domain` 等 3 个元字段），因此评分与冲突规则**可以原封复用**。但方案上有两条限制必须写明：(1) 无 `content`，不能声称对 A2/A3 做过逐条人工核验，其冲突消解只能依赖从 A1 学到的规则；(2) 正确的用法是**一致性检验**——比较 A1 的 arxiv/github 子样本与 A2/A3 在各指标分布（KS 检验/分位数图）、质量分分布、冲突比例上是否一致；一致则说明 A1 抽样代表性好、评分管线稳健，不一致则报告偏移并讨论抽样机制。A3 的 20 万行还能把 github 域的质量分布刻画得比 A1 的 1 万行精细得多（如 sub_path 分层：不同语言/文件类型的质量差异），可作为加分分析。

### 2.3 A4–A15（RegMix 表）——配比→Loss 回归与跨尺度验证

1. **主拟合（A4/A5，512 行）**：17 列配比每行和为 1（需先逐行核验），13 列验证域 Loss。按笔记 §2.3：先对每个验证域 Loss 单独回归，再用事先固定的评价权重 w 聚合为 L_target(p)。基线用满足单纯形约束的可解释回归（对配比列不带自由截距，或用 log-ratio 变换），对照 LightGBM 等非线性模型复现 RegMix 原设置；报告 held-out R²/Spearman。
2. **同尺度验证（A6/A7，256 行）**：1M 模型 held-out 集，报告各域 MAE/RMSE 与排序相关。
3. **跨尺度迁移（A8–A11）**：60M（256 行）与 1B（**取 63 行交集**，index 对齐问题必须记录在数据审计清单中）上检验：用 1M 拟合的回归预测 60M/1B 的 Loss 排序，报告 Spearman/top-k 命中率——这是对 RegMix"排序不变"假设的独立复检，也是问题二"跨尺度"讨论的实证基础。
4. **外推表（A12–A15，各 63 行）**：10B/70B 是估算值而非真实训练，只能检查"估算表与我们回归外推的一致性"，论文中明确标注证据层级为"模型外推"，不作为独立验证。
5. **配比建议输出**：在单纯形上（可用 Dirichlet 大样本 + 回归预测）搜索 L_target 最小的配比，报告最优配比、相对 Pile 人工配比与均匀配比的预测收益及 bootstrap 置信区间；领域边际效应统一表述为"从域 A 向域 B 转移 1% 份额"的效应。

### 2.4 A16 + A17/A18——质量线与配比线的桥接（方案的独创点）

A16 的 17→7 映射中 11 个域是 inferred（无对应质量域），这是"用质量分解释配比效应"的最大缺口。填补方案：**A17（`regmix_domain_sample`）提供了全部 17 个域的原始文本**，其中 15 个 `rps_*` 指标是纯规则统计量，定义公开，可以对 17 个域的文本逐条精确复算，得到全部 17 个配比域在规则指标子空间上的质量分；6 个 direct/near_direct 域上同时有 Meta-rater 模型分与我们复算的规则分，可用来标定"规则分 → 综合质量分"的校准关系，再推到 11 个 inferred 域（并给出校准误差）。随后检验：域级质量分与配比回归中各域边际效应的相关性——若高质量域边际效应未必大（RegMix 的 pile_cc 发现预示如此），这正是"质量 ≠ 训练价值"的定量证据，直接服务于 1.3 节的科学问题表述。注意 A17 各域样本量极不均（ubuntu_irc 仅 16 行、philpapers 67 行），域级统计须报告不确定性；direct/near_direct/inferred 三层映射在敏感性分析中分层处理，主结果可只用 6 个有映射域。

### 2.5 覆盖性自查

A_data_value 目录下全部 6 类文件均已进入方案：A1（主评分+冲突+人工核验）、A2/A3（管线迁移+一致性）、A4–A15（回归+四层验证）、A16（映射+分层敏感性）、A17/A18（inferred 域补全+质量-配比桥接）。无遗漏文件；两个已知数据瑕疵（1B 表行数不对齐、A17 部分域样本过少）已列入处理规则。

## 3. 问题一与问题二三四的衔接（不脱节的具体机制）

衔接不能只是口头声明，要落实为**共享的符号、口径和数值接口**，建议在论文第一问就固定以下四项并贯穿全文：

1. **质量变量 Q 的定义权归问题一**。问题二 B6–B8 的半合成 `Q_score` 与问题三成本项 g(Q) 中的 Q，都必须使用问题一定义的域级/语料级综合质量分（token 加权口径，归一到同一区间）。使用 B6–B8 时明确"数值同范围不等于同尺度"的对应假设，并做敏感性分析——这一句在问题二的开头就要引用问题一的 Q 定义式。
2. **配比变量 p 与目标损失 L_target(p) 的定义权归问题一**。问题二广义标度律中的配比修正项 h(Q,p)、问题三优化中的决策变量 p 及其单纯形约束，直接沿用问题一的 17 域（或聚合后的域组）定义与 A4/A5 回归得到的函数形态；问题一报告的"配比边际效应"为问题三判断"结构性转移"（某域份额从 0 变正）提供先验。
3. **评价权重 w 全文唯一**。问题一聚合 13 域 Loss 用的 w，与问题四 Loss–Benchmark 桥接时选取的验证域口径保持一致（或明确写出换算），避免"每问一套考卷"。
4. **证据分层标签随数据流传递**。问题一产出的每个中间量（质量分、回归系数、最优配比）都标注其证据层级（直接观测/规则复算/校准推断/外推），问题二三四引用时继承标签——例如问题三基于 A12–A15 一致性的任何论述自动继承"外推"标签，不得升格为实证结论。

对应五天计划：本方案的 §2.1–§2.3 属第一天任务（质量分、冲突分析、配比基线），§2.4 桥接与 A6–A15 全部验证属第二天，接口定义（§3）应在第一天晚讨论时冻结。
