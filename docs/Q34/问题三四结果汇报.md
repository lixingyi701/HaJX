## 0. 一页结论

**问题三。** 在三种质量成本函数、五档上下文长度、两种基线质量口径下共解出 210 组最优配置。主要结论有四条：

- 小预算不提质，大预算直接把质量提满。主口径下几乎不存在"部分提质"的内点区间（210 组中只有 3 组内点，且多数出现在副口径）。在主口径 Q₀=0.988、L_ctx=2048 下，临界预算 C_crit 为：指数型 10^20.61，幂函数型 10^20.48，对数型 10^18.52。成本函数的形式决定临界点，对数型比另两种早约两个数量级。
- 三种识别口径给出的 C_crit 相差不超过 0.05 dex（主口径）。bootstrap 的 90% 区间约为 ±0.02–0.03 dex，各档预算的区制判定 100% 一致。
- 上下文越长，C_crit 越往前移，模型也越小。L_ctx=131k 时，指数型 C_crit 降到 10^19.99；C=10^22 时 N* 缩到 2048 档的 0.48 倍，注意力成本占 81%。这些与解析式 [(6+η·2048)/κ]^{β/(α+β)} 吻合。
- 把配比 p 一起放进优化，联合目标能再降约 13.7%，但这部分收益几乎全部来自配比效应，规模通道的贡献不到 0.1%。最优 p 在不同预算和成本函数下的排序秩相关 ≥ 0.976，说明"先定配比、再定规模"的分离做法是成立的。

**问题四。** 能力度量主口径是 C1 的 Average，副口径是 C8 的去饱和分；base 与 chat 分开处理；时间轴以 C2 的发布日为主。

- **桥接。** Loss 与 Average 呈负相关，r = −0.51。sigmoid 桥接的留一 RMSE 为 8.08，优于线性（8.28）和常数（9.51）。
- **分解。** 主窗口 2023.5→2025.0 内，base 前沿从 12.5 升到 37.3。结构模型 M1b/M1c 给出的非规模技术占比为 **13%–23%**，线性效率前沿法 M2/M3 给出 **38%–46%**，两类方法相差 32.8pp。我们如实报告这一区间：**规模扩张是主导，技术进步贡献约一到二成（结构口径）至四成多（线性口径）**。chat 前沿的技术占比约 26%，其中后训练增益每年上升约 3.3 分。
- **预测。** 以 2025.25 为起点，按基线算力增速 0.60 dex/yr，base 前沿 12 个月后中位 43.1（90% 区间 37.4–52.8），24 个月后 46.2（37.5–68.5）。若算力增速降到 1/4，24 个月中位为 44.1。chat 前沿 24 个月中位为 61.6（基线情景，后训练增益延续）；若后训练增益停滞，则为 54.8。算力放缓时，技术进步在增量中的占比由约 55% 升到约 77%。
- **回测。** 用 2024.5 之前的数据训练、预测 2025.25 的 base 前沿，M1b 误差 −0.78，朴素线性外推误差 +2.65。
- **陷阱。** 《数据说明》中的五条灰色"建议"都已用数据反驳，见 §2.7。

## 1. 问题三：算力约束下的联合优化与结构性转移

### 1.1 模型与求解

优化问题为

```
min  L(N,D,Q)
s.t. 6ND + D·[g(Q) − g(Q₀)]₊ + η·N·D·L_ctx ≤ C,   Q₀ ≤ Q ≤ 1,   η = 2×10⁻⁴
```

**降维。** 三项成本都与 D 成正比，而 L 对 D 严格递减，所以最优时预算约束一定取等。由此可以反解出 D(N,Q) = C / [κN + Δg(Q)]，其中 κ = 6 + η·L_ctx。原来的三维约束问题就变成了在 (log N, Q) 上的无约束二维问题，因此不需要罚函数。

**求解器。** 内层对 log N 做黄金分割（剖面 Loss 对 N 是单峰的）；外层对 Q 做三级网格加密，最终步长小于 1e-5，并对端点做保护。整个求解器全向量化，脚本为 `code_q3/q3_00_model.py`。

**组合。** 共 210 组：

- 成本函数 g：指数型 10⁷e^{6Q}、幂函数型 5×10⁹Q⁴、对数型 2×10⁹ln(1+10Q)；
- 预算 C：10^19 到 10^25；
- L_ctx：取 C7 中的五档，即 2k、4k、8k、32k、128k；
- Q₀：两种口径。主口径为 p* 加权质量除以 0.5608，得 0.9878；副口径为网页语料 c4 的质量，得 0.8892。

L_ctx 是外生量，其解析临界值 L_ctx^crit = 6/η = 30000，超过它之后注意力成本就超过训练成本。

**互验结果（均已通过）：**

| 检验 | 结果 |
|---|---|
| Δg=0 区域：数值解 vs 闭式 N* = [αÃ/(βB)]^{1/(α+β)}(C/κ)^{β/(α+β)} | 15 组相对误差 ≤ 1.83×10⁻⁷ |
| 本求解器 vs 粗网格穷举 | 18 组 Loss 差 ≤ 1.6×10⁻⁵，且区制判定一致 |

### 1.3 结构性转移：定义、识别与结果

**定义。** 记 x*(C) 为预算 C 下的最优解。若在 C_crit 两侧 KKT 的活跃约束集不同，就称 C_crit 处发生结构性转移。这里的活跃约束集有三种状态：Q≥Q₀ 活跃、内点、Q≤1 活跃。这是主定义（口径 A）。

**解析识别。** 定义

Φ(C) = [(k₀ + k₁N^−α)(κN + Δg)] / [βB·D^−β·g′(Q)]

它表示"提质的边际收益"与"提质挤占数据造成的边际损失"之比。当 Φ < 1 时，不提质就是 KKT 点。Φ 在 Q=Q₀ 处穿越 1 的位置就是 C_crit，用二分法求得。

**两个辅助口径：**

- 口径 B：提质成本占比 s_Q 取到极大值，此时弹性 d ln s_Q / d ln C 由正变负。
- 口径 C：D/N 的斜率偏离常数 (α−β)/(α+β) 最大的位置。

**C_crit 结果（log10，L_ctx=2048）：**

| Q₀ 口径 | g | A：离开 Q₀ | A：到达 Q=1 | A：Φ 解析解 | B：s_Q 峰 | C：D/N 拐点 | 三口径极差 |
|---|---|---|---|---|---|---|---|
| 主 0.988 | 指数型 | 20.610 | 20.634 | 20.610 | 20.65 | 20.60 | 0.050 |
| 主 0.988 | 幂函数型 | 20.483 | 20.483 | 20.486 | 20.50 | 20.45 | 0.050 |
| 主 0.988 | 对数型 | 18.523 | 18.523 | 18.540 | 18.55 | 18.50 | 0.050 |
| 副 0.889 | 指数型 | 20.100 | 20.430 | 20.100 | 20.45 | 20.15 | 0.350 |
| 副 0.889 | 幂函数型 | 20.199 | 20.250 | 20.199 | 20.25 | 20.20 | 0.051 |
| 副 0.889 | 对数型 | 18.449 | 18.449 | 18.592 | 18.45 | 18.40 | 0.050 |

解读：

- 主口径下，"离开 Q₀"与"到达 Q=1"几乎重合（2048 档宽度 ≤ 0.024 dex，131k 档也仅 0.034 dex），即转移几乎是跳变式的"不提质 → 提满"。原因是 k₁(1−Q)N^−α 与 (1−Q)k₀ 对 Q 都是线性的，而 g(Q) 是凸的，最优解倾向于落在角点。
- 副口径下，起点质量低，指数型会出现约 0.33 dex 宽的"部分提质"内点区间。三口径极差最大为 0.385 dex（副口径、指数型、L_ctx=131k），仍在事先设定的 0.5 dex 一致性门槛之内。
- 对数型的 g′ 在低 Q 处大、在高 Q 处小，接近 1 时的边际提质成本最低，因此早约 2 个数量级就开始提质。**这说明"是否提质"取决于成本函数的形式，不能一概而论**。

**稳健性：**

| 检验 | 结果 |
|---|---|
| 问题二 bootstrap 500 组参数 | 主口径指数型 C_crit 中位 20.610，90% 区间 [20.594, 20.628]；六种组合的宽度都在 ±0.03 dex 以内；10^19、10^22、10^24 三档的区制判定一致率 100% |

### 1.5 配比 p 联立（副口径）

**模型。** 联合目标为 L_joint = L(N,D,Q)·m(p)。其中：

- m(p) 用问题一求 p* 时所用的同一组 13 个验证域 GBDT 模型计算，并以 p* 处为 1 归一化；
- 提质起点改为 Q₀(p) = Σ pᵢ·Q_B,i；
- 在 p* 周围做 Dirichlet 采样，共 4000 个 p。

**结果**（`tables/T3_mixture_joint.csv`）：

- 联合最优相对 p* 再降 13.69%–13.78%，其中配比效应 1 − m 贡献 13.69%，规模与提质通道只贡献 0.001%–0.105%。
- 采样最优点离 p* 的全变差距离为 0.143；若取 top-100 平均，则为 0.017–0.022，更稳健，收益为 1.0%–2.2%。
- 不同 (g, C) 组合下，4000 个 p 的排序秩相关最小值为 0.976。

**结论：** 配比与规模/质量决策近似可分离。主口径固定 p* 的做法是合理的；联立只作为上界参考。

### 2.4 贡献分解：规模扩张 vs 非规模技术进步

**面板**（`q4_04_decomp.py`）：C2 × C4 按（发布日, 组织）联表，t ≥ 2021，D > 1e9 token；base 58 行（51 个 C4 模型；D 取 C4 的 35 行，
其余 23 行按 D = C/(6N) 反解），chat 37 行（只保留同时发布 base 的原厂组织，排除社区微调洪流）；同一 C4 模型多行命中按 1/重复数 加权。
每个模型用问题二标度律算 L̂(N,D) 作为"规模状态"。

**三类互相独立的方法**（在同一前沿窗口上比较"技术占比"）：

| 方法 | 设定 | 关键参数 | 拟合 wRMSE / R² |
|---|---|---|---|
| M1a 桥接即插即用 | C6 桥接不重估 + τ·(t−2023) | τ = 3.48 | 6.52 / 0.56 |
| **M1b 结构·加性（主）** | S = lo + amp·σ(k(L̂−L0)) + τ·(t−2023) 联合重估 | lo 5.75, amp 34.47, k 24.1, L0 1.925, **τ = 2.45/yr** | **3.55 / 0.870** |
| M1c 结构·有效 Loss | S = lo + amp·σ(k(L̂ − δt − L0)) | **δ = 0.035 Loss/yr** | 3.57 / 0.868 |
| 仅规模（M1b 去 τ） | — | — | 4.03 / 0.832 |
| M2 效率前沿（Epoch 口径） | 帕累托有效模型 S = a + b·log10C + c·t | b = 5.71, c = 4.46 | — |
| M3 分位数回归 | 同式，q = 0.75 / 0.5（0.9 不稳） | q.75: b 5.74, c 3.20 | — |
| OLS | 同式全样本 | b 5.99, c 2.33 | 5.73 / 0.66 |

前沿分解用 Shapley（两种顺序平均）：规模 = 只让前沿 L̂ 按实际演进，技术 = 只让 t 演进。前沿取累计 top-3。

**主窗口 2023.5 → 2025.0**：base 前沿 S 12.54 → 37.30（ΔS = 24.76），L̂ 2.006 → 1.869，log10C 23.35 → 24.64；
起点前沿 llama-65b / starcoder2-15b / falcon-40b，终点 Qwen2.5-72B / Qwen2.5-32B / Qwen2-72B。

|---|---|---|---|---|
| M1b（主） | 23.06 | 3.40 | **12.9%** | 6%–22% |
| M1c | 20.12 | 6.04 | **23.1%** | 4%–46% |

| M3 q=0.9 | — | — | −45%（时间系数为负，不稳，不采用） | — |

其余窗口（M1b / M2 / M3 q=0.75）：2024→2025 为 7.1% / 30.6% / 23.9%；2024.5→2025.25 为 8.2% / 24.3% / 18.7%。
换算为"每年算力等效"（dex/yr）：M1b 0.29、M1c 0.56、M2 0.78、M3 q.75 0.56、OLS 0.39 —— 与 §2.2 窗口回归的 0.44–0.77 同量级。

**如何读这组数（重要）**：核心三法 M1b/M2/M3q.75 极差 32.8pp，超过我们事先设的 ±15pp 一致性门槛，**不强行给单一数字**。
差异是结构性的：M2/M3 假设得分对 log C 线性，无法表达桥接的 S 形加速段，把"Loss 刚进入陡峭区带来的规模红利"部分记到时间头上；
M1b/M1c 用标度律 + S 形桥接吸收了这部分，且拟合优度明显更高（R² 0.87 vs 0.66）。故主结论采用结构口径：
**规模扩张贡献约 77%–87%，非规模技术进步约 13%–23%**；线性口径 30%–46% 作为上界参考。各方法在"规模为主"这一定性结论上一致。

**C3 历史点敏感性**（logN 规格）：仅 C2×C4 为 0.78 dex/yr；加入 C3 历史点权 0.2 → 0.50，权 1.0 → 0.21。
C3 的 Avg 与其六维均值相关仅 0.634（混合来源、口径不一），故只以 0.2 降权做敏感性，不进主结果。

**chat 与后训练增益**：89 对（同组织 base, chat）配对，均值增益 4.30 分；有发布日的 31 对回归
G(t) = −0.40 + **3.35**·(t−2023)（bootstrap sd 1.84 / 1.57）——后训练本身是一类逐年增强的非规模技术。
chat 前沿 2023.5→2025.0：8.76 → 46.06，规模 23.77、预训练技术 3.56、后训练技术 4.86，**技术占比 26%**（2024.5→2025.25 窗口 14%）。

### 2.5 算力放缓情景下的 12 / 24 个月前沿预测

**预测链条**（`q4_05_forecast.py`，不新增自由参数）：
算力情景 → 问题三最优配置（Q=1，L_ctx=4096，κ=6.82）下 ΔL* = L*(lc+g·h) − L*(lc)（在 lc≈24.6 处斜率 −0.0645/dex）

不确定性：蒙特卡洛 4000 次 = 问题二 bootstrap × 分解 bootstrap（M1b/M1c 各半）× 后训练增益 bootstrap × 前沿残差（sd 2.05）。

## 3. 局限与说明

1. **分解方法分歧 32.8pp**：结构模型（13%–23%）与线性效率前沿（38%–46%）口径差异是本题最大的不确定性来源，已如实并列并解释原因；主结论"规模为主"在所有方法下成立。
2. **C6 高可比层太少**：High 仅 7 点且全在底噪区，桥接上升段依赖 Medium 层（不同验证集）；已做权重 0.25–1.0 敏感性（S(1.85) 变化 < 0.4 分）。
3. **早期 base 样本稀疏**：2023.5 之前前沿停在 2021 年的 GPT-J 等模型，分解窗口因此从 2023.5 起算。
4. **D 的反解**：23/58 行 D 由 C/(6N) 反解，隐含 Chinchilla 计算量近似；L̂ 使用问题二标度律（Q=1），不代表各厂真实数据质量。
5. **预测为情景条件预测**，不含新架构突破等离散事件；90% 区间已包含标度律、桥接、分解、后训练与残差五类不确定性。
6. **问题三**的 g(Q) 形式与参数取自附录 B，结论"角点解、对数型早两个数量级提质"对 g 形式敏感，已三种并列；p 联立依赖问题一 GBDT 配比模型，只在 p* 邻域内采样，不外推。
