## 二、问题详细诊断

### P1: 几何平均系统性低估冲突文档

#### 问题描述
- **当前实现**: 用加权几何平均合成质量分,对25个指标"乘起来再开方"
- **设计初衷**: "一票否决"效应,低分项拖累总分
- **实际问题**: 21.5%的文档存在指标冲突(LaTeX公式的低流畅度、代码的低表层可读性),这些**不是真实质量缺陷,而是领域特征**
- **后果**: 几何平均系统性惩罚这21.5%的文档,即使Huber事后修正,排名相关仅0.997,说明修正力度不够

#### 证据
1. 代码位置: `q1_02_quality.py:88-90`
   ```python
   def score(self, Z, w=None):
       w = self.critic_w if w is None else w
       return np.exp((w[None, :] * np.log(np.clip(Z, EPS, 1))).sum(axis=1))
   ```
2. Huber降权在**几何平均之后**应用 (`q1_03_conflict.py:50-65`),时序错误
3. 冲突分析显示短板惩罚与冲突检测概念矛盾

#### 根本原因
**方法论张力**: 几何平均假设"所有低分都代表质量缺陷",但冲突分析证明21.5%的低分是领域伪信号。

### P2: DSIR指标缺失长度归一化

#### 问题描述
- **应该做**: DSIR三个指标(dsir_books/wiki/math)是文档级累计的负对数比,应**先除以word_count**归一化
- **实际做**: 直接对原始值做`log1p`压缩,**完全跳过**了`/word_count`这一步
- **后果**: 
  - DSIR与文档长度高度相关(A2: ρ=-0.78, A3: ρ=-0.96)
  - 短文档(<20词)冲突率67.6%,长文档(2000-10000词)仅16%
  - 去掉DSIR组后,冲突率从21%降到12%,**DSIR单独贡献约10个百分点的虚假冲突**

#### 证据
1. 代码确认: `q1_02_quality.py:42-45`
   ```python
   heavy = ind.startswith("dsir") or ind in ("rps_doc_word_count", ...)
   xl = np.log1p(np.clip(x, 0, None)) if (heavy and x.min() >= 0) else x
   # ❌ 缺失: x = x / word_count
   ```
2. `_transform_one`函数签名只接收单列`x`,无法访问`word_count`
3. 全代码库搜索`dsir.*word_count`无结果

#### 数据证据(用户图片)
- Spearman(DSIR组排名, log word_count) = A2 -0.78, A3 -0.96
- 冲突率按长度分层: <20词 67.6%, 500-2000词 35%, >2000词 16%
- 去DSIR基线: A2冲突率12.1%, A3冲突率11.1%(原21%)

### P3: 中位数掩盖长尾分布

#### 问题描述
- **当前使用**: 
  1. 冲突分析的组分数 = 组内指标的**中位数** (`q1_03_conflict.py:24`)
  2. 域级质量汇总 = 域内文档Q的**中位数** (`q1_02_quality.py:188`)
- **问题**: 中位数回答"典型值",不反映长尾。如果训练时模型大量接触极端低质量样本,中位数会低估实际风险

#### 需验证
1. 检查A1七域的质量分布是否存在显著长尾(偏度>1?)
2. 对比中位数 vs token加权均值 vs 截尾均值(去掉最低10%)的差异
3. 如果差异>10%,说明中位数确实掩盖了长尾

#### 数据检查计划
- 读取`outputs_q1/tables/T2_domain_quality.csv`
- 对每域计算: 偏度、P10/P90差距、中位数与加权均值的相对误差
- 如果github/c4等大规模域存在长尾,需要改方案

### P4: 外推稳健性不足

#### 问题描述
- **论文声称**: "排序效应可迁移,绝对水平需要尺度修正"
- **实际证据不足**:
  1. 三尺度Spearman相关0.52/0.47/0.68,平均仅0.56,**有一个尺度几乎失效**(0.47)
  2. pile_cc和pubmed_abstracts的ρ<0.40,**排序根本不能迁移**
  3. MAE从3.5降到0.10依赖"漂移律修正",但修正需要目标尺度数据,**不是盲外推**
- **对下游影响**: 问题三的最优配置p*用1M模型算出,如果外推到大模型时配比效应会变,p*可能只对小模型适用

#### 需检查
1. 非线性模型(梯度提升)是否也做了跨尺度验证? (`q1_06_scale.py`只报告了线性模型)
2. 问题三搜索p*时用的是哪个模型的系数?(检查`q1_07_optimal.py:35-47`)

### 方案B: 几何平均与冲突检测解耦 (P1)

**目标**: 在合成质量分**之前**处理冲突,而不是事后补偿

**两种可选策略**:

#### B1: 冲突指标条件降权(推荐)
```python
# 在 QualityPipeline.score 之前
def resolve_conflict_before_scoring(Z, domains, w):
    """在几何平均前识别冲突并调整权重"""
    S = group_scores(Z)  # 4组分
    R = domain_pct_rank(S, domains)
    c = conflict_score(R)
    is_conflict = c > tau
    
    # 对冲突文档,降低"极端组"的指标权重
    w_adjusted = w.copy()
    for i in np.where(is_conflict)[0]:
        hi_g, lo_g = R[i].argmax(), R[i].argmin()
        for j in G_IDX[GK[hi_g]]:
            w_adjusted[i, j] *= 0.5  # 降权50%
        for j in G_IDX[GK[lo_g]]:
            w_adjusted[i, j] *= 0.5
    return w_adjusted
```

#### B2: 分段合成(保守)
```python
# 对冲突文档用算术平均,非冲突用几何平均
Q = np.where(is_conflict, 
             (Z @ w).sum(1),  # 算术平均
             np.exp((w * np.log(Z)).sum(1)))  # 几何平均
```

**验证标准**:
1. 冲突文档的Q分布应向上移动(平均提升>0.01)
2. 与PCA/TOPSIS的相关应保持>0.85
3. LaTeX/代码样本的典型case质量分应提升

### 方案C: 中位数替换方案 (P3)

**前置步骤**: 先诊断数据分布

**诊断脚本**:
```python
import pandas as pd
import numpy as np
from scipy.stats import skew

df = pd.read_csv("outputs_q1/tables/T2_domain_quality.csv")
A1 = pd.read_pickle("outputs_q1/cache/A1_indicators.pkl")
Q1 = np.load("outputs_q1/cache/step2_scores.npz")["Q1"]

for dom in A1["domain"].unique():
    q = Q1[A1.index.get_indexer(A1[A1["domain"]==dom].index)]
    med = np.median(q)
    mean = q.mean()
    wc = A1.loc[A1["domain"]==dom, "rps_doc_word_count"]
    tokw = (q * wc).sum() / wc.sum()
    sk = skew(q)
    print(f"{dom}: 偏度={sk:.2f}, 中位数={med:.3f}, 均值={mean:.3f}, token加权={tokw:.3f}")
```

**替换策略** (如果偏度>0.5):
1. **域级汇总**: 改用**token加权均值**(已有`Q_tokenw`列,但只做副口径)
2. **冲突组分**: 改用**截尾均值**(去掉组内最高/最低10%后求均值)

**验证**: 重算冲突率,看是否仍约21%(应该差距不大,但分布更合理)
