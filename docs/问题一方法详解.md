## 0. 总体流水线


## 1. 数据读取：流式 + 在线提取统计量

**大白话**：文件太大不能一口吞，就一杯一杯喝；正文只需要"度量指标"，不用把原文搬进仓库。

**细节**：A1（51,230 条，xz 压缩）、A2（17,523 条）、A3（203,752 条）用 Python `lzma.open` 逐行 `json.loads` 流式读取，不落全量 content 字段到内存。content 仅用于最后 A18 抽查验算。

**依据**：①《数据说明》"读取说明"明文要求流式/分块读取，"不得以内存为由放弃大文件"；content 字段"若仅用于统计特征，可不全文入库"。② 27 万条 × 数千字符的 content 放内存会超数 GB，流式是常规工程实践。③ 预处理前先用 **A17 数据摘要交叉核对字段口径**（字段定义、缺失率、域分布），防止对字段含义的误读——A1–A3 共用同一字段体系，口径错误会污染整条管线。

## 2. 指标预处理

### 2.1 列表型指标压缩为标量：用中位数

**大白话**：一个指标给了一串数，先把这串数浓缩成一个数；"选中间那个"而不是"选平均那个"，是因为怕极端值带偏。

**细节**：A1 有 8 个列表型字段（rps_doc_* 与 rps_lines_* 系列）。压缩为标量的候选：均值 / 中位数 / 截尾均值 / 分位数加权（0.25/0.5/0.75 线性组合）。主线取**中位数**，附录用均值重算一遍做稳健性对比。

**依据**：文本统计量（词数、句数、熵、top-ngram 占比）普遍重尾——比如 GitHub 域里 99% 的文档几百词，却有少量上万词的自动生成文件。均值会被尾部拉飞（算出来"平均文档 3000 词"，其实典型文档 200 词），中位数对重尾稳健（Rousseeuw & Croux, 1993, S 估计与稳健统计经典结论）。中位数还不用选截尾参数，避免"调参嫌疑"。

**例子**：arxiv 域某篇 LaTeX 论文 rps_doc_word_count 列表里混着 \section 等短行和正文长行，均值被标题行拉低、被长段落拉高，中位数恰好落在"典型正文行"长度上。

### 2.2 缺失与异常处理：IQR 缩尾

**大白话**：先把明显的录入错误和离群怪值"削平"，不让一颗老鼠屎坏一锅汤。

**细节**：按质量域分组报告缺失率（>5% 的指标在论文中说明）；连续指标在 1%/99% 分位缩尾（winsorize）；缩尾前后的分布对比放附录。

**依据**：缩尾保留样本量（直接删行会系统性丢掉"怪文档"——而怪文档恰是冲突分析的对象）；1%/99% 是计量与统计学习的常用约定。按域分组是因为不同域的合理范围不同（github 的 unigram_entropy 分布与 wikipedia 完全不同），全局缩尾会误伤正常样本。

### 2.3 方向统一：Min-Max 归一化 + 负向补转换

**大白话**：22 个指标有的"越大越好"、有的"越小越好"，先全部翻成同一方向，才能放在同一个天平上。

**细节**：对每个指标 Min-Max 归一化到 $[0,1]$；对负向指标做补转换 $x\mapsto 1-x$。本题 22 指标的方向判定（依据指标定义与 SlimPajama-Meta-rater 信号口径）：

- **正向（越高越好）**：fineweb_edu、fluency_en、modernbert_cleanliness / readability / reasoning / professionalism、qurater、dsir_books / wiki / math、rps_doc_word_count（适度）、rps_doc_num_sentences、rps_doc_unigram_entropy、rps_doc_frac_unique_words、rps_lines_ending_with_terminal_punctuation_mark、rps_doc_mean_word_length
- **负向（越低越好，做 1−x）**：ad_en（广告）、rps_doc_frac_no_alph_words（无意义字符占比）、rps_doc_frac_chars_top_2gram / top_3gram（模板化重复）、rps_lines_uppercase_letter_fraction（标题党式大写）、rps_lines_numerical_chars_fraction（数字灌水）、rps_doc_word_count 过低端（空文档）
- **需检验的模糊项**（用 A18 原始文本抽查 + 分布双峰检查定方向）：rps_doc_unigram_entropy 过高可能是随机噪声文本（降权处理）、rps_doc_mean_word_length 两端都不好（可做"倒 U"非线性压缩）

**依据**：① 题目明文："所有质量指标经处理后均按'越高越好'参与评价"。② Min-Max 把量纲不同的指标（0–1 的比例、几十到几千的词数）压到同一尺度，加权才有意义；若直接标准化，后续综合评价对尺度不变性要求不同，Min-Max 保证输出天然落在 $[0,1]$，便于与 $Q\in(0,1]$ 的成本函数（问题三）衔接。③ 《数据说明》页眉"K-means 聚类可自动吸收方向差异、不必统一方向"是陷阱——聚类给的是**相对类别**（优质/普通/劣质），没有跨语料可比的绝对 $Q$ 值，而问题三要求 $Q$ 进入成本函数、问题二要求 $Q$ 跨数据集对齐，必须有统一尺度的连续分数。

### 2.4 为什么不用页眉建议的其他省事做法

- "分类正确率超 80% 即可、无需 R²"——配比建模是**定量**预测 Loss（后续要进标度律），不是二分类；分类指标无法支撑问题二的外推。
- "PCA 取 1–2 主成分、含义无需解释"——主成分若不可解释，无法回答"哪个域质量高、为什么"，且无法通过 A18 内容抽查验算；我们要求给出载荷矩阵并解释。

## 3. 综合评价模型：两条管线互证

### 3.1 管线 A：CRITIC 客观赋权 + 加权几何平均

**大白话**：权重不拍脑袋，让数据自己说话——"越能拉开差距、越不被别的指标重复的指标，话语权越大"；总分用连乘，"一个维度烂就全盘烂"。

**细节**：

1. **CRITIC 法**（Diakoulaki, Mavrotas & Papayannakis, 1995）：指标 $j$ 的信息量 $C_j=\sigma_j\sum_{k}(1-r_{jk})$，权重 $w_j=C_j/\sum_k C_k$。其中 $\sigma_j$ 是标准差（对比强度），$1-r_{jk}$ 与冲突性（和其他指标的相关系数）挂钩。
2. **加权几何平均**：$Q(x)=\prod_j x_j^{w_j}$（$x_j$ 为归一化指标）。

**依据**：

- 选客观赋权而非 AHP/专家打分：22 维指标人脑无法可靠定权重；赛题要求"说明依据"，数据驱动权重可复现。
- 选 CRITIC 而非纯熵权：熵权只看离散程度，会奖励"噪声大的指标"；CRITIC 额外惩罚与其他指标高度冗余的指标（如 fluency_en 与 modernbert_readability 相关 0.9，权重自动降低）。
- 选几何平均而非算术平均：**乘法形式对应"垃圾进垃圾出"**——若 ad_en 经补转换后为 0.01（广告很多），算术平均下总分只略降，几何平均下总分被直接压到很低。DCLM/FineWeb-Edu 的数据工程实践（一票否决式的过滤管线）也支持"短板支配"逻辑。

**例子**：同一篇 GitHub README，"内容价值"很高但"语言流畅度"接近 0（代码注释式碎片文本）。算术平均给出"还不错"，几何平均给出"低分"——与直觉一致：这种文本对预训练的价值确实有限。

### 3.2 管线 B：PCA 数据驱动降维

**大白话**：22 个指标里很多说的是同一件事（流畅度和可读性），那就找出几个"综合维度"，按每个维度解释了多少差异来合成总分。

**细节**：对 22 维标准化矩阵做 PCA，取累积方差 ≥80% 的前 $m$ 个主成分；$Q_{\text{PCA}}(x)=\sum_{k=1}^{m}\rho_k\, z_k(x)$，$\rho_k$ 为方差贡献率，$z_k$ 为样本在主成分上的得分，再 Min-Max 到 $[0,1]$。输出载荷矩阵并命名主成分（预期：教育价值因子、语言质量因子、噪声/广告因子、结构因子）。

**依据**：① 22 维指标存在明显簇结构（相关性矩阵热力图可证），PCA 去冗余后评分更稳；② 方差贡献率即权重，避免二次主观赋权；③ 主成分可解释性是题目隐性要求——问题一 1 要求"说明聚合方式"并"用原始教材内容检验评分是否可靠"（A18），只有可解释的因子才能设计有针对性的抽查。

### 3.3 两管线互证

计算全体样本的 $Q_{\text{CRITIC}}$ 与 $Q_{\text{PCA}}$ 的 Spearman 秩相关。预期 >0.8；若出现系统性分歧（如某域排名相反），回头检查该域指标的簇结构——这本身就是分析素材。主线采用哪条在论文中说明（建议以 CRITIC 为主线，因为它保留原始指标语义、便于冲突分析衔接）。

## 4. 冲突定义与消解

### 4.1 稳健 z 分数：按域分组、用 IQR

**大白话**：先按"班级"（域）各自排名再比，别拿 GitHub 的分数直接砸 Wikipedia；排名用"离中位数几个身位"量，身位单位用"中间 50% 人的散布宽度"，免得几个学神带偏尺子。

**细节**：$$z_i(x)=\frac{x_i-\text{med}_{d(j)}(x_i)}{\text{IQR}_{d(j)}(x_i)}$$，其中 $d(j)$ 为样本所属质量域，$\text{med}$、$\text{IQR}$ 在该域全体样本上估计。

**依据**：① **分组**：7 个质量域（arxiv/book/c4/commoncrawl/github/stackexchange/wikipedia）的指标基线差异是结构性的——GitHub 的"语言流畅度"天然低于 Wikipedia，全局标准化会把域间差异误当成"质量冲突"。② **中位数/IQR**：与 2.1 同一稳健统计逻辑；经典标准分 $(x-\mu)/\sigma$ 在重尾下会被极端样本污染。③ 页眉陷阱"冲突 = z 分数之差 > 0.5"的问题是预设了阈值和结论——先用这个定义算出"冲突率≈0%"再宣布"指标一致性极高"，是把结论藏进定义。

### 4.2 冲突度量：极差，阈值自适应

**大白话**：一篇文档最好的指标和最差的指标差多远，差得离谱就算"打架"；多离谱算离谱，让分布自己告诉你（ elbow 在哪）。

**细节**：冲突得分 $c(x)=\max_i z_i(x)-\min_i z_i(x)$。阈值 $\tau$ 的确定：① 画 $c(x)$ 的直方图 + KDE；② 若有双峰，两峰间谷值为 $\tau$；③ 若单峰长尾，用肘部准则或 **POT**（超越阈值建模，Pickands, 1975）：对 $c$ 的尾部拟合广义帕累托分布，取形状参数稳定的起始点为 $\tau$。报告"冲突率–阈值曲线"，而非单一数字。

**依据**：固定阈值（0.5）毫无依据且量纲依赖；数据自适应阈值是聚类数确定（Thorndike, 1953 elbow）与极值理论的标准做法。给曲线的好处：结论对阈值稳健（在 $\tau\in[2,5]$ 区间结论不变），这正是"消解规则可靠"的证据。

### 4.3 成因分析

对冲突样本：① 按域给出冲突率排名（预期 github > arxiv > wikipedia）；② 对高冲突样本做**指标对联合分布**检查（fineweb_edu 高 × ad_en 高 = 营销式科普；modernbert_reasoning 高 × fluency_en 低 = 代码/公式密集文本）；③ 卡方检验"冲突 × 域"独立性。

### 4.4 消解规则（两套，互为补充）

**消解 = 重新算分时对打架的指标"降权/惩罚"，而不是删掉矛盾信息。**

**规则 A：Huber 稳健加权。** 对 $|z_i|>\tau$ 的极端指标降权 $w_i=\min(1,\tau/|z_i|)$，再用 $w_j$ 替换 CRITIC 权重算修正分 $\tilde Q$。依据：稳健统计 M-估计（Huber, 1964）——冲突的本质是"该指标对这篇文档不适用"，适用性表现为 z 分数是否落在正常范围；与其让不适用的指标一票否决或照样平均，不如按超出程度连续降权。

**规则 B：因子调和平均。** 先做因子分析（主轴因子法 +  promax 斜交旋转，允许因子相关）提取 3–4 个公共因子；单文本内因子得分极差 > 阈值记为因子级冲突；合成时对冲突因子取**调和平均** $\tilde Q=\left(\frac{1}{m}\sum_k F_k^{-1}\right)^{-1}$，一致因子取算术平均。依据：调和平均对极小值极度敏感（调和平均 $\le$ 几何平均 $\le$ 算术平均），能表达"质量由短板决定"；因子级消解比指标级更抗噪（先聚类 22 维到 3–4 维再判冲突，误判率下降）。

**例子**：一篇高广告含量的"软广科普文"：fineweb_edu=0.95（像教材）、ad_en 补转换后=0.02。算术平均 ≈ 0.5 → "还行"；Huber 降权后广告因子话语权大降、调和平均后 $\tilde Q\approx0.2$ → "低质"。后者与 FineWeb-Edu 的一票否决式过滤实践一致。

### 4.5 扩展集复检（题目强制）

同一管线跑 A2（arxiv）/A3（github）全量，比较：① 域级冲突率是否与抽样集排序一致（Spearman）；② 主要成因（top 指标对）是否复现。预期发现：抽样集按域等比例抽样，极端样本占比被稀释，冲突率低于全量——这本身是"抽样偏差"的量化证据，写进论文。

## 5. 域级聚合与跨集对照

**大白话**：先给每篇打分，再把一个域里所有文档的分"合成一个代表值"；用"中间水平"代表而非"平均水平"，因为语料质量分布总是歪的。

**细节**：域级 $\bar Q_d=\text{med}\{Q(x): x\in d\}$，同时报告 token 加权均值 $\sum t_x Q(x)/\sum t_x$（$t_x$ 为文档 token 数）作对照；抽样集（A1）与扩展集（A2/A3）用**同一组权重、同一归一化锚点**计算，输出 7 域 × 3 集对照表 + 差异效应量（Cohen's d）。

**依据**：① 中位数对长尾稳健（与 2.1 同）；token 加权回答"若按体量随机抽一个 token 期望质量"，两种口径分别服务"数据源筛选"与"训练贡献"两种用途。② **同一管线**是对照成立的前提——若对扩展集重估权重/重定 Min-Max 端点，差异中就混入了"管线差异"，无法归因于抽样偏差。③ 题目强制："须使用全量质量信号……给出其域级 $Q$ 且与抽样集结果对照"。

## 6. 领域配比建模（A4–A15）

### 6.1 为什么先做 clr 变换

**大白话**：17 个百分比加起来恒等于 100%，你涨我就跌，这样的数据直接回归会算出假关系——先把"比例"换成"和对数比"，解除捆绑。

**细节**：clr 变换 $z_i=\ln(p_i/g(\mathbf p))$，$g(\mathbf p)=(\prod_i p_i)^{1/17}$；回归在 $z$ 空间进行，预测时逆变换回单纯形。稳健性对照：ilr 变换（正交，无坐标冗余）。

**依据**：成分数据（compositional data）的闭合效应会产生伪相关与负偏差——Aitchison（1982, 1986）建立的成分数据统计理论指出，成分数据的合理几何是 Aitchison 几何，clr/ilr 是其坐标映射；RegMix 原文直接对配比做线性回归，未处理闭合效应，这是本方案相对文献的**改进点**（预期检验集 RMSE 下降即是证据）。例子：某配方 arxiv 从 0.3→0.31 必然伴随其余 16 域合计 −0.01，OLS 会把"此消彼长"的机械负相关误读为领域间的替代关系。

### 6.2 回归形式：线性（对数空间）为主线

**大白话**：配比每个域加一点减一点，对 Loss 的影响大致是"按域线性叠加"的，先试试最简单的线性账。

**细节**：对每个验证域 $v\in\{13\ 个有 Loss 列的域\}$：
$$L_v=\exp\!\Big(b_v+\sum_{i=1}^{17}\beta_{v,i}\,z_i+\varepsilon\Big)\quad\text{即}\quad \ln L_v=b_v+\sum_i \beta_{v,i} z_i+\varepsilon.$$
用 A4/A5 的 512 组训练，Huber 损失（对异常配方稳健）。备选：梯度提升（XGBoost）作非线性对照，用于捕捉交互；论文报告二者在检验集上的对比。

**依据**：① RegMix（Xia et al., ICML 2024）在同样数据上验证了线性模型的可预测性，512 组对 17+1 个参数充足；② 在 clr 坐标下线性形式天然满足"配比和为 1"的不变性（clr 坐标和恒为 0，平移不变）；③ 线性模型系数 $\beta_{v,i}$ 有明确含义（第 $i$ 域对验证域 $v$ 的边际贡献），这是题目"分析各领域及其组合对性能的影响"所需要的可解释性；树模型作对照可检验交互效应是否存在，但不作主模型（系数不可解释）。

### 6.3 无 Loss 的 4 个域（nih_exporter / enron_emails / europarl / philpapers）

保留为解释变量，理由：它们是配比的组成部分（clr 坐标需要全 17 维）；无法单独评估不代表没有间接效应（其占比变化通过其余域的相对配比起作用）。论文说明该处理，并给出敏感性分析：把 4 域合并为"其他"后的结果对比。

### 6.4 是否引入质量分 $Q$：引入，且给出论证链

**大白话**：同样的课时表，用"好教材"和"烂教材"效果不同——所以配比模型里要再乘一个"教材质量折扣"。

**细节**：经 A16 映射把 17 配方域挂到 7 质量域（direct 直接用、near_direct 用、inferred 标注降级并做敏感性），加入质量交互项：
$$L_v=\exp\!\Big(b_v+\sum_i \beta_{v,i} z_i+\lambda\sum_i p_i\big(1-\bar Q_{d(i)}\big)+\varepsilon\Big).$$
检验 $\lambda$ 的显著性（bootstrap 置信区间）。

**依据**：① 赛题背景明说"数据质量 $Q$ 与领域配比 $\mathbf p$ 对模型能力具有不可忽视的作用"（OpenScholar 案例）；② 问题二要求把 $Q$ 做成"有效数据乘子"，问题一若证明配比模型中 $\lambda>0$ 显著，就是为问题二的 $h(Q,\mathbf p)$ 形式提供的**附件内证据**；③ 用 $1-\bar Q$ 而非 $\bar Q$：使"质量折扣"非负、且高质量域（$\bar Q\to1$）折扣→0，模型退化为纯配比模型，逻辑干净。反方风险也要写进论文：A1 质量信号来自 SlimPajama 独立标注体系，与 RegMix 的 The Pile 语料并非同源，映射带来测量误差——用 A16 的 mapping_type 分层给出 $\lambda$ 的上下界。

### 6.5 检验集验证（A6–A11）

三套检验集（1M/60M/1B 参数规模，256+256+64 组）直接预测，报告每验证域的 R²、RMSE、MAE 与平均排名；重点看：① 跨规模系数是否稳定（1M 拟合→60M/1B 检验误差是否显著增大）；② 质量交互项是否提升检验集表现（消融：有/无 $\lambda$ 项）。

### 6.6 外推表稳健性（A12–A15，题目强制）

**大白话**：小锅试出来的菜谱，直接放大到大锅要变味——要么证明菜谱尺度不变，要么把"变味规律"也建进模型。

**细节**：A12–A15 是 10B/70B 尺度的**预估** Loss（幂律外推生成，非观测，论文须标注）。步骤：① 用 1M 拟合系数直接预测 est Loss，量化系统性偏差；② 用 1M/60M/1B 三套检验集估计系数随尺度 $N$ 的漂移（如对 $\beta_{v,i}$ 拟合 $\beta_{v,i}(N)=\beta_{v,i}^{0}(N/10^6)^{\rho}$）；③ 代入尺度修正后重预测 est 表，比较误差收窄幅度；④ 用 Spearman 排名相关 + 灰色关联度给出"外推结论稳健性排序"（哪些验证域的结论跨尺度稳、哪些不稳）。

**依据**：标度律跨 4 个数量级（1M→10B/70B 参数）保持系数完全不变是强假设；RegMix 原文也只做到 1B 实验。拒绝页眉陷阱"直接套用原系数无需重新估计"——跨尺度外推必须给出偏差证据或修正机制，这也是问题二、三"百亿外推"（B9/B10）的前置演练。
