# 问题二规格说明

> 版本：2026-09-24。本文定义问题二的输入、建模口径、输出接口与验收条件。赛题要求以《算力约束下提升大语言模型能力的资源配置建模.docx》为准；已实现行为以 `src/code_q1/q2_00_reverse_engineering.py`、`src/code_q2/` 和现有 `src/outputs_q2/` 为准；《分析说明.md》用于解释方法与结果。本文将已实现部分和待补齐部分分开写，现有 CSV/JSON 数值是产物基线，不代表本次重新运行。

## 1. 目标与范围

问题二须交付一条可估计、可检验的广义标度律，解释参数量 $N$、训练 token 数 $D$、数据质量 $Q$ 和领域配比 $\mathbf p$ 如何影响验证交叉熵损失 $L$；分析边际效用与弹性、质量与扩参的等效替代条件、领域间的局部迁移关系，并把冻结的模型参数交给问题三、四使用。

附件 A 的信息只通过问题一接口进入，不在问题二重复读取 A 原始文件。经典 $N,D$ 基线以 B1 为主；B2 或 B3 至少使用一项做检验，B4/B5 须做跨族或文献对照，质量项使用 B6 或 B7/B8，百亿参数以上外推须结合 B9/B10。B2、B6–B8 的半合成性质及 B10 的估算性质必须在图表与论述中标明。

当前代码完整实现的是 **$L(N,D,Q)$ 三变量核心**及其解析命题；问题一配比信息在论文中经 $Q_B(\mathbf p)$ 和迁移矩阵解释，在问题三的副口径中另有配比乘子。`src/code_q2/` 目前没有可调用、已标定的 $L(N,D,Q,\mathbf p)$ 四变量函数，也没有相应的 P2 配比接口。因此不能把“同时包含四变量的联合律已在问题二估计并验证”写成现有代码结果。

## 3. 建模与估计规范

### 3.1 逆向审计与证据分层

入口：[q2_00_reverse_engineering.py](../../src/code_q1/q2_00_reverse_engineering.py)。在 B1 的 1,176 行上拟合 $L_0$，并用它分解 B7 的残差 $\Delta=L-L_0$；检验 $\Delta$ 对 $(1-Q)$ 的线性结构以及 B8 的同点差异。现有逆向表为 [T8_reverse_engineering.csv](../../src/outputs_q1/tables/T8_reverse_engineering.csv)：B7 的组均值线性 $R^2=0.9974$，质量残差尺度约 0.051；B8 同点相关约 $-0.026$。这些诊断支持候选形式与数据分层，不构成“真实训练实验发现了质量地板”的独立证据。

### 3.2 两步拟合与形式选择

入口：[q2_01_fit.py](../../src/code_q2/q2_01_fit.py)。第一步只在 B1 上拟合

$$L_0(N,D)=E+A N^{-\alpha}+B D^{-\beta}.$$

代码在 $\alpha=0.300,0.302,\ldots,0.380$ 与 $\beta=0.240,0.242,\ldots,0.320$ 的网格上搜索，每个网格点用最小二乘求 $(E,A,B)$，按训练 SSE 取最优。这里没有使用 Huber 损失、log-Loss 拟合或“只取尾段检查点”；其他文档中的这类方案不能写成当前实现。

第二步固定 $L_0$，在 B7 的 450 行上比较五种质量形式：

| 代号 | 质量项或有效数据量 | 当前比较方式 |
|---|---|---|
| M-add | $\Delta=(1-Q)(k_0+k_1N^{-\alpha})$ | 最小二乘估计 $k_0,k_1$。 |
| M-add0 | $\Delta=k(1-Q)$ | 最小二乘估计 $k$。 |
| M-mult | $D_{\rm eff}=DQ^\gamma$ | 搜索 $\gamma$，每次重估数据项系数。 |
| M-lin | $D_{\rm eff}=D[q_0+(1-q_0)Q]$ | 搜索 $q_0$，每次重估数据项系数。 |
| M-exp | $D_{\rm eff}=D\exp[-\gamma(1-Q)]$ | 搜索 $\gamma$，每次重估数据项系数。 |

五折交叉验证按随机**行**分割，固定同一个 B1 基线，各折计算原始 Loss 尺度的 RMSE 后取均值。B7 的相邻网格点和同规模点可能分到不同折，因此该 CV 只检验网格内预测，不能替代按模型规模或数据源留出的外推检验。选中的 M-add 形成

$$\boxed{L(N,D,Q)=E+[A+k_1(1-Q)]N^{-\alpha}+BD^{-\beta}+k_0(1-Q).}$$

$Q=1$ 时退化为 B1 的经典形式。这是模型设计约束和 B7 网格共同支持的性质；$Q$ 只能在适用区间和同一 Loss 口径下解释。

### 3.3 参数不确定性与跨源检验

脚本做 500 次**案例重抽样**：分别有放回重抽 B1、B7 的行；每次固定原估计的 $\alpha,\beta$，重估 $(E,A,B,k_0,k_1)$。它不是代码注释所称的“残差 bootstrap”，也没有覆盖 $\alpha,\beta$ 的选择不确定性、半合成机制误差或跨源分布漂移。`T22_params_ci.csv` 的 95% 区间只按此条件口径解释。

冻结主模型后，B2、B4、B5、B10 均按 $Q=1$ 预测，分别输出 Pearson、Spearman、平均残差 `observed − predicted` 与 RMSE。B2 半合成只作族外参考；B4/B5 因验证语料不同主要检验趋势；B10 是估算表，只检验外推公式的一致性。对 B9 的模型配置分布、训练 token/参数比和 B10 覆盖范围须另给联合表或说明，不能以 B10 低 RMSE 替代。

### 3.4 质量与配比的跨附件接口

问题一的域质量 $\hat Q_i$ 来自 `P1_Q_domain.csv` 的 `Q_final`，候选配比 $\mathbf p^*$ 来自 `P1_p_star.csv` 的 `p_star_eqweight`。论文采用的跨源锚定假设为

$$Q_B(\mathbf p)=\frac{\sum_{i=1}^{17}p_i\hat Q_i}{Q_{\rm ref}},\qquad Q_{\rm ref}=0.5608.$$

$Q_{\rm ref}$ 被解释为 Pile 原始配比语料的加权质量，因而 $Q_B=1$ 对应 B1/B7 的基线。它是**桥接假设**，不是 B 表直接观测到的问题一质量分；当前 `P2_scaling_law.json` 只在 `Q_anchor` 文字中记录该常数，没有可机读的数值字段、误差区间或对不同锚点的敏感性输出。某些单域 $Q_B>1$，已超出 B7 的 $Q\le1$ 网格；若带入四变量预测，须明确是截断到 1 还是进行有标记的外推，不能默默混用。

问题一的 `P1_f_p_coefficients.csv` 给出 $\log \hat L_v(\mathbf p)=b_v+\boldsymbol\beta_v^\top\operatorname{clr}(\mathbf p)$；`P1_transfer_matrix.csv` 给出均匀配比附近的 17×13 局部切向效应。非对角负值可读为“增配域 $i$ 时验证域 $v$ 的预测 Loss 下降”，正值反之；因单纯形上其他份额同时调整，这只是给定参照配比的净边际效应，不能单凭符号证明两个领域有因果互补或替代。论文所述领域关系应注明这一边界。

`q2_01_fit.py` 文件头提出过配比修正 $s[\log L_{\rm tgt}(\mathbf p)-\log L_{\rm tgt}(\mathbf p^*)]$，但正文代码未估计 $s$、未读取 P1 配比接口，也未输出联合预测函数。问题三副口径 [q3_03_mixture_joint.py](../../src/code_q3/q3_03_mixture_joint.py) 则使用问题一缓存的 GBDT 构造独立乘子 $m(\mathbf p)$，与这个拟议的加性修正不是同一个已标定模型。若将“四变量同时进入”作为代码验收项，应先确定唯一联合公式、标定方法、适用域和留出检验，并输出可复用接口；当前应把配比作用称为**结构桥接与单独的配比效应分析**。

## 4. 解析命题与数值互验

入口：[q2_02_theory.py](../../src/code_q2/q2_02_theory.py)。记 $\widetilde A(Q)=A+k_1(1-Q)$，则：

1. **边际效用与弹性**：$\partial L/\partial N=-\alpha\widetilde A N^{-\alpha-1}$，$\partial L/\partial D=-\beta BD^{-\beta-1}$，$\partial L/\partial Q=-(k_0+k_1N^{-\alpha})$。对应弹性为 $\varepsilon_N=-\alpha\widetilde A N^{-\alpha}/L$，$\varepsilon_D=-\beta BD^{-\beta}/L$，$\varepsilon_Q=-Q(k_0+k_1N^{-\alpha})/L$。它们是对 $N,D,Q$ 的相对变化敏感度；“质量约为规模的 4 倍”只针对指定点 $(10^{10},10^{12},0.9)$，不是全域常数。配比的边际效应应从 P1 的单纯形切向矩阵读取，不能把闭合约束下的某一份额当作独立变量求偏导。
2. **等效替代**：固定 $D$，让扩参至 $N'$ 与质量提高 $\delta$ 达到同一 Loss，得到 $N'=N[1-\delta(k_0+k_1N^{-\alpha})/(\widetilde A N^{-\alpha})]^{-1/\alpha}$。须有 $0\le Q,Q+\delta\le1$ 且方括号内严格为正；否则不存在有限的 $N'$。现有脚本对 $N=10^8,10^9,10^{10}$ 和 $Q=0.5,0.7,0.9$ 的 $\delta=0.1$ 做解析与数值互验。
3. **质量地板**：$N,D\to\infty$ 时 $L\to E+(1-Q)k_0$；若仅令 $N\to\infty$ 而 $D$ 固定，仍保留 $BD^{-\beta}$。这是**所选模型的条件性推论**，绝对数值受半合成质量数据和锚点假设限制。
4. **固定质量的算力最优解**：在 $6ND=C$ 下，$N^*=[\alpha\widetilde A/(\beta B)]^{1/(\alpha+\beta)}(C/6)^{\beta/(\alpha+\beta)}$，$D^*=C/(6N^*)$，且 $\partial N^*/\partial Q<0$。该闭式解只含基础训练成本；问题三加入提质、注意力成本后另行优化。

`T24_equiv_substitution.csv` 与 `T25_compute_optimal.csv` 保存解析/数值互验；`T26_elasticities.csv`、`T27_quality_floor.csv` 保存示例数值。解析与数值方法复用同一拟合式，因此检验的是推导和求解器，不是独立的数据验证。

## 6. 当前实现待补齐与复现条件

1. **联合律缺口。**题目要求同时刻画 $N,D,Q,\mathbf p$。现有 P2 接口只含三变量核心；应确定并实现配比修正，显式规定 $Q$ 与 $Q_B(\mathbf p)$ 如何同时使用，标定配比项且避免同一质量效应计两次，并用 A 的留出配比实验或其他适当数据检查。未完成前，论文应将配比关系标为结构假设和 P1 迁移证据。
2. **B9/B10 联合外推缺口。**现有 `T23` 只评估 B10。应读取 B9，按模型名并核对 $N,D$ 连接 128 个交集配置，说明另外 4 个 B9 模型为何无 B10 对照，按规模区间报告配置覆盖和外推误差；B10 的数值仍只能标为估算一致性。
3. **锚点与适用域。**$Q_{\rm ref}=0.5608$ 目前是文字硬编码；应保存机器可读来源与敏感性。高质域的 $Q_B>1$ 超出 B7 网格，需规定截断或外推口径并报告影响。问题一域质量本身的桥接误差尚未传播到 P2 的区间。
4. **不确定性表述。**代码的 500 次是案例重抽样，$\alpha,\beta$ 固定；`noise_sigma=0.051` 直接写入 JSON，而非从该脚本的残差字段自动生成。论文与分析说明中若称“残差 bootstrap”或“全参数区间”，应改文案或改计算。
5. **路径与运行环境。**`q1_00_common.py` 的 `ROOT` 固定为旧环境 `/sessions/gifted-quirky-euler/mnt/HaJX-main`，B 输入写成 `ROOT/real_attachments/B_scaling_laws`；当前仓库实际是 `附件/B_scaling_laws/`。直接运行会找不到数据；复现前应改为相对源码定位或可配置路径。需 Python 3、NumPy、pandas、Matplotlib；本问题现有实现不依赖 SciPy。

主链运行顺序为 `q2_00_reverse_engineering.py` → `q2_01_fit.py` → `q2_02_theory.py`。在路径修正后，验收须检查：B1/B7 拟合与 B2/B4/B5/B10 只检验的边界不混淆；B6 不被当作 B7 的独立验证；B8 不混入主拟合；单位换算正确；所有 P2 参数与 Q3/Q4 读取一致；公式退化条件、有限替代条件、解析/数值互验成立；半合成和估算结果在论文中保持性质标签。若修改联合律或 P2 参数，须同步重算问题三、四及论文相关图表。
