# 问题二：A 侧真实 \(Q\) → B 侧自定义 \(Q\) 的映射推导（修订版）

> 日期：2026-09-24  
> 依据：赛题正文问题二、《数据说明》、问题一接口 `P1_Q_domain.csv`、`T5_lambda_interaction.csv`、B6/B7 半合成网格、`scaling_baseline.csv`、问题二主模型接口 `P2_scaling_law.json`  
> 相对旧稿 `问题二_Q映射推导.md` 的主要修正：质疑「\(Q_B=1\Leftrightarrow\) Pile」锚点，并给出题面语义锚点（完美教材）作为主口径候选。

---

## 一、问题陈述

问题一得到基于质量信号的真实合成分 \(q\)（样本级 / 域级），17 域级均值约在 \([0.35,\,0.72]\)。

附件 B 中 B6–B8 的 `Q_score` 是命题人设定的自定义质量变量 \(Q_B\in[0.1,1]\)，用于把质量纳入广义标度律。

**核心问题**：如何建立映射 \(\varphi: q\mapsto Q_B\)？是否应以 A、B 两侧的 Loss 为桥梁？是否还有其他路径？

---

## 二、结论摘要

| 判断 | 说明 |
|------|------|
| 方向对 | Loss 是 A、B 唯一共同可观测结果；题面要求「提出可检验的假设」统一两边，故用 Loss 作桥梁符合题意 |
| 不够 | 映射至少有「位置 + 尺度」两个自由度；Loss 最多约束尺度，且在本题 A 侧数据上**尺度也无法识别**（符号相反） |
| 位置 | 必须用 Loss **以外**的桥：题面语义 / 语料身份 / \((N,D)\) 锚点 |
| 形式 | 由「聚合一致性」推出 \(\varphi\) 必须是**仿射** \(\varphi(q)=a+bq\) |
| Loss 角色 | **检验假设，不标定参数** |
| 现有方案需修订 | \(Q_B=q/0.5608\) 依赖「\(Q_B=1\Leftrightarrow\) Pile」，该前提经核对站不住；更符合题面的读法是「\(Q_B=1\Leftrightarrow\) 完美教材」 |

正确表述：

> 映射 = 聚合一致性（定形式）+ 题面/构造锚点（定位置）+ 零点/支撑锚（定尺度）+ Loss 检验 + 尺度敏感性。

## 三、符号与 B 侧模型

- \(q_d\)：问题一的域级真实质量分  
- \(\bar Q(p)=\sum_d p_d q_d\)：配比 \(p\) 下的语料质量  
- \(Q_B=\varphi(q)\)：待求映射，要求单调递增  
- B 侧主模型（`q2_01_fit.py` 嵌套族裁决结果）对 \(Q_B\) 线性：

\[
L_B(N,D,Q_B)=L_0(N,D)+\Phi(N,D)\,(1-Q_B),\qquad
\Phi=\kappa_N A N^{-\alpha}+\kappa_D B D^{-\beta}+k_0>0
\]

当前点估计（见 `P2_scaling_law.json`）：\(\kappa_N\approx0.431\)，\(\kappa_D\approx0.140\)，\(k_0\approx0.141\)。

---

## 四、第一步：映射的形式必须是仿射的

问题一把样本或域的质量按 token 占比线性聚合成 \(\bar Q(p)\)。若 B 侧质量惩罚也按 token 可加，则「先映射再聚合」与「先聚合再映射」必须给出同一结果：

\[
\sum_d p_d\,\varphi(q_d)=\varphi\Big(\sum_d p_d q_d\Big)\qquad\forall p\in\Delta^{16}
\]

左边对 \(p\) 的依赖只能通过 \(\sum_d p_d q_d\) 发生。17 个域里 \(q_d\) 至少有 3 个不同取值，因此 \(\varphi\) 在 \(q\) 的取值区间上必须是仿射的。写成锚点形式：

\[
\boxed{Q_B=1-b\,(q^*-q)}
\]

其中 \(q^*\) 是映射到 \(Q_B=1\) 的真实质量分（位置参数），\(b>0\) 是尺度参数。

**推论**：用 Loss 拟合任何非线性 \(\varphi\)（如分位秩、sigmoid）都会破坏问题一的聚合口径，不可取；分位映射只能作对照。

---

## 五、第二步：Loss 能识别什么（「不必令 Loss 相等」的正确形式）

任何实际评测管线 \(e\)（分词器、验证集不同）的 Loss 都带有系统偏移 \(c_e\)：

\[
L^{e}=c_e+L_0(N,D)+\Phi(N,D)\,b\,(q^*-q)
\]

### 5.1 差分消去偏移 → 可定尺度 \(b\)

在同一管线、同一 \((N,D)\) 下比较两种语料：

\[
L^e_2-L^e_1=-\Phi(N,D)\,b\,(q_2-q_1)
\quad\Rightarrow\quad
b=-\frac{\partial L^e/\partial q}{\Phi(N,D)}
\]

这里**不需要** A、B 两侧 Loss 相等，只需要「质量的边际效应」相等。若偏移是乘性的，改用 \(\partial\ln L\) 同样成立。这就是「以 Loss 为桥」应有的形式。

### 5.2 水平值才能定位置 \(q^*\)

\(q^*\) 需要 \(c_e=0\)，即与 B1 同一评测管线下的 Loss 水平。A 侧（RegMix 管线）做不到这一点。

### 5.3 A 侧实测：差分桥给出的符号是反的

`q1_05_mixture.py` 已在控制 \(\mathrm{clr}(p)\) 后估计质量偏效应：

\[
\ln L_v=\dots+\lambda_v\sum_i p_i(1-q_{d(i)})
\]

理论预期 \(\lambda>0\)（低质量占比越高，Loss 越高）。`T5_lambda_interaction.csv` 实测：13 个验证域中 10 个显著，其中 **9 个为负**，只有 arxiv 为正。代入上式会得到 \(b<0\)，违反单调性。

**原因**：A 侧 Loss 差异主要来自「训练配比 ↔ 验证域匹配」，而 \(\bar Q\) 与配比特征高度共线。

**结论**：A 侧 Loss 只能作为**证伪检验**写进论文。质量效应的形状与强度只能来自 B6/B7（半合成，须标注局限）。这样 \(p\) 项与 \(Q\) 项各有独立信息源，不重复计数。

| 尺度 | \(\mathrm{corr}(\bar Q,L)\) | A 侧 \(dL/d\bar Q\) | B7 同尺度 \(dL/dQ_B\) |
|------|----------------------------|---------------------|------------------------|
| 1M   | +0.21                      | +1.50               | （B 无此尺度）         |
| 60M  | +0.16                      | +0.88               | ≈ −0.55（70M）         |
| 1B   | +0.35                      | +0.85               | −0.34                  |

另有四条硬障碍：方向相反；\(\bar Q\) 与 \(\bar f(p)\) 共线导致不可识别；A/B 绝对 Loss 水平不可比（1B 处 A∈[2.11,2.44]、B7∈[2.25,3.05]）；B 的 \(Q_B\) 是均匀网格自由变量，生成过程里没有 A 侧质量公式，不存在可反推的「真实映射」。

## 六、第三步：位置参数 \(q^*\)——现有方案需修订

现有方案取 \(q^*=\bar Q(p_{\mathrm{pile}})=0.5608\)，依据是「B6/B7 在 \(Q=1\) 处回到 B1，而 B1 是在 Pile 上训练的 Pythia」。核对后发现两个问题：

1. **B1 的参数就是 Chinchilla 原文常数**（\(E=1.69,\,A=406.4,\,\alpha=0.34,\,B=410.6,\,\beta=0.28\)），Hoffmann 等人在 MassiveText 上拟合，**不是** Pile。「\(Q_B=1\) 回到 B1」只能说明 \(Q_B=1\) 对应经典公式本身。  
2. **真实 Pythia 的 Loss 比该公式高很多。** `scaling_baseline.csv` 中 8 个真实 Pythia 点平均比 B1 公式高 0.44，反推出的 \(Q_B\approx-0.09\)，落在 B 支撑之外。若「\(Q_B=1\Leftrightarrow\) Pile」成立，真实 Pythia 应贴着 B1。

题面另有两处提示指向另一种读法：

- 问题二：「当教材趋于完美时，新公式退化为经典形式」⇒ \(Q_B=1\) = 完美教材，而非 Pile 质量。  
- 问题三：「基线质量 \(Q_0\) 可由附件 A 的质量评分给出，将质量由 \(Q_0\) 提升至 \(Q\in(0,1]\)」⇒ 问题一分数可直接作为 \(Q\) 的尺度。

### 两种锚点对照

| 锚点 | \(q^*\) | Pile / \(p^*\) 的 \(Q_B\) | 依据 | 后果 |
|------|---------|--------------------------|------|------|
| (a) 构造标签：\(Q_B=1\Leftrightarrow\) Pile（现行） | 0.5608 | ≈ 0.99 | 数据说明标注 B1 为 Pythia | arxiv → 1.28，超出支撑；问题三 \(Q_0\approx0.99\)，几乎无提质空间 |
| (b) 题面语义：\(Q_B=1\Leftrightarrow\) 完美 | 1（或样本最大 0.886） | ≈ 0.55（或 0.63） | 问题二、三原文 | 17 域落在 [0.35, 0.72]，在 B 支撑内；问题三有实质性提质空间 |

### 真实模型残差旁证（仅定性）

用 \(\hat Q_B=1-(L_{\mathrm{obs}}-L_{B1})/\Phi\)，按模型族取中位数：

| 族 | 隐含 \(Q_B\)（中位） |
|----|---------------------|
| Yi | 0.89 |
| LLaMA | 0.63 |
| Mistral | 0.46 |
| GPT-2 | 0.43 |
| Qwen2 / Gemma / Cerebras | ≈ 0.37 |
| Pythia / BLOOM / OPT | ≈ 0 或负 |

受分词器与验证集差异污染，**不能用于标定**。但量级与读法 (b)（真实语料 \(Q_B\) 约 0.3–0.7）更吻合，与读法 (a)（Pile 训练模型应接近 1）不符。

**建议**：以 (b) 为主口径、(a) 为敏感性。该选择对问题三影响大（\(Q_0\) 从 0.99 → 约 0.55），结构性转移结论可能随之改变，需组内确认。

## 七、第四步：尺度参数 \(b\)

\(q^*\) 确定后仍剩 \(b\)：

| 路径 | 做法 | 本题可用性 |
|------|------|------------|
| 零点锚 | \(q=0\Leftrightarrow Q_B=0\) ⇒ \(b=1/q^*\)；(b) 且 \(q^*=1\) 时映射为恒等 \(Q_B=q\)；(a) 时即现行 \(q/0.5608\) | 主方案 |
| 支撑匹配 | 样本级 \(q\) 低分位 ↔ B 网格下界 0.1（P1=0.120，P5=0.208） | 敏感性 |
| Loss 差分 | \(b=-\theta/\Phi\) | 理论最优，A 侧符号错误，只作检验 |

## 八、除 Loss 以外的路径汇总

1. **题面与构造约束**：用「完美 ⇔ 经典式」与「\(Q_0\) 来自 A、\(Q\in(0,1]\)」确定位置（依据最硬）。  
2. **仿射聚合一致性**：确定映射函数形式（第四节）。  
3. **分布 / 分位匹配**：确定尺度；若把 \(Q_B\) 当作分位秩 \(F(q)\) 则违反仿射性，只能作对照。  
4. **真实模型残差反推**：第六节旁证，受分词器混杂影响，只作定性支持。  
5. **文献锚点**：通过有效数据倍数确定尺度。

---

## 九、Loss 在映射中的正确角色：检验

1. **锚点检验**：B6/B7 在 \(Q_B=1\) 与 B1 的差异 ≈ 0.004，通过（说明 \(Q_B=1\) 对应经典式）。  
2. **符号检验**：映射预测 A 侧 \(\partial L_A/\partial\bar Q=-b\Phi<0\)，实测为正 → A 侧 Loss 差异由配比–验证匹配主导，已被 \(\bar f(p)\) 吸收；**质量效应量级只能来自 B6/B7**（半合成，须标注）。  
3. **过度识别**：若做受限配比模型后再估 \(b\)，应检验 60M 与 1B 是否一致。  
4. **敏感性**：在所选 \(b\) 区间上报告弹性与「\(Q+0.1\) 等效 \(\Delta N\)」的变化。

## 十、推荐写入论文的表述

### 主口径（建议采用题面语义锚点 (b)）

\[
Q_B=\varphi(q)=q\qquad\text{（若取 }q^*=1\text{ 的零点锚）}
\]

或更一般地：

\[
Q_B=1-b\,(1-q),\qquad b=1\text{（零点锚）},\quad b\in[1,\,b_{\mathrm{P5}}]\text{（敏感性）}
\]

### 敏感性口径（现行构造锚点 (a)）

\[
Q_B=\frac{q}{Q_{\mathrm{ref}}},\qquad Q_{\mathrm{ref}}=\bar Q(p_{\mathrm{pile}})=0.5608
\]

### 依据链

1. H1 聚合一致性 ⇒ \(\varphi\) 仿射；  
2. H2 题面语义：\(Q_B=1\Leftrightarrow\) 经典式 ⇔ 完美教材（主）；构造标签「Pile」作敏感性；  
3. 零点锚 \(q=0\Leftrightarrow Q_B=0\) ⇒ 定 \(b\)；支撑匹配作敏感性；  
4. Loss 用于检验（锚点重合、符号、过度识别），不用于最小二乘标定 \(\varphi\)；  
5. 下游「质量提升 0.1」须声明是 \(Q_B\) 口径，对应 \(\Delta q=0.1/b\)。

### 与问题二分工

| 项 | 信息来源 |
|----|----------|
| 配比项 \(\bar f(p)\)、\(s(N)\) | 附件 A / 问题一 Loss |
| 质量形状与强度 \(\kappa_N,\kappa_D,k_0\) | B6/B7（半合成） |
| 质量口径 \(\varphi\) | 题面语义锚点 + 仿射假设 |

## 十一、下游注意点

1. **「质量提升 0.1」须声明口径。** 题面等效替代应在 \(Q_B\) 下定义；弹性与等效替代随 \(b\) 线性缩放。κ、k0 在 B 口径下估计，**不受 \(\varphi\) 选择影响**。  
2. **\(Q_B>1\) 问题**（仅在锚点 (a) 下出现）。arxiv 等超出 B 支撑与问题三 \(Q\in(0,1]\)。问题二可外推并标注；问题三取 \(Q_0=Q_B(p^*)\approx0.99\)，在 \(Q\le1\) 内优化。锚点 (b) 下 17 域自然落在支撑内。  
3. **若改用 (b)，需同步改动**：`P1_Q_domain.csv` 的 `Q_B_calibrated`、`q3_00_model.py` 的 `Q_REF`/`Q0_MAIN`、`q2_01_fit.py` 的 `Q_anchor`、`sec1_4.tex` / `sec5_q2.tex` 的锚点假设。

## 附：一句话答「思路对不对」

> 「用 Loss 作桥梁」若指**检验** A/B 规律是否可统一到同一模型——正确，且符合题面。  
> 若指**用 A 与 B 的 Loss 方程反解 \(\varphi\)**——不正确；形式由聚合一致性定、位置由题面语义/构造锚点定、尺度由零点/支撑锚定，Loss 只负责检验与敏感性。  
> 现有 \(Q_B=q/0.5608\) 的方向仍可用作敏感性，但其「Pile 锚点」前提经数据核对站不住；更符合题面的主口径是 \(Q_B=1\Leftrightarrow\) 完美教材。
