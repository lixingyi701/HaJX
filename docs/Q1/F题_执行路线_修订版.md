## 0. 核对到的关键事实

### 0.1 列表型字段的正确压缩方式

| 字段 | 长度 | 真实含义 | 正确压缩方式 |
|---|---|---|---|
| `modernbert_{professionalism,readability,reasoning,cleanliness}` | 6 | 0–5 六档评分的 logits | softmax 后取期望分 \(\sum_k k\,\sigma_k\)，范围 0–5 |
| `qurater` | 4 | [Writing Style, Required Expertise, Facts&Trivia, Educational Value] | **拆成 4 个指标**，不可平均 |
| `ad_en` / `fluency_en` | 2 | 二分类 logits；ad 标签1=无广告，fluency 标签1=流畅 | softmax 取 \(P(\text{label}=1)\)，已是“越高越好” |
| `fineweb_edu` | 1 | 教育价值分 | 直接取值 |

22 个字段展开后恰好是 Meta-rater 的 **25 个评分器**（11 规则型 + 3 DSIR + 11 模型型）。

### 0.2 其他关键事实

- **DSIR** 三项按定义是 \(\log p(\text{doc})/q(\text{doc})\)，q 是源域 n-gram 模型 → 跨域直接比较不成立，域级 Q 聚合必须**域内标准化**。
- **A1 是 range-sampled**（连续区间抽样，见 `source_manifest.json`），不是随机抽样。A1 的 arxiv/github 子集来自 A2/A3 同一物理文件 → “扩展集与抽样集对照”= **抽样代表性检验**。
- A1 各域样本量：c4 10000、cc 9640、github 10000、stackexchange 10000、wikipedia 10000、arxiv 1419、**book 仅 171**。
- **A18**（138k 条 17 域原文）可对 11 个 RedPajama 规则型信号重算 → 把质量域从 7 个扩到 17 个，解决 A16 中 11 个 `inferred` 域问题。

## 1. 科学问题凝练

### 1.1 Meta-rater（ACL 2025，A1–A3 数据来源）

| 维度 | 内容 |
|---|---|
| **核心问题** | 多维评分器对同一文本判断不一致，如何合成为可用于选数据的标量 |
| **解法** | 随机权重 → 加权 Q_agg → 选 top 训小代理模型 → LightGBM 拟合权重→loss → 搜索最优权重 |
| **效果** | 1.3B/30B token 下比随机 +3.23%；收敛约 2×；25 评分器 > 11 > 4 |
| **他们报告但未深挖** | ① 学到的权重接近均匀（加权增益有限，覆盖更重要）；② 单域 CC 即便按质量选也全面下降 → **质量不能替代领域多样性**；③ Meta-rater 自述是 RegMix 的推广 |
| **我们的切入点** | 冲突结构与成因；规则型信号对代码/数学的系统性偏差；域级聚合 |

### 1.2 RegMix（ICLR 2025，A4–A15 数据来源）

| 维度 | 内容 |
|---|---|
| **核心问题** | 17 域配比空间是 16 维单纯形，域间交互复杂反直觉 |
| **解法** | 512 个 1M 代理模型 → 配比→loss 回归 → 单纯形内模拟找最优；假设**排名不变性** |
| **效果** | LightGBM Spearman：98.45%（1M）/ 98.64%（60M）/ 97.12%（1B）；线性约 90%/89%/88% |
| **发现** | Pile-CC 相关性最强；域间交互反直觉；配比效应超越标度律 |
| **我们的切入点** | 域级质量画像能否解释配比效应；排名不变性衰减；17×13 迁移矩阵；4 个无 loss 域的外溢 |

### 1.3 三个可检验科学问题

- **SQ1（合成与偏差）**：是否存在“评分器语义随域变化”的系统性偏差？  
  H1：规则型与模型型冲突集中在 github/arxiv；域内标准化后冲突率显著下降。

- **SQ2（排名不变性边界）**：配比→loss 规律在 1M→60M→1B 保持多少？  
  H2：Spearman 随规模单调下降但仍 >0.9；下降主要来自少数专业域。

- **SQ3（质量对配比效应的解释力）**：域级 \(Q_d\) 能否解释各域边际贡献？  
  H3：只能部分解释；剩余由域间迁移解释（Meta-rater“质量不能替代多样性”的量化版）。

## 2. 数据集对照与逐文件方案

### 2.1 前人问题是否存在 / 方法能否照搬

| 前人问题 | 我们数据中 | 能否照搬 |
|---|---|---|
| 多维评分合成 | 完全相同的 25 评分器 | Meta-rater 代理回归**不能**（无 GPU）→ 用 CRITIC + RegMix 表做权重合理性检验 |
| 评分器冲突 | A1 跨 7 域 + A2/A3 单域大样本 | Meta-rater 没做 → **我们的空白** |
| 配比→loss | A4–A11 就是他们的表 | **完整复现**作基线 |
| 跨尺度外推 | A12–A15 是出题方幂律外推 | 只做稳健性，不当验证 |
| 质量域≠配比域 | 7 vs 17，11 个 inferred | 两篇论文都没面对 → A18 自建 |

### 2.2 方法替代与预处理原则

- **无训练版 Meta-rater**：把 \(p\) 折成域级质量画像 \(\bar q(p)=\sum_i p_i q_{d(i)}\)，用 512 组 RegMix 做“质量画像→loss”回归，作权重合理性检验（主估计仍用 CRITIC）。
- **RegMix LightGBM + 单纯形模拟**：完整复现后再扩展。
- **方向统一**：正向 Min-Max，负向 \(1-x\)。负向候选：`frac_no_alph_words`、`top_2/3gram`、`numerical_chars`、`uppercase`。  
  `word_count`/`num_sentences`/`mean_word_length` 为**非单调** → 用“距域内中位数偏离”做成单峰后再归一。
- **重尾**：`word_count`、`num_sentences`、DSIR 先 log/分位数变换再 Min-Max。

### 2.3 逐文件处理清单

| 编号 | 用途 | 处理要点 |
|---|---|---|
| **A1** | 22→25 展开、CRITIC、样本级 Q、冲突主样本 | 流式读；content 只算长度；book 仅 171 条给置信区间 |
| **A2/A3** | 全量域级 Q；抽样代表性；冲突复现 | A1 上变换与权重**冻结**后套用；github 分块读；KS 检验 A1 子集 vs 全文件 |
| **A4/A5** | 配比回归训练（512） | 13 域 loss 各建模型 + 综合；p 原值（LGBM）与 clr(p)（线性）两套 |
| **A6–A11** | 三尺度检验 | Spearman/R²/RMSE 按尺度；1B 用 bootstrap；量化排名衰减（SQ2） |
| **A12–A15** | 外推稳健性 | 标注为幂律外推；只看最优配比排名稳定性 |
| **A16** | 域映射 | direct/near_direct 直接用；inferred 由 A18 补齐 |
| **A17** | 文本长度统计 | 解释 word_count 类指标的域偏 |
| **A18** | 原文 | ① 17 域重算 11 个 rps_* → \(Q_d^{\mathrm{rule}}\)；② 抽高/低/冲突样本人工核验 |

**A18 关键路径**：6 个 direct/near_direct 域同时有完整 25 维 Q 与自算 11 维 \(Q^{\mathrm{rule}}\) → 拟合 \(Q\approx\phi(Q^{\mathrm{rule}})\) → 应用到 11 个 inferred 域，得到带不确定性的 \(Q_d\)。

### 2.4 问题一三个子任务（修订）

#### (a) 质量评分 Q

1. 展开 25 指标 → 变换 → 方向统一 → **域内** Min-Max（处理 DSIR 域相对性与规则型域偏）。
2. 权重：CRITIC 主估计；对比 Meta-rater Table 11 权重、等权；报告三种权重下 Q 的 Spearman（预期 >0.95）。
3. 聚合：样本→域，报均值与 P10/P50/P90；A2/A3 全量 vs A1 子集对照。
4. 17 域 \(Q_d\)：6 域直接、11 域经 A18 校准，均带区间。

#### (b) 冲突消解

1. 25 指标分 4 组：规则型、DSIR、WanjuanCC、PRRC+QuRating+FineWeb；组内 Kendall W。
2. 冲突：两组域内分位数排名差 \(|\Delta\mathrm{rank}|>\tau\)，报告冲突率–τ 曲线；“结构性冲突”= 冲突方向在域内显著偏向一侧。
3. 成因：域×组对交叉表验证 H1；用 A17 + rps 定义解释（如 github 代码语法导致 `frac_no_alph` 高）。
4. 消解：域内标准化 + 结构性冲突组降权 + 冲突样本取组内中位数；A2/A3 复现。

#### (c) 配比建模

1. 复现 RegMix：线性 vs LightGBM，三尺度 Spearman，与论文数字对照。
2. **17×13 迁移矩阵** \(T_{ij}=\partial L_j/\partial p_i\)：自域效应、跨域迁移、4 个无 loss 域外溢。
3. 引入 Q：加 \(\bar Q(p)=\sum_i p_i Q_i\)，嵌套检验回答 SQ3。
4. 最优 \(p^*\)：Dirichlet 采样 + 模型预测 + top-k 平均。
5. A6–A11 按尺度报告；A12–A15 只报 \(p^*\) 排名稳定性。

## 3. 问题二三四与问题一的耦合

### 3.1 问题一固定产出（必须落盘）

| 产出文件 | 内容 | 下游用途 |
|---|---|---|
| **P1-Q_sample** | 样本级 Q + 25 维标准化分 | Q4 按能力维度解释任务 |
| **P1-Q_domain** | 17 域 \(Q_d\) 及区间、来源等级 | Q2 的 \(\bar Q(p)\)；Q3 的 \(Q_0\) |
| **P1-f(p)** | 配比→13 域 loss + 迁移矩阵 T | Q2 替代/互补；Q3 中 p 的 loss 项 |
| **P1-p*** | 最优配比及 \(\bar Q(p^*)\) | Q3 默认配比；Q2 参照点 |
| **P1-rank_decay** | 排名不变性随 N 的衰减曲线 | Q2 决定 p 进入标度律的位置；Q3 外推不确定性 |

### 3.2 问题二：广义标度律

用 A6–A11 检验 H4：\(\Delta L(p)\) 随 N 是否收缩（乘性→收缩，加性→不变），决定模型形式：

\[
L = E(p) + A N^{-\alpha} + B\,\big(D\cdot h(\bar Q(p))\big)^{-\beta}
\]

- \(h(Q)\) 由 B6–B8 估；尺度与 P1-Q_domain 对齐（写明单调映射假设）。
- 域间替代/互补直接用 T 矩阵，不另起模型。
- 验证：B1 主拟合；B2 或 B3；B4+B5；B6–B8；B9+B10（估算需标注）。
- 弹性 \(\varepsilon_x=\partial\ln L/\partial\ln x\)（必须归一）；Q 提升 0.1 等价于 N 增加多少的可计算条件。

### 3.3 问题三：算力约束优化

**结构性观点（只有做完 Q1 才能提出）**：调整 \(p\) 是**零算力成本**提升 \(\bar Q\) 的手段；付费提升 Q 走 \(g(Q)\)。

两阶段最优：

1. 先用 \(p\) 把 \(\bar Q\) 推到 \(\bar Q(p^*)\)；
2. 再看预算是否值得付费继续提升。

约束：

\[
6ND + D[g(Q)-g(Q_0)]_+ + \eta ND L_{\mathrm{ctx}} \le C
\]

- \(Q_0=\bar Q(p_{\mathrm{baseline}})\)，baseline 取 Pile 原始或 RegMix 人工配比（两者都算）。
- 三档 \(C=10^{19}/10^{22}/10^{24}\)；三种 \(g(Q)\) 都跑。
- \(L_{\mathrm{ctx}}\) 外生，取值来自 C7；解析 \(L_{\mathrm{ctx}}^{\mathrm{crit}}=6/\eta=30000\)，在 C7 真值上敏感性。
- 结构性转移定义（选一并给判定）：活跃集切换 / 弹性跳变 / 资源份额排序变化。
- 结构转移点可写成 \(6N\sim g'(Q)\) 的条件，串起 Q1 的 \(p^*\)、Q2 的 \(h(Q)\)、Q3 的成本函数。

### 3.4 问题四：演进与前沿预测

- 桥接时用 P1-f(p) 的 **13 域 loss** 做多域桥接（MATH↔dm_mathematics，GPQA↔arxiv/pubmed，BBH↔综合），在 C8 逐任务检验域 loss 解释力。
- 规模/技术分解中，“数据工程”可用 Q1 框架解释：同 N 下 Benchmark 上升的一部分对应 \(\bar Q\) 与 \(p\) 改善。
- 必用：C1/C2、C3、C4（算力/数据量/开源权重）、C8 逐任务；C6 按可比性分层。
- 口径：综合能力度量、开源筛选、pretrained vs chat、时间轴——全部写明。

1. **照抄《数据说明》PDF 夹杂建议**（ε 为正、Loss–Benchmark 正相关、Q*=1 无需比较成本函数、N*=1.2e-3B 等荒谬结论）。

3. 把 B6–B8、B2、B10、A12–A15 当真实观测陈述。
4. Q3 把 Lctx 当寻优变量或不推 \(6/\eta\)。

10. 列表型字段取均值+标准差（把 qurater 四维混掉、把 logits 当分数）。
