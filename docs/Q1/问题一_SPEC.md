## 2. 处理与建模规范

### 2.1 展开 25 指标与 DSIR 测量校正

**方法、定义。**22 个原始字段展开为 25 列：4 个 `modernbert_*` 六档 logits 各取 softmax 后的 $0,\ldots,5$ 期望分；`qurater` 拆四维；`ad_en`、`fluency_en` 取标签 1 的 softmax 概率，其中 `ad_en` 标签 1 表示无广告；`fineweb_edu` 取单元素值；3 个 DSIR 与 11 个 `rps_*` 取原标量。缺字段或列表长度不符记缺失。三个 DSIR 分量先除以 $\max(\mathrm{word\_count},1)$；在 A1 各域内再以 $\log(1+\mathrm{word\_count})$ 拟合带截距 OLS，后续使用残差，A2/A3 复用 A1 回归系数。

**为什么使用，如何解决本题。**列表 logits 不能直接当标量质量分。原 DSIR 与长度混杂，长文可能因为累积量被误判；两步校正是独立于任何冲突类型的**测量假设**，没有根据“DSIR 高、规则型低”等类型设置阈值、降权或四组评分权重。它提供更可比的 25 维信号，但不能说附件证明了校正必然正确。

**结果。**A1 七域×三 DSIR 的词数 Spearman 绝对相关中位数由原量 **0.957**，除词数后 **0.599**，OLS 残差后 **0.095**。book 小样本剩余相关最高 $|\rho|=0.503$，未完全消除长度关系。逐项见 `T2_dsir_length_diagnostic.csv`。本诊断与冲突率分开计算。

### 2.2 方向、归一化、CRITIC 与 Huber 主质量分

**方法、定义。**词数、句数、平均词长和词熵按 A1 域内中位数变成适宜区间型 $-|h_j(x)-m_{dj}|$；正向指标保留，负向指标取负。重尾非负值按代码规则 `log1p`；DSIR 残差可能为负，不强行取对数。各域各指标用 A1 的 1%/99% 分位缩尾，再按 A1 端点 Min–Max 到 $z_j(x)\in[0,1]$；缺失值用**A1 同域同指标**标准化中位数填补。所有这些参数在 A2/A3 冻结。A1 标准化矩阵上，CRITIC 信息量与固定单指标权重为

$$C_j=s_j\sum_k(1-r_{jk}),\qquad w_j=C_j/\sum_k C_k,\qquad\sum_jw_j=1.$$

主分逐篇求解

$$Q(x)=\arg\min_{q\in[0,1]}\sum_{j=1}^{25}w_j\rho_\delta(z_j(x)-q),\qquad
\rho_\delta(u)=\begin{cases}\frac12u^2,&|u|\le\delta,\\ \delta(|u|-\frac12\delta),&|u|>\delta.\end{cases}$$

用一维凸目标导数方程 $\sum_jw_j\operatorname{clip}(q-z_j,-\delta,\delta)=0$ 二分求解。$\delta$ **只从 A1 确定**：先求每篇的加权指标中位数 $m_x$ 及加权 MAD $a_x=\operatorname{wmedian}_j|z_j-m_x|$，再取 $\delta=1.345\times1.4826\times\operatorname{median}_{x\in A1}a_x=\mathbf{0.403491}$。1.4826 作正态尺度校正，1.345 是经典 Huber 效率常数；这是一条不依赖质量真值或下游 Loss 的 A1 尺度规则。A2/A3 复用该数。对照 $Q_{\rm mean}=\sum_jw_jz_j$ 使用同一 25 列和同一权重。

**为什么使用，如何解决本题。**域内方向与尺度统一使异质信号可合成；CRITIC 减少冗余指标重复贡献。Huber 中心对近中心指标保持平方损失，对少数远离中心的指标采用线性损失，避免几何平均将单个接近零的指标放大为整篇低分。没有预评分条件降权、冲突特例权重或四组额外权重。

**结果。**A1 主分与 CRITIC 算术均值、PCA、TOPSIS 的 Spearman 分别为 **0.9936、0.8166、0.9588**，表示方法一致性，**不是独立质量标签验证**。逐篇剔除距加权中位数最远的一个指标后，极端程度最高 10% 的文档中，主分绝对变动中位数 **0.0260**，算术均值 **0.0374**；P90 分别 **0.0340、0.0488**。这验证单个极端指标的影响较小，不能推出主分更准确。A1 对 A2/A3 的 KS $p$ 分别为 0.313/0.220，只能说未检出分布差异。域级汇总取中位数、2,000 次文档 bootstrap 95% 区间及词数加权副口径；词数只是 token 量代理。

### 2.3 得到主 $Q$ 后诊断四组冲突

**方法、定义。**把 25 项按来源分为规则型、DSIR、轻量分类器、模型评分器；组分 $S_g(x)$ 为组内指标中位数，再在每个数据集的每个领域内转为百分位秩 $R_g(x)$。冲突度 $c(x)=\max_gR_g(x)-\min_gR_g(x)$。A1 在 0.30–0.95 的 0.01 网格扫描，取归一化冲突率曲线距首尾弦最远处 $\tau=0.71$；A2/A3 冻结 $\tau$，各自重算域内秩。$c>\tau$ 才标冲突，最高组和最低组定义方向。历史代码所称“最大曲率”实际是**最大弦距肘部**。阈值仅供诊断，不回写 $Q$。

**为什么使用，如何解决本题。**同源指标可能重复，组间排名落差揭示评估视角分歧。先评分后分析，避免依特定冲突类型倒推想要的分数。

**结果。**A1/A2/A3 冲突率分别 **19.08%/24.52%/23.28%**。它们与更换评分聚合器前相同，因为只依赖标准化指标。首要方向分别为“轻量分类器高×规则型低”“DSIR 高×轻量分类器低”“DSIR 高×规则型低”；A1 book/arxiv/github 冲突率分别 25.15%/24.10%/23.44%。A1 冲突与领域关联 $\chi^2=206.4$，df=6。30 条原文仅供后续人工复核，尚无正式人工质量标签，不能称具体成因已被人工证实。旧四组 Huber 后处理及调和消解不再生成主分。

### 2.4 桥接到 17 个配比域并修正区间口径

**方法、定义。**从 A1/A18 原文各自复算 11 个同名近似规则特征 $\Phi(text)$；它们不保证逐位复现附件 `rps_*`。A1 取 21,590 篇，以 §2.2 **同一个主 $Q$** 作标签，按领域分层五折比较 Ridge 与 GBDT；每折的特征均值和标准差仅用训练折估计。选较优者用 A1 全部训练子集拟合，对 A18 的 31,340 篇预测并逐域聚合。六个 direct/near_direct 映射域的 `Q_final` 取对应 A1 质量域主 $Q$ 中位数，`CI_lo/CI_hi` 同取该 A1 域主分 bootstrap；11 个 inferred 域的 `Q_final` 与区间同取 A18 预测中位数和文档 bootstrap。A18 对照预测及区间另存 `Q_med`、`CI_calibrated_lo/hi`。`Q_tokenw` 也按最终来源取值。

**为什么使用，如何解决本题。**17 个配比域中 11 个没有直接质量信号，共同文本特征提供桥接；六个映射域可检验预测与 A1 主分的一致性。点估计和区间必须同源，不能用 A1 点估计配 A18 预测区间。

**结果。**本轮选 GBDT，五折均值 $R^2=\mathbf{0.4106}$（Ridge 0.3415）；六映射域预测与 A1 主分的 Pearson **0.6549**、Spearman **0.7714**、MAE **0.0365**，但 $n=6$。17 域最高 arxiv **0.7707**，最低 dm_mathematics **0.5091**。六映射域 `Q_final` 均在同源区间内。映射域区间以 A16 映射成立为条件，尤其不覆盖 near_direct 的映射偏差；inferred 区间只反映**给定桥接模型**下的文档抽样变动，不涵盖模型选择和跨域偏差。ubuntu_irc 16 篇、philpapers 63 篇须低置信使用。桥接 $R^2$ 和六域一致性均不是独立质量准确率。

### 2.5 配比模型、迁移矩阵与质量交互

**方法、定义。**A4/A5 按 `index` 连接，非正份额替换为 $10^{-4}$ 并重新闭合，作 $\operatorname{clr}(p)_i=\log p_i-17^{-1}\sum_k\log p_k$。对 13 验证域分别拟合 $\log L_v=b_v+\sum_i\beta_{vi}\operatorname{clr}(p)_i+\varepsilon_v$ 的 Huber 回归；原始份额 OLS 和 GBDT 作对照。在均匀配比处计算局部迁移效应 $T_{iv}=17(\beta_{vi}-\bar\beta_v)$。额外拟合 $\lambda_v\sum_i p_i(1-Q_{i,\mathrm{final}})$，用 400 次案例 bootstrap 给区间，并在 A6/A7 检查预测。

**为什么使用，如何解决本题。**clr 处理配比份额的闭合约束；线性模型便于解释，GBDT 检查非线性。质量交互只读本轮 `Q_final`，检验质量与配比 Loss 的附加关联。

**结果。**1M 留出平均逐域 $R^2$ 为 clr+Huber **0.772**、裸份额 OLS **0.654**、GBDT **0.897**；13 域等权目标 $R^2$ 中裸 OLS 0.418 高于 clr+Huber 0.260，不能称 clr 在所有目标均优。质量项 bootstrap 区间不含零的域数由旧口径 **10/13** 变为 **6/13**，系数有正有负；它不证明质量因果效应或新评分准确性。只依赖 A4/A5 的配比主模型及其预测基本不变，质量交互已重算。

### 2.6 跨尺度检验及估算表对照

**方法、定义。**冻结 1M 配比模型直接预测 A6–A11；在 60M/1B 上重拟合只作同尺度拟合对照。用 1M/60M/1B 系数随 $\log N$ 漂移的趋势对照 A12–A15 估算 Loss；另将 1M GBDT 直接用于 60M/1B。

**为什么使用，如何解决本题。**只有冻结模型的直接预测能检验跨尺度迁移。同尺度重拟合不能替代留出检验；绝对 Loss 与排序分开报告，避免把尺度漂移当配比改进。

**结果。**固定 1M 线性模型在 1M/60M/1B 的等权目标 Spearman 为 **0.523/0.467/0.677**；固定 1M GBDT 在 60M/1B 为 **0.872/0.664**，MAE **1.470/2.773**。这些模型不使用 Q，重跑后主预测数值不因 Q 而变化。60M/1B 自训练 GBDT 的约 0.937 是同集拟合。10B/70B 只对照**估算/外推、非观测**表，不能称真实训练验证。

### 2.7 候选最优配比与配比加权质量

**方法、定义。**以 A4 平均配比为中心、四档浓度 Dirichlet 生成 99,996 个候选；1M GBDT 分别按 13 域等权 Loss 与 pile_cc Loss 选前 100 个份额取平均，得两组候选。固定等权候选后，用线性模型 200 次案例 bootstrap 报另一模型下的收益分布。每个候选的 `Q_domain` 从本轮 `Q_final` 按域名连接，$\bar Q=\sum_i p_iQ_i$。

**为什么使用，如何解决本题。**Dirichlet 保证非负、和为 1；1M 代理模型给出候选，$Q_{\mathrm{final}}$ 明确传到下游接口。预测收益不等于重新训练的实测改善。

**结果。**等权候选的 GBDT 预测相对均匀配比降损 **9.915%**；线性 bootstrap 中位数 **11.90%**、95% 区间 **[9.72%,14.12%]**，后者不是前一 GBDT 点估计的区间。候选配比与预测损失不随 Q 改变；等权候选 $\bar Q$ 从 **0.55397 → 0.66089**，均匀配比 $\bar Q$ 从 **0.54800 → 0.66064**。质量与训练边际价值的 17 域 Spearman 由旧表约 −0.06 变为 **−0.211**，不能据此断言完全无关。pile_cc 候选经前百平均后自身目标 Loss 5.608，高于等权候选 5.530，只能称搜索候选，不能称复评后的最优解。
