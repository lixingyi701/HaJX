# 问题一规格说明

> 版本：2026-09-24。本文定义问题一的输入、计算口径、输出接口与验收条件，供代码复现、论文写作和问题二至四读取。赛题条款来自《算力约束下提升大语言模型能力的资源配置建模.docx》；实现口径以 `src/code_q1/` 和现有 `src/outputs_q1/` 为准；《分析说明.md》用于解释方法和结果。文末单列当前实现与说明文字的差异，不把尚未实现的方案写成既成结果。

## 1. 目标与范围

问题一须完成三项交付：

1. 将 A1、A2、A3 的 22 个原始质量字段展开、统一方向，生成可比较的样本级质量分 $Q\in[0,1]$，并报告域级质量及抽样集与扩展集的差异。
2. 定义同一文本的指标冲突，在 A1 上分析成因，使用同一判据在 A2、A3 上复检，并生成冲突消解后的 $\widetilde Q$。
3. 在 17 域单纯形上拟合配比 $\mathbf p$ 与 13 个验证域交叉熵损失 $L_v$ 的关系，检验 1M、60M、1B 三个尺度，讨论 10B、70B 估算表的外推稳健性，产出最优候选配比 $\mathbf p^*$ 及下游接口。

本规格不重新估计问题二的标度律，也不把 A12–A15 的估算值当作真实训练观测。问题一的主模型只使用 A4/A5 拟合；A6/A7 用于 1M 留出检验，A8–A11 用于直接跨尺度检验。后续为描述尺度漂移而在 60M、1B 上重拟合的步骤须单独标注，不能再称作对该漂移模型的独立检验。

## 3. 处理与建模规范

### 3.1 质量指标与综合评分

实现入口：[q1_00_common.py](../../src/code_q1/q1_00_common.py)、[q1_01_extract.py](../../src/code_q1/q1_01_extract.py)、[q1_02_quality.py](../../src/code_q1/q1_02_quality.py)。

- 22 字段展开为 25 个标量：4 个 `modernbert_*` 六档 logits 各取 softmax 期望分；`qurater` 拆为 4 维；`ad_en`、`fluency_en` 二档 logits 取标签 1 的概率；`fineweb_edu` 取单元素值；DSIR 与 11 个 `rps_*` 取标量。缺失或列表长度不符记为 `NaN`。
- 指标方向由 `DIRECTION` 固定。正向保留、负向取负；词数、句数、平均词长、unigram entropy 四项按“离域内中位数越近越好”单峰化。对非负的单峰项先 `log1p`；DSIR 的重尾变换仅在该列非负时触发。逐域用 A1 的 1%/99% 分位缩尾，再 Min–Max 到 $[0,1]$。A2/A3 直接应用 A1 冻结的中位数、缩尾端点和 Min–Max 端点。
- A1 变换后的 25 维矩阵 $Z$ 用 CRITIC 估权：$C_j=s_j\sum_k(1-r_{jk})$，$w_j=C_j/\sum_kC_k$。样本主分为 $Q(x)=\exp\{\sum_jw_j\log[\max(Z_j(x),10^{-3})]\}$。当前实现对剩余缺失值按该指标整列中位数填补；代码注释写“域内中位数”，与实际不一致。
- 对照分使用等权几何平均、加权 TOPSIS、PCA；K-means 三档仅作相对分类，不代替连续 $Q$。域级主口径为样本中位数，报告 2,000 次 bootstrap 95% 区间、均值、P10/P90。`Q_tokenw` 使用 `rps_doc_word_count` 加权，是词数代理，不是实测 token 加权。
- 以同一冻结管线比较 A1 中 arxiv/github 子集和 A2/A3 的 $Q$ 分布，输出双样本 KS、渐近 $p$ 值、Cohen's $d$ 与逐指标 KS。A2/A3 不参与权重重估。

### 3.2 冲突定义与消解

实现入口：[q1_03_conflict.py](../../src/code_q1/q1_03_conflict.py)。25 指标分为规则型、DSIR、轻量分类器、模型评分器四组。每篇文本在组内取标准化指标中位数，再把组分数转为**本数据集、本领域内**的百分位秩 $R_g$。冲突度定义为

$$c(x)=\max_gR_g(x)-\min_gR_g(x),\qquad I(x;\tau)=\mathbf1\{c(x)>\tau\}. $$

在 A1 的 $\tau\in[0.30,0.95]$、步长 0.01 上计算冲突率曲线。程序把横纵坐标归一化后，选取曲线到首尾连线距离最大的点；该规则是**几何肘部法**，不是代码注释和《分析说明.md》所写的微分“最大曲率”。所得阈值在 A2/A3 固定使用，扩展集的百分位秩仍各自重算。报告组内 Kendall $W$、冲突类型、域级冲突率及域与冲突的卡方关联。程序把 30 条冲突样本的原文前 500 字符导出，人工成因判读须另有人工记录，不能仅凭导出文件宣称已核验。

消解采用文档级组权重。记 $m(x)=\operatorname{median}_gR_g(x)$、$d_g=(R_g-m)/0.25$，则 $u_g=\min(1,1.5/|d_g|)$；每个指标权重乘所属组的 $u_g$ 后按篇归一，代入几何平均得到 $\widetilde Q$。该降权对所有样本执行，并非只对判定冲突的样本执行。调和平均仅作更强短板惩罚的对照。

### 3.3 将质量分桥接到 17 个配比域

实现入口：[q1_04_bridge.py](../../src/code_q1/q1_04_bridge.py)。程序从文本自算 11 个规则特征 $\Phi(text)$，包括词数、句数、平均词长、词分布熵、无字母词比例、独特词比例、最高频 2/3 元片段占比和三项行统计。实现对文本最多截取 40,000 字符；这些是自定义同名近似算子，不应表述为官方 `rps_*` 的逐位复现。

A1 每域按上限抽取有效原文，现有训练样本 21,590 篇，以冲突消解后的 $\widetilde Q$ 为标签。对 11 特征的词数、句数取 `log1p`，标准化后做域内分层五折交叉验证，在 Ridge 与自实现的梯度提升树桩模型GBDT中选择平均 $R^2$ 较高者，再用全部桥接训练样本拟合。A18 各域文本预测值截断到 $[0,1]$，按域输出中位数、词数加权均值及 2,000 次 bootstrap 区间。

最终 `Q_final` 的取法：有 A16 质量域映射的六域使用 A1 的 $\widetilde Q$ 域中位数；其余 11 域使用 A18 校准预测中位数。六个映射域同时用“预测中位数 vs A1 映射分”进行桥接互验。须保留 `mapping_type`、样本量和证据等级；inferred 域尤其是 ubuntu_irc、philpapers 的点估计不得脱离区间与小样本说明单独解释。

### 3.4 配比回归与迁移效应

实现入口：[q1_05_mixture.py](../../src/code_q1/q1_05_mixture.py)。对每个配比的零或负分量先置为 $10^{-4}$、闭合后做中心对数比变换

$$z_i=\log p_i-\frac1{17}\sum_{k=1}^{17}\log p_k,\qquad
\log L_v=b_v+\sum_{i=1}^{17}\beta_{vi}z_i+\varepsilon_v. $$

每个验证域单独在 A4/A5 上用 Huber IRLS 拟合，默认阈值为标准化残差的 1.35 倍。对照为去掉一列以避开闭合共线性的原始配比 OLS，以及 250 棵树桩、学习率 0.06 的自实现 GBDT。预测后取指数回到 Loss 尺度。主报告指标 `R2_mean`、`RMSE_mean`、`MAE_mean` 是 13 个验证域指标的**算术平均**；`target_r2`、`target_spearman` 则针对 13 域等权平均 Loss，二者不得混写。

在均匀配比处，迁移矩阵按 $T_{iv}=17(\beta_{vi}-\bar\beta_v)$ 输出，含义是 $\partial\log L_v/\partial p_i$ 的局部切向量近似；矩阵为 17×13。质量交互项以 $q_{\rm pen}(\mathbf p)=\sum_i p_i(1-\hat Q_i)$ 加入每域的对数 Loss 回归，$\lambda_v$ 用 A4/A5 的 400 次案例 bootstrap 给区间，在 A6/A7 比较对数 Loss 的 RMSE。不同验证域的 $\lambda_v$ 可异号，不能统一解释为正向质量惩罚。

### 3.5 跨尺度、外推与候选最优配比

实现入口：[q1_06_scale.py](../../src/code_q1/q1_06_scale.py)、[q1_07_optimal.py](../../src/code_q1/q1_07_optimal.py)。先用 1M 训练系数**不作修正**地预测 A6/A7、A8/A9、A10/A11，分别报告目标 Loss 的 Spearman 和逐域平均误差。之后在 60M、1B 数据上重新拟合系数，与 1M 系数一起按 $\log(N/10^6)$ 拟合每个截距和斜率的三点漂移线。把修正后的系数用于 A12–A15，仅报告与估算表的一致性；这是估算值对照，不是外部实测验证。当前三个 Spearman 点并非随规模单调下降，因此图名中的“衰减”只能理解为跨尺度变化。

最优配比搜索用训练配比均值作为 Dirichlet 中心、四档浓度生成 **99,996** 个候选（代码请求 99,999，按四档整除后实际为 99,996）；GBDT 预测 13 域等权目标与 pile_cc 单域目标，各取前 100 个候选的份额平均并重新归一，得到两个 $\mathbf p^*$。用同一代理模型与均匀配比和训练配比均值比较；主口径的 9.9% 降损是**代理模型预测**，不是新训练实验。200 次线性模型 bootstrap 固定已选出的 $\mathbf p^*$ 再评价，其区间不覆盖候选搜索本身的不确定性。$\bar Q(\mathbf p^*)=\sum_i p_i^*\hat Q_i$ 是传给后续问题的质量汇总。

## 6. 当前实现待修正项

1. **路径不可移植。**`q1_00_common.py` 把 `ROOT` 写为原运行环境的 `/sessions/gifted-quirky-euler/mnt/HaJX-main`，当前仓库附件实际在 `附件/A_data_value/`。在本机按编号直接运行脚本会找不到输入；复现前应改为相对源码定位或可配置路径，并检查依赖环境。
2. **映射域区间口径不一致。**`q1_04_bridge.py` 对六个映射域把 `Q_final` 改为 A1 官方映射的消解后中位数，却保留 A18 校准预测中位数的 `CI_lo/CI_hi`。现有六个映射域的区间全部不包含各自的 `Q_final`；例如 arxiv 的 `Q_final≈0.716`，现有区间约 `[0.587,0.593]`。应对映射域重算与 `Q_final` 同源的区间，并明确映射误差是否另外纳入。
3. **单域候选目标未通过最终复核。**现有 `T7_pstar_benchmark.csv` 中，`p*_pile_cc口径` 的最终平均候选在 pile_cc Loss 上为 5.608，高于 `p*_等权口径` 的 5.530。前 100 个候选平均后不能自动保证仍优；“pile_cc 最优”只能描述搜索目标，交付时还应复评最终候选并说明其相对收益。
4. **文案与代码有细节差异。**阈值使用到首尾连线最大距离而非微分最大曲率；缺失值填补按指标整列中位数而非域内中位数；`Q_tokenw` 按词数而非 tokenizer 计数；抽查脚本只导出 30 条素材，未保存人工判读结论。论文与说明文字须按实际实现或修正后的实现同步更新。

## 7. 运行与追溯

问题一源码顺序为 `q1_01_extract.py` → `q1_02_quality.py` → `q1_03_conflict.py` → `q1_04_bridge.py` → `q1_05_mixture.py` → `q1_06_scale.py` → `q1_07_optimal.py`；`q1_00_common.py` 是公共模块，`q1_04b_a18_chunk.py` 是依赖临时解压文件的辅助分片工具，不属于标准主链。修正路径后，需要 Python 3、NumPy、pandas、Matplotlib；当前实现的 GBDT 和统计工具为自实现，无 SciPy、scikit-learn 或 LightGBM 运行依赖。若更新任一步的数学口径，须同步重算其下游缓存、接口、论文表图，并更新本规格中的验收基线。
