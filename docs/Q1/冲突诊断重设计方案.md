# 问题一质量指标冲突诊断重设计方案

**版本**: v2.0  
**日期**: 2026-09-25  
**状态**: 设计完成，待实现

## 1. 设计目标与原则

### 1.1 核心问题

原四组方法存在以下问题：

1. **RPS 组内部异质性过高**：11 项规则型指标（词数、句数、词长、熵、特殊字符比例等）合并为一组，组内 Kendall W 一致性很低，组中位数掩盖了内部分歧
2. **模型评分器过度聚合**：FineWeb-Edu（1项）、QuRating（4项）、ModernBERT（4项）被合并为"模型评分器"，丢失了不同模型视角的差异
3. **指标数量主导**：RPS 11 项和模型评分器 9 项占主导，轻量分类器 2 项和 DSIR 3 项话语权被稀释
4. **组中位数掩盖对立**：同组内真正相反的指标意见被中位数平滑

### 1.2 设计原则

1. **单指标分析为基础**：每个指标的标准化分 $z_j(x) \in [0,1]$ 是最细粒度信号
2. **来源分层汇总**：按六个较细来源汇总，保留来源内部一致性检查
3. **避免数量偏见**：来源间比较时归一化指标数量影响
4. **后置诊断**：在主质量分 $Q(x)$ 计算之后进行，不回写 $Q$
5. **冻结规则**：A1 确定参照和阈值，A2/A3 冻结复检
6. **证据边界清晰**：区分统计发现与人工验证，不过度解读

## 3. 冲突诊断方法论

### 3.1 单指标层级分析

对每个指标 $j \in \{1,\ldots,25\}$ 和每篇文档 $x$：

1. **标准化分**：$z_j(x) \in [0,1]$（来自 Step2 的域内标准化）
2. **域内百分位排名**：$r_j(x) = \text{percentile\_rank}(z_j(x) \mid \text{domain}(x)) \in [0,1]$
3. **与主分偏离度**：$\delta_j(x) = |r_j(x) - \text{percentile\_rank}(Q(x) \mid \text{domain}(x))|$

**意义**：
- $r_j(x)$ 是指标 $j$ 对文档 $x$ 在同域内的相对评价
- $\delta_j(x)$ 度量该指标与主质量分 $Q$ 的一致性
- 大的 $\delta_j$ 表示该指标对该文档的看法与共识不同

### 3.2 来源层级汇总

对每个来源 $s \in \{S1, \ldots, S6\}$，定义来源分数 $\bar r_s(x)$ 为：

$$\bar r_s(x) = \frac{1}{|I_s|} \sum_{j \in I_s} r_j(x)$$

其中 $I_s$ 是来源 $s$ 包含的指标索引集。

**与原四组方法的区别**：
- **原方法**：$S_g(x) = \text{median}_{j \in I_g} z_j(x)$，再转域内百分位
- **新方法**：先转各指标百分位，再取算术平均（等权）

**理由**：
1. **避免中位数掩盖对立**：中位数对内部分歧不敏感；算术平均保留所有指标投票
2. **等权来源贡献**：每个来源的权重是 $1/6$，不因指标数量而异
3. **可解释性**：$\bar r_s(x) = 0.8$ 表示来源 $s$ 的指标平均认为该文档在同域排名前 20%

### 3.3 来源内部一致性

对每个来源 $s$，在 A1 上计算：

1. **Kendall W**（来源内指标一致性）：
   $$W_s = \frac{12 S_s}{k_s^2 (n^3 - n)}$$
   其中 $k_s = |I_s|$ 是指标数，$S_s$ 是秩和平方和统计量

2. **平均成对 Spearman 相关**：
   $$\bar \rho_s = \frac{2}{k_s(k_s-1)} \sum_{i < j \in I_s} \rho(r_i, r_j)$$

3. **指标-来源均值相关**：
   $$\rho_{j,s} = \text{corr}(r_j(x), \bar r_s(x)), \quad \forall j \in I_s$$

**预期**：
- S2（DSIR 3项）、S5（QuRating 4项）、S6（ModernBERT 4项）应有较高 $W_s$ 和 $\bar \rho_s$
- S1（RPS 11项）预计 $W_s$ 较低，因其本质异质（词数 vs 熵 vs 特殊字符）
- S3（2项）和 S4（1项）无需内部一致性

### 3.4 来源间分歧度

对每篇文档 $x$，定义：

1. **来源间极差**（原方法沿用）：
   $$c_{\text{range}}(x) = \max_{s} \bar r_s(x) - \min_{s} \bar r_s(x)$$

2. **加权标准差**（新增，对极值不敏感）：
   $$c_{\text{std}}(x) = \sqrt{\frac{1}{6} \sum_{s=1}^6 (\bar r_s(x) - \bar r(x))^2}$$
   其中 $\bar r(x) = \frac{1}{6} \sum_s \bar r_s(x)$ 是六来源平均

3. **方向不一致性**（新增，检测正负对立）：
   $$c_{\text{dir}}(x) = \mathbb{1}[\exists s, s': \bar r_s(x) < 0.3 \land \bar r_{s'}(x) > 0.7]$$
   表示是否存在某来源认为很差（<30%）而另一来源认为很好（>70%）

### 3.5 单指标异常 vs 多来源对立

**单指标异常**定义（孤立离群）：
- 存在某指标 $j$ 使得 $\delta_j(x) > \tau_{\text{ind}}$
- 且该指标所属来源 $s$ 的其他指标 $\delta_{j'}(x) < \tau_{\text{ind}}, \forall j' \in I_s \setminus \{j\}$

**多来源对立**定义（系统分歧）：
- 存在两个来源 $s, s'$ 使得 $|\bar r_s(x) - \bar r_{s'}(x)| > \tau_{\text{src}}$
- 且这两个来源内部各自一致（$W_s, W_{s'}$ 较高或样本内方差较小）

**区分意义**：
- 单指标异常可能是测量误差、特殊文档类型、或该指标捕捉的独特维度
- 多来源对立反映评价体系的根本分歧（如 DSIR 认为重要 vs RPS 认为低质）

## 4. 阈值确定与统计解释

### 4.1 A1 阈值自适应

**极差阈值 $\tau_{\text{range}}$**（主阈值）：
1. 计算 A1 全体的 $c_{\text{range}}(x)$ 分布
2. 扫描候选 $\tau \in [0.30, 0.95]$，网格步长 0.01
3. 计算冲突率曲线 $p(\tau) = \mathbb{P}(c_{\text{range}}(x) > \tau)$
4. 选择**最大弦距肘部**：
   $$\tau_{\text{range}} = \arg\max_\tau \frac{|p(\tau) - p_{\text{linear}}(\tau)|}{\sqrt{2}}$$
   其中 $p_{\text{linear}}(\tau)$ 是首尾连线的线性插值

**标准差阈值 $\tau_{\text{std}}$**（辅助阈值）：
- 取 A1 的 $c_{\text{std}}(x)$ 的第 80 百分位（top 20% 作为高分歧）

**单指标阈值 $\tau_{\text{ind}}$**：
- 取 A1 全体指标-主分偏离度 $\delta_j(x)$ 的第 90 百分位（top 10% 作为异常）

### 4.2 统计含义与证据边界

**冲突率的含义**：
- $p_{\text{conf}} = \mathbb{P}(c_{\text{range}}(x) > \tau_{\text{range}})$ 表示**指标分歧候选比例**
- 这是统计发现，不是"真实质量错误率"或"需要修正的文档比例"
- 没有人工质量标签时，不能说"19.08% 的文档存在真实冲突"

**阈值的稳健性**：
- 肘部法选择使 $p_{\text{conf}}$ 对 $\tau$ 的微小变动不敏感的分界点
- 报告 $\tau \pm 0.05$ 邻域内的冲突率变化，作为稳定性检查

**与主分 $Q$ 的关系**：
- 高冲突 $\not\Rightarrow$ 主分 $Q$ 错误
- 可能是：(1) 文档质量多面；(2) 指标捕捉不同维度；(3) 主分合理但信号分散
- $Q$ 的 Huber 稳健性已通过极端指标扰动实验检查（Spec §2.2）

## 5. A2/A3 冻结复检规则

### 5.1 参数冻结

从 A1 冻结并应用于 A2/A3：
1. $\tau_{\text{range}}$、$\tau_{\text{std}}$、$\tau_{\text{ind}}$（三个阈值）
2. 六来源分组 $I_{S1}, \ldots, I_{S6}$（指标归属）
3. 域内百分位转换规则（A2/A3 各自域内重算，但规则同 A1）

### 5.2 复检内容

对 A2（arxiv 扩展）和 A3（github 扩展）：
1. **冲突率**：$p_{\text{conf}}^{(A2/A3)}$ 与 $p_{\text{conf}}^{(A1)}$ 比较
2. **首要方向**：最常见的"来源 $s$ 高×来源 $s'$ 低"配对
3. **域内差异**：A2/A3 虽只有单域，但可报告其冲突率是否落在 A1 同域区间内

### 5.3 稳定性指标

跨集稳定性：
- **冲突率标准差**：$\sigma_p = \text{std}(p_{\text{conf}}^{(A1)}, p_{\text{conf}}^{(A2)}, p_{\text{conf}}^{(A3)})$
- **方向一致性**：A1/A2/A3 首要方向是否相同
- **阈值敏感性**：在 $[\tau - 0.05, \tau + 0.05]$ 内，冲突率变化幅度

## 6. 与原四组方法的对比

### 6.1 对照实验设计

在相同的标准化矩阵 $Z$ 和主分 $Q$ 下，并行计算：
- **旧方法**：四组（规则型、DSIR、轻量分类器、模型评分器），组中位数
- **新方法**：六来源（S1–S6），百分位算术平均

### 6.2 稳定性比较维度

1. **冲突率差异**：
   $$\Delta p = |p_{\text{conf}}^{\text{new}} - p_{\text{conf}}^{\text{old}}|$$

2. **文档级一致性**：
   - 交集：同时被两方法标记为冲突的文档比例
   - Cohen's Kappa：考虑随机一致性的校正一致度

3. **首要方向稳定性**：
   - 旧方法最常见配对（如"DSIR高×规则型低"）
   - 新方法能否追溯到更细来源（如"S2-DSIR高×S1-RPS低"）

4. **与主分 $Q$ 的关联**：
   - 冲突文档的 $Q$ 分布 vs 全体 $Q$ 分布（KS 检验）
   - 冲突文档的 $Q$ 方差是否更大（方差齐性检验）

## 9. 证据边界与解释限制

**本方法能提供的证据**：
1. 六来源指标在给定文档上的评价分歧程度（统计事实）
2. 分歧在不同数据集和领域的分布特征（描述性统计）
3. 与主质量分 $Q$ 的关联模式（相关性，非因果）

**本方法不能声称**：
1. 冲突文档的"真实质量"（无金标签）
2. 哪个来源"更准确"（需下游任务验证）
3. $Q$ 应该根据冲突调整（已规定后置诊断）
4. 冲突率是"错误率"（可能是多面性而非错误）

**推荐表述**：
- ✅ "A1 有 19.08% 的文档显示六来源评价极差 >0.71"
- ✅ "DSIR 与 RPS 是 A1 最常见的对立来源配对"
- ❌ "19.08% 的文档质量分存在错误"
- ❌ "DSIR 比 RPS 更准确"
