# 问题一详细解决方案：数据质量评价、质量冲突消解与领域配比建模

> 定位：本文是可直接写入论文第 3–4 章的问题一完整技术方案（数学表述 + 算法步骤 + 数据使用 + 检验设计）。问题二的广义标度律、问题三的算力优化均以本文产出（样本级/域级质量分 $Q$、配比模型 $f(\mathbf p)$、最优配比 $\mathbf p^*$）为输入，本文不写问题二/三/四的求解正文，但全部产出标注下游用途。
> 依据：赛题正文问题一条款、《附件A数据集详解》（实查）、《问题一方法详解》、《F题执行路线》。

## ① 问题重述与分析

**一句大白话**：出题人给了我们两样东西——一批"被 22 把尺子量过身材的教材"（质量信号），和 512 次"换课时表做实验"的成绩单（配比实验）；问题一要我们把 22 把尺子合成一个可信的质量分 $Q$，处理尺子之间打架的情况，再从实验数据里反推出"课时表怎么排，哪科成绩涨多少"。

官方三项子任务：

- **(a) 数据质量评价**：预处理 22 个质量字段 → 综合评分 $Q$（样本级 + 领域级）；指标统一为"越高越好"；必须用 A1 抽样集全量 + A2、A3 扩展集全量，并做域级对照。
- **(b) 质量冲突消解**：定义冲突、分析成因、给出消解后的综合评价；冲突分析覆盖抽样集，并在扩展集上复验主要结论。
- **(c) 领域配比建模**：用 A4–A15 建立 17 域配比 $\mathbf p$（$p_i\ge 0$，$\sum_i p_i=1$）与交叉熵 Loss 的定量关系；分析各领域及其组合对性能的影响；论证是否/如何引入 $Q$；在 A6–A11 上验证；A12–A15 只作外推稳健性讨论（其 est Loss 为幂律外推生成，**非观测**，不得当作真实验证）。

方案围绕三个科学问题（SQ）组织，而非流水账：

- **SQ1（信号合成与域偏差）**：22 个异质指标（量纲混杂、方向不一、部分是分类器 logits）如何合成跨域可比、可进数学模型的连续质量分？业界（FineWeb-Edu、DCLM、Nemotron-CC）只做硬过滤不给连续分；且 github/arxiv 等域的指标基线存在系统性差异，全局标准化会把"域的本性"误判为"质量的差"。
- **SQ2（冲突的定义与消解）**：指标互相矛盾（如"像教材"与"广告多"同时成立）时怎么办？业界"一票否决"丢信息且不可解释；预设固定阈值（如 z 分差 >0.5）再宣布"冲突率≈0%"是把结论藏进定义的循环论证——本方案让阈值由数据自适应产生。
- **SQ3（配比效应及其尺度边界）**：配比→Loss 规律在 1M→60M→1B 三个尺度上保持多少？质量分能否解释各域的边际贡献？RegMix 验证了线性可预测性，但未处理成分数据的闭合效应，且只验到 1B——闭合效应的处理与尺度漂移的量化是本方案的两个改进点。

## ② 符号与假设

### 2.1 符号表

| 符号 | 含义 |
|---|---|
| $i\in\{1,\dots,17\}$ | 训练域（The Pile 17 子域，A4 配比列） |
| $v\in\{1,\dots,13\}$ | 验证域（A5 有 Loss 列的 13 个域） |
| $d\in\{1,\dots,7\}$ | 质量域（A1–A3：arxiv/book/c4/commoncrawl/github/stackexchange/wikipedia） |
| $j\in\{1,\dots,25\}$ | 展开后的质量指标（22 字段 → 25 指标） |
| $x_j$ | 样本在第 $j$ 个指标上的取值（压缩为标量后） |
| $Q(x)\in[0,1]$ | 样本级质量分；$\bar Q_d$ 为域级质量分 |
| $\mathbf p=(p_1,\dots,p_{17})$ | 训练配比，$\mathbf p\in\Delta^{16}$（16 维单纯形） |
| $z_i=\ln(p_i/g(\mathbf p))$ | clr 坐标，$g(\mathbf p)=(\prod_i p_i)^{1/17}$ |
| $L_v(\mathbf p)$ | 配比 $\mathbf p$ 下验证域 $v$ 的交叉熵 Loss |
| $T=(T_{vi})$ | 迁移矩阵，$T_{vi}=\partial L_v/\partial p_i$ |
| $c(x)$ | 样本冲突得分；$\tau$ 为冲突阈值 |
| $d(i)$ | 配方域 $i$ 经 A16 映射到的质量域 |

### 2.2 模型假设

1. **同域同质性假设**：同一质量域内的文档共享指标基线分布，域内标准化可消除域间结构性差异。依据：DSIR 权重定义为 $\log p(\text{doc})/q(\text{doc})$，$q$ 是源域 n-gram 模型，跨域直接比较在定义上就不成立（硬数据事实）。
2. **小样本域不确定性假设**：book 域仅 171 条，域级统计必须带 bootstrap 置信区间，点估计不单独作为结论。
3. **配比有效性假设**：A4 各行配比和 ≈1（千分位舍入误差），建模前重新归一化 $\mathbf p\leftarrow \mathbf p/\sum_i p_i$。
4. **外推表性质假设**：A12–A15（10B/70B）的 est Loss 是 1M/60M/1B 三尺度幂律外推**生成值**，只用于稳健性讨论，论文中明确标注"非观测"。
5. **跨体系映射单调性假设**：A16 的 direct/near_direct 映射下，SlimPajama 质量分与 The Pile 对应域的真实质量存在保序关系；inferred 域的结论以区间形式分层给出。

### 3.2 关键硬事实：列表型字段的正确展开（22 字段 → 25 指标）

**大白话**：8 个"列表字段"不是"一个指标的几个重复测量"，而是分类器还没过 softmax 的原始输出（logits）或四个语义不同的维度打包——直接把 logits 平均，相当于把"考试选择题的原始选项"当"分数"。

| 字段 | 长度 | 正确压缩 | 原因 |
|---|---|---|---|
| `modernbert_{professionalism, readability, reasoning, cleanliness}` | 6 | softmax 后期望分 $s=\sum_{k=0}^{5} k\,\sigma_k$，$\sigma=\mathrm{softmax}(\mathbf u)$ | 是 0–5 六档评分的 logits，不是分数 |
| `qurater` | 4 | **拆成 4 个独立指标**（写作风格 / 专业知识 / 事实性 / 教育价值） | 四维语义不同，平均会抹掉语义 |
| `ad_en` / `fluency_en` | 2 | softmax 取 $P(\text{label}=1)$ | 二分类 logits；ad 标签 1 = 无广告，fluency 标签 1 = 流畅，**本身已是"越高越好"** |
| `fineweb_edu` | 1 | 直接取值 | 已是分数 |

展开后恰好得到 Meta-rater 的 **25 个评分器**：11 个规则型（rps_* 系列）+ 3 个 DSIR + 11 个模型型。

**例子**：`ad_en = [2.31, -0.45]` 不是"两个广告分数"，而是 [有广告, 无广告] 两类的 logits；softmax 后 $P(\text{无广告}) = \sigma_1 \approx 0.06$，即"这篇广告很重"，在"越高越好"口径下应得低分——若直接取均值 0.93 当分数，方向与尺度全错。

### 3.3 预处理五步管线（每步注明针对的核心问题与理由）

**第 1 步：重尾变换（针对：文本统计量重尾，均值被极端值带偏）。**
`word_count`、`num_sentences`、DSIR 三项先取 $\log(1+\cdot)$ 或分位数秩变换。依据：GitHub 域存在上万词的自动生成文件，原始尺度下 1% 的怪文档支配方差。

**第 2 步：非单调指标单峰化（针对：`word_count`/`num_sentences`/`mean_word_length` 两端皆差——过短是空文档，过长多为模板灌水）。**
按"距域内中位数偏离"改单峰：
$$x' = 1-\frac{|x-\mathrm{med}_d(x)|}{\max\big(\mathrm{med}_d(x)-\min_d(x),\ \max_d(x)-\mathrm{med}_d(x)\big)},$$
使"接近典型长度"得分最高。模糊方向项（如 `unigram_entropy` 过高是否为噪声）用 A18 原始文本抽查各 20 条人工判定后定方向。

**第 3 步：方向统一（针对：题目强制"越高越好"，且输出须落 $[0,1]$ 以便问题三进入成本函数）。**
正向指标 Min-Max 归一化；负向指标归一化后做补转换 $x\mapsto 1-x$。负向清单：`frac_no_alph_words`（无意义字符）、`frac_chars_top_2gram`/`top_3gram`（模板化重复）、`lines_numerical_chars_fraction`（数字灌水）、`lines_uppercase_letter_fraction`（标题党式大写）。

**第 4 步：域内标准化（针对 SQ1 的域基线差，优先域内 Min-Max）。**
**大白话**：别拿 GitHub 的"语言流畅度"直接砸 Wikipedia——代码托管站的文本天生不流畅，这不是质量差，是域的本性。所有归一化的 $\min/\max$ 端点在**域内**估计。依据：DSIR 的 $\log p/q$ 定义决定其只能域内比较（硬事实）；全局标准化会把域间结构差异误判为质量差异，冲突分析（子任务 b）会被域效应污染。
**工程约定**：域内 Min-Max 的端点在 A1 全量上估计后**冻结**，A2/A3 直接套用，保证三集对照中差异只来自抽样、不来自管线。

**第 5 步：缺失与异常（针对：录入错误与离群值）。**
按质量域分组报告缺失率（>5% 的指标在论文中说明）；连续指标域内 1%/99% 分位缩尾（winsorize），保留样本量——直接删行会系统性丢掉"怪文档"，而怪文档恰是冲突分析的对象。

**禁止事项**（对照页眉诱导）：列表字段取均值/标准差；`qurater` 四维混一维；logits 当分数；聚类"自动吸收方向差异"（聚类给的是相对类别，给不出跨语料可比、能进问题三成本函数的绝对 $Q$）。

## ④ 模型

### 4.1 模型一：质量综合评价模型 $Q(x)$（子任务 a，对应 SQ1）

**输入**：A1–A3 流式读取的 27.3 万条样本；预处理后的 25 维指标矩阵 $X\in[0,1]^{n\times 25}$。
**输出**：样本级 $Q(x)\in[0,1]$；7 质量域级 $\bar Q_d$（含区间）；经 A16/A18 扩展的 17 配方域 $Q_d$。

**(1) 权重确定：CRITIC 客观赋权（主用）。**
**大白话**：权重不拍脑袋——"越能拉开差距、又不跟别的尺子重复"的尺子，话语权越大。
$$C_j=\sigma_j\sum_{k=1}^{25}(1-r_{jk}),\qquad w_j=\frac{C_j}{\sum_k C_k},$$
其中 $\sigma_j$ 为标准差（对比强度），$r_{jk}$ 为 Pearson 相关（在方向统一后的矩阵上计算），$1-r_{jk}$ 度量冲突性。
**理由**：22→25 维人脑无法可靠定权；熵权只奖励离散程度、会抬举噪声指标，CRITIC 额外惩罚冗余（如 fluency 与 readability 相关 0.9 时自动降权）；数据驱动、可复现，满足题目"说明依据"的要求。

**(2) 聚合：加权几何平均（主用）+ 加权算术平均（对照）。**
$$Q(x)=\prod_{j=1}^{25}\tilde x_j^{\,w_j}.$$
**理由（针对"短板支配"的语料工程实践）**：乘法形式对应"垃圾进垃圾出"——若补转换后 ad_en ≈ 0.01（广告很多），算术平均下总分只略降，几何平均下总分被直接压低，与 FineWeb-Edu/DCLM 一票否决式过滤的工程直觉一致。为防 $\tilde x_j=0$ 奇异，Min-Max 后做 $\tilde x_j\leftarrow 0.01+0.98\,\tilde x_j$ 的边界收缩。
**例子**：GitHub 上一篇"内容价值高但语言碎片"的 README——算术平均给"还不错"，几何平均给"低分"，后者与预训练价值直觉一致。

**(3) 对照管线：PCA。**
对 25 维标准化矩阵做 PCA，取累积方差 ≥80% 的前 $m$ 个主成分，$Q_{\mathrm{PCA}}(x)=\sum_{k=1}^m \rho_k z_k(x)$（$\rho_k$ 为方差贡献率）再 Min-Max 到 $[0,1]$；**必须输出载荷矩阵并命名主成分**（预期：教育价值因子、语言质量因子、噪声/广告因子、结构因子）——不可解释的主成分无法支撑 A18 抽查设计。
**互证**：全体样本 $Q_{\mathrm{CRITIC}}$ 与 $Q_{\mathrm{PCA}}$ 的 Spearman 秩相关，预期 >0.8；另与 Meta-rater 论文 Table 11 权重、等权两套对照权重的 $Q$ 报 Spearman（预期 >0.95）。若系统性分歧（如某域排名相反），回头检查该域指标簇结构——这本身是分析素材。无 GPU，**不复现** Meta-rater 的代理模型训练 + LightGBM 搜权重全流程。

**工业实践定位（校准自厂商技术报告，2024–2026）**：当前厂商的质量做法是"大模型当裁判 + 蒸馏分类器 + 分桶硬过滤"——Qwen3 对超 30T token 做多维标注（教育价值/领域/学科/安全）驱动过滤与组合；Nemotron-CC 用分类器集成把 Common Crawl 分桶精炼成 6.3T token；GLM-4.5 按来源分别打分后加权采样；DeepSeek-V3 走"去重 → 过滤 → 重混"三段管线。这些管线能选出好数据，但**给出的只是过滤档位，没有跨语料可比、能进数学模型的连续质量分**——本模型的连续 $Q\in[0,1]$ 正是补这个位置（详见文献 11–15）。

**(4) 样本 → 域聚合。**
$$\bar Q_d=\mathrm{med}\{Q(x):x\in d\},$$
同时报告均值、P10/P90、token 加权均值 $\sum t_xQ(x)/\sum t_x$（$t_x$ 为文档 token 数，A17 提供域级长度参考），并对中位数给 bootstrap 95% 置信区间（book 域 n=171 时区间必然宽，如实呈现）。
**理由**：语料质量分布长尾，中位数稳健；token 加权回答"按体量随机抽一个 token 的期望质量"，与"按文档等权"分别服务"训练贡献"与"数据源筛选"两种用途（A17 显示域平均长度差 300 倍，两口径差异本身就是结论）。

**(5) 抽样集 vs 扩展集对照（题目强制）。**
A2/A3 全量用**同一管线、同一组冻结权重与端点**复算域级 $\bar Q$，输出 7 域 × 3 集对照表 + Cohen's d。由于 A1 是 range-sampled 且其 arxiv/github 子集与 A2/A3 同源，"扩展集 vs 抽样集"的正式解释是**抽样代表性检验**：对 25 维指标逐维做两样本 KS 检验（A1 域内子集 vs A2/A3 全量），并同时报告 1-Wasserstein 距离（KS 回答"形状差多少"，Wasserstein 回答"差多远"，后者直接服务问题三域级 $Q_0$ 的选取）；报告两指标的通过比例。预期抽样集按域等比例抽取稀释了极端样本，域级冲突率低于全量——这是"抽样偏差"的量化证据。

**(6) 17 配方域 $Q_d$（为问题二 $\bar Q(\mathbf p)$ 与问题三 $Q_0$ 供料）。**
- direct（3 个：arxiv、github、stackexchange）与 near_direct（3 个：wikipedia_en→wikipedia、gutenberg_pg_19→book、pile_cc→commoncrawl）：直接用对应质量域的 $\bar Q_d$；
- inferred（11 个）：用 A18 原始文本对 11 个规则型信号（rps_*）重算，得 $Q^{\mathrm{rule}}_d$；在 6 个重叠域上拟合校准映射 $Q\approx\phi(Q^{\mathrm{rule}})$（保序回归或线性），外推到 11 个 inferred 域并给出经校准残差放大的区间。论文按 mapping_type 分层给出结论的上下界，并声明 SlimPajama 与 The Pile 不同源带来的测量误差风险。

### 4.2 模型二：质量冲突定义、成因与消解模型（子任务 b，对应 SQ2）

**输入**：模型一中间产物——25 维域内标准化指标与域标签。**输出**：冲突得分 $c(x)$、冲突率–阈值曲线、成因交叉表、消解后修正分 $\tilde Q(x)$。

**(1) 指标分组（针对：同源信号天然一致，冲突主要跨组发生）。**
25 指标按来源分 4 组：G1 规则型（11 个 rps_*）、G2 DSIR（3 个）、G3 WanjuanCC 系、G4 PRRC + QuRating + FineWeb 模型型。组内一致性先算 Kendall 和谐系数 $W$ 作基线。

**(2) 冲突定义（针对：禁止预设阈值、循环论证）。**
对每对组 $(g,g')$，样本在组内综合分的**域内分位排名**之差超过阈值即记冲突：
$$\text{conflict}_{g,g'}(x)=\mathbb 1\big\{|\mathrm{rank}_d^{(g)}(x)-\mathrm{rank}_d^{(g')}(x)|>\tau\big\},\qquad c(x)=\max_{g,g'}|\Delta\mathrm{rank}|.$$
阈值 $\tau$ 自适应确定：画冲突率–$\tau$ 曲线；若 $c(x)$ 分布双峰，取两峰间谷值；若单峰长尾，用 POT 极值理论（对尾部拟合广义帕累托分布，取形状参数稳定的起始点）。**报告整条曲线而非单一数字**——结论在 $\tau$ 的宽区间内不变，恰是"消解规则可靠"的证据。
另定义**结构性冲突**：冲突方向在域内显著偏向一侧（二项检验，如 GitHub 域规则型系统性低于模型型）。

**(3) 成因分析。**
域 × 组对交叉表 + 卡方独立性检验，验证假设 H1（规则型与模型型的冲突集中在 github/arxiv，域内标准化后冲突率显著下降）；结合 A17 长度统计与 rps 指标定义做机制解释。
**例子**：github 域代码的符号语法导致 `frac_no_alph_words` 系统性偏高 → 规则型尺子给低分，而 modernbert_reasoning 认可其逻辑密度给高分——这不是数据矛盾，是尺子量错了对象，属于"该指标对此类文档不适用"。

**(4) 消解规则：降权而非删除（两套互补）。**
**大白话**：打架的尺子不是扔掉，而是"这次你说的我不全信"——保留矛盾信息，可解释，这是相对工业界硬过滤的改进点。
- **规则 A：Huber 稳健降权。** 对域内稳健 z 分数 $z_j=(x_j-\mathrm{med}_d)/\mathrm{IQR}_d$ 超阈的指标降权 $w'_j=w_j\cdot\min(1,\tau/|z_j|)$，重算 $\tilde Q$。依据：稳健统计 M-估计（Huber, 1964），按超出程度连续降权。
- **规则 B：结构性冲突组降权 + 冲突样本取组内中位数。** 对被判结构性冲突的（域, 组）对整体降权；冲突样本的总分取 4 组组内分的中位数而非加权几何平均，避免单组一票否决。
- **规则 C（工业界对照）：Nemotron-CC 式乐观聚合 + 质量分桶。** 参照 Nemotron-CC 的做法：样本总分取各组组内分的最大值 $S=\max_g Q^{(g)}(x)$（"宁可误留、不可误杀"），再按分位数归并为若干质量档，只在最低档做硬过滤。该规则是当前工业界事实标准，作为对照规则纳入消融：三条规则（A/B/C）消解后的高分样本各抽 20 条用 A18 原文人工核验，比较谁更贴近人工判断。Nemotron 3 Nano 报告的"翻译的日常对话/广告文本被质量分类器误打高分、需追加 LLM 过滤删除 10.6% token"案例，正是规则型/模型型尺子在某类文本上集体失灵的工业证据，与本节的结构性冲突概念互证（见文献 14、16）。
**复验（题目强制）**：同一管线（冻结阈值与权重）在 A2/A3 全量复跑，比较域级冲突率排序（Spearman）与 top 冲突指标对是否复现。
**备选（论文一笔带过）**：D-S 证据理论合成；鲁棒回归残差法。

### 4.3 模型三：领域配比模型 $f(\mathbf p)$（子任务 c，对应 SQ3）

**输入**：A4/A5 的 512 组 $(\mathbf p^{(m)}, L_v^{(m)})$；域级质量分 $Q_d$（模型一产出）。
**输出**：13 个验证域的配比模型 $L_v(\mathbf p)$、17×13 迁移矩阵 $T$、最优配比 $\mathbf p^*$、质量交互项检验结论。

**(1) clr 变换消闭合效应（针对：成分数据伪相关——RegMix 原文的缺陷与本方案改进点）。**
**大白话**：17 个百分比加起来恒等于 100%，你涨我就跌，直接回归会把这种"机械此消彼长"误读成领域间的替代关系；先换成"对数比"坐标，解除捆绑。
$$z_i=\ln\frac{p_i}{g(\mathbf p)},\qquad g(\mathbf p)=\Big(\prod_{i=1}^{17}p_i\Big)^{1/17}.$$
**零配比处理**（512 组实验存在大量 $p_i=0$）：乘性替换法，$p_i\leftarrow\max(p_i,\delta)$，$\delta=\tfrac12\min\{p_i>0\}$，替换后重新闭合。对照：ilr 变换（正交坐标）重跑主线结果。
依据：Aitchison 成分数据统计理论；RegMix 原文直接 OLS 未处理闭合效应，本方案预期检验集 RMSE 下降即为改进证据。

**(2) 主模型：clr 坐标下的对数线性回归。**
对每个验证域 $v$：
$$\ln L_v=b_v+\sum_{i=1}^{17}\beta_{v,i}z_i+\varepsilon,\qquad L_v(\mathbf p)=\exp\Big(b_v+\sum_i\beta_{v,i}z_i\Big).$$
Huber 损失稳健估计（对异常配方稳健）。**理由**：RegMix 在同数据上验证了线性可预测性（512 组对 18 参数充足）；clr 坐标和恒为 0，线性形式天然满足单纯形约束；系数 $\beta_{v,i}$ 即"第 $i$ 域对验证域 $v$ 的边际贡献"，直接提供题目要求的可解释性。
**非线性对照**：LightGBM（原始 $\mathbf p$ 输入）捕捉交互效应，三尺度 Spearman 与 RegMix 论文数字（约 98.5%/98.6%/97.1%）对照，作为管线正确性的外部校验；树模型系数不可解释，只作对照不作主模型。

**(3) 迁移矩阵 $T$（直接回答"各领域及其组合对性能的影响"）。**
由 clr 链式法则，$\partial z_i/\partial p_i'=\delta_{ii'}/p_i-1/(17p_{i'})$，得
$$T_{vi}=\frac{\partial L_v}{\partial p_i}=L_v\cdot\frac{\beta_{v,i}-\bar\beta_{v}}{p_i},\qquad \bar\beta_v=\frac{1}{17}\sum_i\beta_{v,i},$$
在参考配比（如均匀配比）处取值。$T$ 的对角元为自域效应，非对角元为跨域迁移；4 个无 Loss 列的域（nih_exporter、enron_emails、europarl、philpapers）保留为解释变量（clr 坐标需要全 17 维），其效应通过外溢列体现，并做"合并为其他域"的敏感性分析。$T$ 供问题二做域间替代/互补分析，不另起模型。

**符号约束（针对共线导致的不可解释系数）**：估计时对迁移矩阵对角元加先验约束 $T_{vv}\le 0$——"多练哪科、哪科扣分变少"是领域常识，若回归算出某域自域效应为正，几乎必是共线性假象（Olmo 3 的偏科退火实验证实域间此消彼长真实存在，见文献 15）。实现上用带符号约束的 Huber 回归（scipy/cvxpy 二次规划），并报告约束前后系数跨尺度（1M/60M/1B）的符号一致率——预期约束后显著提升，直接强化"各领域对性能影响"结论的可信度。

**(4) 引入质量分 $Q$：引入，且用嵌套检验论证（为问题二质量乘子提供附件内证据）。**
$$\ln L_v=b_v+\sum_i\beta_{v,i}z_i+\lambda\sum_i p_i\big(1-Q_{d(i)}\big)+\varepsilon.$$
**大白话**：同样的课时表，用好教材和烂教材效果不同——配比模型要再加一个"教材质量折扣"；$Q\to1$ 时折扣消失，模型干净退化为纯配比模型。
**动机（校准自厂商实践）**：质量×配比交互已被工业界默认——Olmo 3 的 quality-aware upsampling 让质量分直接调制采样概率，GLM-4.5/Kimi K2 在退火期集中注入高质量域数据，Nanbeige4 的 FG-WSD 把"训练后期喂高质数据"做成课程（见文献 12、13、15）——但没有任何报告量化过这个交互，本检验即补此空白。
**检验一（λ 显著性）**：bootstrap 构造 $\lambda$ 的 95% 置信区间；消融对比加项前后检验集 RMSE。按 A16 的 mapping_type 分层报告 $\lambda$ 的上下界（direct/near_direct 为主估计，inferred 域参与为下界稳健性）。若 $\lambda$ 显著为正，即"质量是配比之外独立解释边际贡献的因素"成立——这直接支撑问题二把 $Q$ 做成有效数据乘子 $h(Q)$。
**检验二（权重方案的外部效度闭环）**：把每条训练配比折成"质量画像" $\bar q(\mathbf p^{(m)})=\sum_i p_i^{(m)} Q_{d(i)}$，分别用 CRITIC 版、等权版、Meta-rater Table 11 权重版 $Q_d$ 构造三套画像进同一回归，比较 $\lambda$ 的显著性与检验集误差。若 CRITIC 版最优，即说明 §4.1 的客观权重不只"内部自洽"，且真的能预测训练效果——这复刻了 Meta-rater"用下游 Loss 检验权重"的思想，但用现有表格数据实现、不需要 GPU。
**检验三（交互形式比较）**：嵌套比较加性形式 $\lambda\sum_i p_i(1-Q_{d(i)})$ 与乘性形式 $\nu\ln\bar Q(\mathbf p)$（即 $Q^\nu$ 有效乘子的雏形，对应 Muennighoff 重复数据折有效数据量的先例，文献 17）的拟合优度（AIC/检验集 RMSE）。若乘性胜出，问题二把 $Q$ 做成 $h(Q)=Q^\nu$ 就有**形式级**证据，而不只是方向级证据。
**反方风险如实写**：A1 质量信号与 RegMix 的 Pile 语料非同源，映射含测量误差。

**(5) 最优配比 $\mathbf p^*$：单纯形内采样寻优 + Aitchison 几何平均 + 不确定性分布。**
**大白话**：配比空间是个 16 维的"三角形"，最优课时表只能在里面找——在单纯形上撒几百万个 Dirichlet 随机点，用模型预测每个点的成绩，取最好的那一小撮；但"平均"要在对数比坐标里做，而且最优解应该给"一坨云"而不是一个点。
**采样寻优流程**：从 $\mathrm{Dirichlet}(\alpha)$ 采 $N=10^6$ 个候选 $\mathbf p$；用模型预测每个点的 $\hat L_v(\mathbf p)$；按目标函数排序，取 top-$k$（$k=50$），在 clr 空间取均值再逆变换回单纯形（Aitchison 几何中心，与整个建模范式自洽；算术平均虽仍在单纯形内，但不是成分几何意义下的"中心"）：
$$\mathbf p^*=\mathrm{clr}^{-1}\Big(\frac{1}{k}\sum_{\mathbf p\in\mathcal T_k}\mathrm{clr}(\mathbf p)\Big),\qquad \mathcal T_k=\mathrm{top}_k\big\{\hat L_v(\mathbf p)\big\}.$$
**不确定性**：对回归系数做 $B=200$ 次 bootstrap 重抽样，每次重估模型并重新寻优，报告 $\mathbf p^*$ 在单纯形上的**分布**（各分量的成分均值 + clr 方差），而非单点——这为问题三"主线固定 $\mathbf p^*$"的决策提供稳健性依据，也给"±20% 扰动敏感性"一个数据驱动的扰动半径。
目标函数：13 域 Loss 的（域内标准化后）均值为主，另报"均衡性约束下最优"作对照。**禁止裸 OLS 外推最优解**（无视单纯形与共线会得到出界或退化解）。

**(6) 三尺度联合建模与排名衰减（SQ3 的尺度边界，主线升级）。**
**大白话**：不是"用 1M 拟合、再看 60M/1B 偏多少"，而是把"规模"直接写进回归式，让漂移自己从数据里长出来。
把 A4–A11 三个尺度的全部 $512+256+256+64$ 组实验**联合**拟合尺度感知模型：
$$\ln L_v=b_v+\gamma_v\ln N+\sum_i\beta_{v,i}z_i+\sum_i\delta_{v,i}\,z_i\ln N+\varepsilon,$$
其中 $N$ 为模型参数量；$\gamma_v$ 是规模主效应，交互系数 $\delta_{v,i}$ 就是"第 $i$ 域的配比效应随规模漂移"的**直接估计**——一次拟合、自带标准误，比事后拟合漂移律更干净，且能回答"哪些域的配比效应尺度不变（$\delta\approx0$）、哪些随规模衰减"。这正面检验了 RegMix 赖以成立的"秩不变性"假设。
**动机（校准自厂商实践）**：没有厂商敢把小尺度配比结论直接搬上大模型——Qwen3 的实例级配比消融在小代理模型上做、结论用于 235B，Nemotron 的每个数据决策都配 8B 级消融，Olmo 3 把 microanneal 中途验证做成标准流程；厂商"每升一档重消融"的行为等于承认系数会漂（文献 11、14、15）。
排名衰减曲线（Spearman 随 $N$ 的变化，产出 P1-rank_decay）改为该模型的**推论**而非独立检验：$\delta_{v,i}$ 非零即预测排名衰减。同时报告各尺度上的 Spearman/R²/RMSE（1B 仅 64 组，指标给 bootstrap 区间），验证假设 H2：Spearman 随规模单调下降但仍 >0.9，下降主要来自少数专业域。

**(7) 外推表稳健性（A12–A15，只讨论不验证）。**
**大白话**：小锅试出的菜谱放大到大锅会变味——要么证明菜谱尺度不变，要么把"变味规律"也建进模型。
① 用 1M 拟合系数直接预测 est Loss，量化系统性偏差；② 用 (6) 的尺度联合模型代入 $N=10^{10}/7\times10^{10}$ 重预测，与事后漂移律 $\beta_{v,i}(N)=\beta^0_{v,i}(N/10^6)^{\rho_{v,i}}$ 的修正结果互相对照（两条独立修正路径的吻合程度本身是稳健性证据）；③ 只把"$\mathbf p^*$ 的排名稳定性"（Spearman + 灰色关联度）作为结论，并**明确标注 est Loss 为幂律外推生成、非观测**。
依据：标度律跨 4 个数量级（1M→70B）系数完全不变是强假设；RegMix 原文也只验到 1B。跨尺度外推必须给偏差证据或修正机制——"直接套原系数"一律视为待检验假设。
